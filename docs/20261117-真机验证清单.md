- **iPhone（重点）**：静音键对 WebAudio 的影响（5 号检查点）；刘海安全区（顶部横幅是否被刘海挡）；Safari 底部工具栏收展

- **安卓**：返回键行为（会直接退出页面——可接受，记录即可）；低端机第 3 关的帧率主观感受
