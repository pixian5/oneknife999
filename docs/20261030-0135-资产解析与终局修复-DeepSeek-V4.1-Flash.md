# 20261030-0135 资产解析与终局修复（0.8.5）

> 日期：2026-10-30 01:35 · 模型：DeepSeek-V4.1-Flash · 基线：0.8.4（`a18d520`）
> 本轮针对 0.6.2 代码审查中确认的 P0/P1 问题做修复，不改变既有玩法规则。

## 背景

0.6.0 把 50 种新野怪写进 `CHAPTERS`，生成图会给名字加章节前缀（如「边境荒原战狼」），
但素材库文件名无前缀（`monster-full-荒原战狼-idle.png`）。`render.js` 直接按
`monster-full-${entity.name}-${action}.png` 拼接，导致 5–100 关怪物贴图全部 404 并回退几何图形；
0.5.1 的 200 张动作帧实际 0 个生效。另一个独立问题是 Boss 情报头像每帧把 `src` 重设成
不存在的 `boss-{通用领主}.jpg`，单会话产生 5000+ 次 404。

## 改动

### 1. 新增 `game/src/assets.js`

- `stripChapterPrefix`：按 `map.chapter` 剥离章节短名；
- `MONSTER_ALIASES`：40 个旧生成怪 → 50 个动作帧物种；4 个素材库缺失命名
  （幽冥鬼鸮 / 熔岩蛇王 / 虚影刺客 / 灰烬魔像）显式映射；
- `resolveMonsterSpriteName`：完整名优先（避免「苍月鲨卫」被误剥成「鲨卫」），再剥前缀；
  动作帧 → 静态单帧回退；
- `resolveBossSprite`：11 个专属 Boss 用 `boss-full-*`，通用领主复用精英立绘 + 章节色调；
- `resolveBossUiPortrait`：通用领主回退本章章末 Boss，避免全部显示裂碑领主；
- `resolveMapBackgroundName`：50 张 `map-cXX-YY.jpg` 每图底图。

### 2. 渲染层

- `drawEntity` 改用资产解析器；新增章节色调离屏缓存；
- `renderBoss` 头像按 Boss 名缓存 `src`，只在变化时赋值，消除 404 风暴；
- `getGroundLayer` 优先每图底图，加载前回退章节图，缓存键带 `bgKey`；
- 角色面板攻击加入套装加成；图鉴全集改为模块级常量，消除每帧 900 次扫描。

### 3. 战斗 / 终局

- `resolveLethalSave` 改为按 `maxHp × hpRatio` 保留（500 血保留 60，不是固定 12），
  且低血时不回血；
- `meleeReflect` 只对普通 / 破甲 / 冲锋等近战命中生效；
- 玩家受击写入 `hitFlash`，`hit` 动作帧真正触发；
- 怪物 `heavy` 的 `windupMult` 接入前摇；`charge` 的 `dash` 接入出手位移；
- 无尽深层 `abyssFloor` 写入存档并在读档时夹紧；`abyssBest/abyssFloor` 同时净化；
- 深层击杀经验乘 `abyssMultipliers(floor).exp`，掉落品质叠加 `abyssQualityBonus(floor)`；
- 进入深层层数改为 `max(abyssFloor, abyssBest) + 1`，避免刷新后从第 1 层重开。
