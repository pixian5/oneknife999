## 伤害公式

```text
命中率 = clamp(0.75 + (准确 - 闪避) * 0.005, 0.35, 0.98)
技能基础伤害 = 主属性取值 * 技能倍率 + 固定值
防御减免 = 防御 / (防御 + 100 + 攻击者等级 * 5)
元素系数 = clamp(1 + 元素增伤 - 元素抗性, 0.20, 2.50)
最终伤害 = max(1, 基础伤害 * (1 - 防御减免) * 元素系数 * 暴击系数 * 状态系数)
PvP伤害 = PvE最终伤害 * 0.65 * 等级保护 * 职业修正
```

职业修正 0.90~1.10；PvE 吸血上限 15%，BOSS 效率 40%，PvP 上限 5%。同类控制依次 100%、50%、25%、免疫。

## 使用规则与版本治理

本文件是数值单一事实源，不是建议值列表。其他分卷可以解释体验和实现，但不得重新定义同名常量。每次
修改必须新增 `rules_version`、变更原因、影响范围、模拟结果、回滚版本和审批人；线上配置只能在维护窗口
切换，事件已经开始时锁定该事件的规则版本。

### 数值变更记录格式

```yaml
change_id: BAL-20260810-001
rules_version_from: 0.0.6
rules_version_to: 0.0.7
changed_keys: [combat.pvp_multiplier, loot.boss_protection_s]
reason: clarify_pvp_and_loot_boundary
expected_effect: no_change_to_existing_item_ledger
simulation_window_days: 180
rollback_version: 0.0.6
approvers: [system_design, economy, server]
effective_at_utc: 2026-08-12T02:00:00Z
```

同一字段不得同时出现在运营活动配置和基础配置中；活动只能引用白名单字段并设置有效期。客户端显示
版本、战斗结算版本和资产流水版本分别保存，不能用当前客户端版本重算历史掉落。

100级、九州主线完成、三件职业证明和个人试炼完成后可转1次。转生等级回到80，保留技能、装备、属性、
图鉴、社交和主线选择，开放皇州和转生装备。首发不出售转生券；配置预留3转但不开放入口。

## 战斗详细常量

### 基础公式

```text
命中率 = clamp(0.75 + (准确 - 闪避) * 0.005, 0.35, 0.98)
技能基础伤害 = 主属性 * 技能倍率 + 固定值
防御减免 = 防御 / (防御 + 100 + 攻击者等级 * 5)
元素系数 = clamp(1 + 元素增伤 - 元素抗性, 0.20, 2.50)
暴击系数 = 1.50 + 暴击伤害增益
最终伤害 = max(1, 基础伤害 * (1 - 防御减免) * 元素系数 * 暴击系数 * 状态系数)
PvP伤害 = PvE最终伤害 * 0.65 * 等级保护 * 职业修正
```

职业修正范围0.90~1.10；必须在公开版本说明和服务器配置同时出现。PvE吸血上限15%，对 BOSS 的有效
吸血效率再乘40%；PvP吸血上限5%。同类控制8秒内按100%、50%、25%、免疫递减，窗口外恢复100%。
