# 0.8.83 新 B 两轮 F91–F95 复测

- 日期：2026-11-24 19:09
- 版本：0.8.83
- 模式：真实键鼠，B 组 `?abyssPreserve=1`，`--cache-policy main-first --cache-timing entry`
- 结论：B 的“越死越回血”已消失，但两轮合计 +47、+51，仍未优于 A 组的 +47；B 继续只做 opt-in，默认保持 A。

## 1. 测试档与口径

- 起始档：`taoist-100-complete.json` 派生，`currentMapId=abyss-F91`、`abyssBest=91`、`abyssFloor=91`。
- 起始玩家：道士 41 级、HP 1583/1583、药水 0（进层首访 +1 变 1）、印记 3529、死亡 473。
- 每层入口先开主线秘藏补给箱（`main-first`），通常从 1 瓶变 3 瓶。
- 只统计真实死亡；每层按 5 只任务怪 + 回响走完，不额外清 12 只。
- 测试结束的存档另存 `/tmp/abyss-b083-run1-f95.json`、`/tmp/abyss-b083-run2-f95.json`；正式 `saves/abyss-progress.json` 已恢复为原 B F95 档（deaths 525），不用测试档覆盖。

- 单层波动仍然大：F93 第一轮 +9、第二轮 +11，A 基线 +6；F95 两轮都是 +13，A 基线 +11。F91/F92 新 B 略好于 A，F93/F94/F95 没有优势。

## 3. 归因

- 新 B 确实不再回血：本轮没有出现“同一只怪从 8302 回到 17361”的现象。
- 但“保留伤害”没有转化为更少死亡，原因更可能是：
  1. 死亡后普通怪仍在原出生点重建，玩家回营地后要重新接敌，已损生命只减少第二次击杀时间，不减少第一次接敌的伤害；
  2. F93/F95 的主要死亡来自首领阶段残留普通怪、雷暴/地刺与反伤，而不是“同一只怪打了两次”；
  3. 药水仍然只有 3 瓶/层，B 省下的击杀时间没有换来额外药水或站位优势。
- 因此不能把 B 的 +49 平均当成“已优于 A”；也不能因为两轮没回血就改默认。

## 4. 决策与下一步

- 默认保持 A；B 只保留 `?abyssPreserve=1` 实验开关。
- 若还要证明 B 有价值，需要 A 组同档再跑至少 1 轮，做 2v2 对照；单看两轮 B，样本仍不足以翻案。
- 若 B 继续无优势，建议删除 B 或把它降级为开发者调试开关，不再作为玩家默认选项候选。
- 下一轮优先看 F93/F95 的“首领阶段残留普通怪 + 地面危险区”而不是继续调普通怪回填比例；B 只改死亡回填，治不了这两个死因。
