# F111–F120 深层连续层实测与 F120 单层降档（0.8.91）

0.8.90 已把 F106–F110 压回 132–262 秒区间并发布。继续用同一套真实键鼠脚本 North F111–F120，目标是找到下一道墙，而不是只看单层是否通关。测试使用 `saves/abyss-runs/20261126-f111-f120-0890/` 的隔离存档，每层完成立即落 `floor-deaths.jsonl` 与日志；不调用 E2E strike、不注入战斗数据。

## F120 数值诊断

原公式下 F120 普通怪实体 HP：

- 普通：16,091–20,773
- 深渊化（×1.6）：27,626 / 31,364
- 回响：121,836（0.65 档，已与 F110 同档）

F110 经 0.75 降档后普通怪 11,513–14,350，201.3s 可通；F120 的深渊怪 27k–31k 约为其两倍，玩家单轮输出在死亡前打不完，死亡又把 5 只任务怪全部重建，形成死循环。

## 修复

`game/src/maps.js` 的 `normalTuning` 只给 F120 增加：

```js
{ hp: 0.65, attack: 0.75, defense: 0.8 }
```

修复后实体 HP：

- 普通：10,449–13,510
- 深渊化：17,942–20,399
- 回响仍 121,836，三阶段与整十补给不变

F119 与 F121 保持原公式，F110 仍是 0.75 档；单测锁定 F120 系数、最低/最高实体 HP，以及 F119/F121 不受影响。`echoVictoryRule` 仍保持 `legacy`：F120 的失败原因不是提前击破回响，而是普通怪打不动；强行改成 clear-first 反而把回响拖到 400 秒，实测后回退。

## 修复后真实键鼠

| 层 | 用时 | 死亡 | 药水 | 结果 |
|---|---:|---:|---:|---|
| F120 | **211.1s** | **+10** | 5→0 | completed |

同层从 666.7s/+69/未完成，降到 211.1s/+10/完成，接近 F110 的 204.0s/+10。普通阶段不再卡 0/5，回响阶段死亡从 27 次量级降到 10 次。

## 结论

F120 的墙由普通怪数值造成，不是回响 HP、营位数或 clear-first 规则；单层 0.65 降档即可把 666.7s/+69 的失败样本压到 211.1s/+10。F117–F119 的 254–276 秒 / +20–26 仍是下一段可优化区间，但当前均可通。
