# 0.8.45 暂停/后台自动暂停与画面缩放

- 时间：2026-11-20 17:38
- 版本：0.8.44 → 0.8.45
- 依据：`docs/20261120-1730-下一步待实现-豆包.md` 第 1 项（设置面板加缩放与暂停）
- 原则：只加“玩家离开/看不清”的保命能力，不动战斗数值

## 问题

真人试玩时，接电话、切后台、想看键位或存档，游戏时间照常推进：怪物继续打、药水继续回、重生继续走，回来可能已经躺了。设置面板只有键位，没有暂停入口；1280×960 下技能/设置正文 10–11px 偏小，手机画面里的怪物与飘字也偏小。

## 改动

### 1. 暂停：冻结整局时间，不是只停渲染

- `game/src/runtime.js` 新增 `pauseState`；`game/src/main.js` 的 `update(dt)` 在暂停时只 `renderAll()` 后返回，怪物 AI、玩家伤害、掉落计时、重生计时、药水回复、技能冷却全部不推进。
- `setPaused(paused, reason)` 暂停时清空 `keys`、摇杆、`pointer.down` 与走位目标，避免恢复后角色继续沿暂停前方向走；恢复时重置 `lastTime`，不把暂停期间的真实时间算成一帧超大 `dt`。
- 暂停时 `body.paused` 让动作栏 `pointer-events: none`，不会出现“点了攻击没反应”的假按钮。
- 普通战斗动作（普攻 / 技能 / 药水 / 拾取 / 一刀时刻）都加暂停保护；键盘在暂停时只允许开技能面板、静音、改键。

### 2. 三个暂停入口

- 画布左下角新增“Ⅱ 暂停”按钮，触屏可点。
- 打开设置面板自动暂停（`reason=settings` 时不显示暂停遮罩，因为弹窗本身盖住画面），关闭设置或点“继续”恢复。
- 页面切到后台（`visibilitychange` → `hidden`）自动暂停，回来显示“已暂停，点击任意处继续”；不会自动恢复，避免玩家没准备好就被打。
- 暂停遮罩覆盖画布，点击/回车/空格恢复；Esc 也会恢复。

### 3. 画面缩放 100% / 125% / 150%

- `game/src/render.js` 的 `getViewScale()` 乘以 `viewZoom`，镜头放大、画布分辨率不变；`canvasPoint` 仍用同一个比例换算，设置后鼠标/触屏点击不会错位。
- 设置面板新增三档按钮，选择写入 `localStorage`（key `oneknife999-view-zoom-v1`），刷新后保留。
- 设置/技能弹窗正文从 10–11px 提到 11–12px，缓解 1280×960 下的费眼问题。注意：这次缩放的是**画面镜头**，不是 DOM 字号；HUD 字号只做了小幅静态提升，完整 DOM 缩放仍未做。

### 4. 顺带修掉“点首领却锁到小怪”

触屏用例连续跑时出现约 1/3 概率：点首领上半身，`targetId` 变成旁边的小怪。定位到点击候选排序：

```js
.sort((a, b) => Number(b.boss) - Number(a.boss))
```

普通怪没有 `boss` 字段，`Number(undefined)` 是 `NaN`，比较器返回 `NaN` 会被引擎当作 0，排序整段失效。于是命中列表里谁先遍历到就锁谁；首领和小怪立绘重叠时就会锁到小怪。改为显式 `(b.boss ? 1 : 0) - (a.boss ? 1 : 0)`，并在 `tests/unit/real-player-fixes.test.mjs` 加契约禁止 `Number(b.boss)` 回归。修后同一用例连续 10 次 10/10 通过。

## 仍需注意

- 暂停遮罩只覆盖画布，右侧角色/装备面板仍可查看（这是有意的，方便暂停时看属性），但面板上的装备/强化操作仍可执行；如果要在暂停时禁止一切养成操作，需要再收一层。
- 设置触发的暂停不显示遮罩；如果玩家在设置里改完键位后直接切后台，`visibilitychange` 不会覆盖 `reason=settings`，回来仍是设置暂停，关闭设置才恢复。
- 画面缩放 150% 在 320×568 视口下可视范围很小，未单独限制上限；后续可按视口给最大档位。
- 真实 iOS Safari / 微信内置浏览器的 `visibilitychange` 行为未验。
- 点击候选排序只在“立绘重叠”时体现差异；其他场景仍可能锁到更靠近点击点的普通怪（当前规则是 Boss 优先，不是最近优先），是否符合预期可再定。
