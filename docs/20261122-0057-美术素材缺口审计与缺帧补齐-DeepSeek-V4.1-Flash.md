**代码引用的素材没有 404，但「106 种怪各有独立外观」远未补齐。**

- 106 个地图怪物名 × 4 动作，**解析后 100% 有文件**（靠别名复用与静态单帧回退）

## 三、本轮实际补全（4 张派生帧）

### 3.1 做法

| 怪 | 缺帧 | 派生方式 |
|---|---|---|
| 灰鬃狼 | idle | 复制 `walk`（项目 0.8.40 已有「idle 副本」先例） |
| 灰鬃狼 | attack | 由 `hit` 放大 1.05 + 右移 4 px + 上移 1 px |
| 沙盗斥候 | idle | 复制 `walk` |
| 沙盗斥候 | hit | 由 `attack` 缩小 0.95 + 上移 2 px |

约束：

- 统一 **160×160 RGBA**（与现有帧一致）
- **不做水平翻转**——渲染层没有朝向镜像（`render.js` 无 flip 逻辑），翻转会让攻击/受击帧突然转身；实测重心与 idle 一致（灰鬃狼 73.2→75.0，沙盗斥候 85.5→83.3）
- 文件命名为 `monster-full-<怪名>-<动作>.png`，与现有约定一致

### 3.2 白名单接入

`game/src/assets.js` 的 `ACTION_MONSTERS` 末尾加入 `"灰鬃狼"`、`"沙盗斥候"`，并留注释说明是临时派生帧、真实原画到位后覆盖同名文件即可。

### 3.3 验证

- `node --test tests/unit/assets.test.mjs` → **6 / 6 PASS**（含「106 怪 × 四动作全部解析到真实文件」）
- HTTP：4 张新帧 `monster-full-{灰鬃狼,沙盗斥候}-{idle,attack,hit}.png` 全部 **200**
- 尺寸 / 透明通道：160×160 RGBA，alpha 有效像素占比与同源帧一致
- 浏览器冒烟：第 1→3 关连续推进，**0 请求失败 / 0 console error**；但第 2 关随机刷怪没有命中灰鬃狼，**未取得「该怪在画面中真实渲染」的截图证据**（见第六节）

## 四、剩余缺口与能力边界（必须说明）

### 4.1 缺口规模

| 需求 | 数量 |
|---|---|
| 给 88 个复用怪做独立原画（每只 4 帧 = 352 张图） | 最大 |
| 给 12 个仅静态图的怪补 4 帧（48 张） | 中 |
| 给 46 个无自有素材的怪补 4 帧（184 张） | 中 |
| 去重后物种级缺口 | 约 100 个物种 × 4 帧 |

### 4.2 为什么本容器补不了

- 没有图像生成工具：可用工具中只有 `analyzeImage`（分析），没有 `image_gen` / 文生图能力
- 没有图像生成 API 凭证：环境里只有 `CODEARTS_ACCESS_TOKEN`，无豆包 / GLM / 即梦 / OpenAI / Replicate 等 key
- 项目历史路径是「会话内 `image_gen` 生成 → 短链落地 → PIL 亮度抠图（阈值 45）+ SMOOTH_MORE 羽化 → 160×160 RGBA」，短链数天过期、必须当轮落地（见 `docs/20261120-0134-下一步待实现-豆包.md`）

因此本轮只做了**能在无生成能力下闭环**的部分：缺帧派生 + 白名单 + 审计工具。**用程序化绘制（PIL 画新怪）会破坏与现有 79 个物种的美术一致性，不建议**；用现有素材换色/镜像批量造「新怪」会让 88 个复用怪变成 88 个色差怪，同样不建议，除非明确接受这种占位方案。

### 4.3 可选的下一步

| 方案 | 说明 | 需要什么 |
|---|---|---|
| A（推荐） | 提供图像生成通道（API key / 工具），按审计清单分批生成，每批 10 种落地 + 复制 idle + 进白名单 + 提交 | 一个能用的文生图接口 |
| B | 接受「程序化变体」占位：换色 / 加装饰 / 局部变形，让 88 个复用怪至少颜色不同 | 明确同意降级方案 |
| C | 只补 12 个仅静态图的怪（用静态图派生四帧） | 同意「静态图伪动作」 |

## 五、工具与复现

```bash
# 审计
node tools/asset-audit.mjs

# 缺帧补齐（可重复执行，只创建缺失文件）
python3 - <<'PY'
from PIL import Image
def derive(src,dst,scale=1.0,dx=0,dy=0):
    im=Image.open(src).convert("RGBA")
    if scale!=1.0: im=im.resize((round(im.width*scale),round(im.height*scale)),Image.LANCZOS)
    c=Image.new("RGBA",(160,160),(0,0,0,0))
    c.alpha_composite(im,((160-im.width)//2+dx,(160-im.height)//2+dy))
    c.save(dst)
derive("game/assets/monster-full-灰鬃狼-walk.png","game/assets/monster-full-灰鬃狼-idle.png")
derive("game/assets/monster-full-灰鬃狼-hit.png","game/assets/monster-full-灰鬃狼-attack.png",1.05,4,-1)
derive("game/assets/monster-full-沙盗斥候-walk.png","game/assets/monster-full-沙盗斥候-idle.png")
derive("game/assets/monster-full-沙盗斥候-attack.png","game/assets/monster-full-沙盗斥候-hit.png",0.95,0,-2)
PY

node --test tests/unit/assets.test.mjs
```
