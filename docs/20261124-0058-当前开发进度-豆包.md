# 0.8.79 当前开发进度

## 版本

0.8.79。`VERSION`、`package.json`、`package-lock.json`、`CURRENT_APP_VERSION`、`CACHE_VERSION` 已一致；`BUILD_VERSION` 改为复用 `CURRENT_APP_VERSION`。

## 本轮完成

1. `game/src/maps.js` 新增 `generatedMonsterRoster()`、`shuffledIndices()`、`monsterRoster` 字段与 `MAP_THREATS` / `mapThreatFor()`。
2. 每张生成图实际派出 4–6 种怪，不再是本章 9 种全上；相邻图重叠 ≤ 较小阵容一半。

5. `tests/unit/maps.test.mjs` 新增阵容契约与威胁契约测试。
6. 版本、构建版本、PWA 缓存版本同步到 0.8.79。
