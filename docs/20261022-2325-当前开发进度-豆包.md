### 0.3.0 消耗品与材料体系（本轮）

材料从「能掉、能消耗」升级为完整闭环：

1. **材料堆叠**：`stackMaterial` 拾取合并同名材料（count+1）；`normalizeInventory` 存档恢复时合并旧档重复同名材料；强化消耗 count-1（归零才删条目）。材料不再占满 12 格背包。
2. **拆解系统**：`salvageReward`（返还 1 黑铁矿石 + 10% 价值金币）+ `salvageItem`；背包装备格新增「拆」按钮（材料/消耗品/货币不可拆解），新增拆解音效。
3. **任务奖励可配置化**：`QUEST_REWARD = { gold: 60, marks: 8 }` 成为唯一事实源——`checkMapCompletion` 发放与任务链任务卡/任务标签展示同源，消除硬编码漂移。
4. **材料来源分层**：生成图物品池新增黑铁矿石（普通怪基础材料来源，docs/03：普通怪 -> 基础材料）；首领魂核保留为铸魂材料。
5. 背包格由 `<button>` 改为 `<div>`（支持内部「拆」按钮，避免嵌套 button 非法 HTML）；背包渲染签名含 count（堆叠变化触发重渲染）。
