# 0.8.51 侧栏当前生命与受伤血条（豆包）

## 真人试玩暴露的问题
首领区混战时，页面运行时 `state.player.hp = 111`，右侧玩家卡仍显示「生命 386」。`hpStat` 取的是 `playerMaxHp()`，只展示最大生命；画布玩家头顶只有一条 76×5 的细血条，没有数值。

结果是玩家只能看到「386」这个不会变的数字，无法判断自己还剩多少血，也不会意识到已经进入低血线。这不是单纯的美术问题，是战斗信息缺失。

## 修复
- 右侧「生命」改为 `当前 / 最大`，如 `320 / 386`。
- 数值下新增 7px 高生命条，宽度按 `hp / maxHp` 实时变化，低于 25% 加 `.low` 变亮红。
- `renderHeroPanel` 的签名加入当前生命，否则面板缓存会拒绝刷新。
- 430px 视口玩家卡固定 172px 高，生命条加入后溢出 7px；移动端把血条压到 4px、上边距 2px。

## 踩坑
第一次用了 `setClassName($("hpBar"), "low", condition)`，但 `setClassName` 只有两个参数，第三个条件被忽略，血条永远挂 `low`。应使用三参数的 `setClass`。UI 用例补了「满血时 low 必须为 false」，防止这种静默错误。

## 验证
- 真实浏览器：站定挨打，`386 → 320`，侧栏同步 `320 / 386`，血条 `82.9%`，未误触低血样式。
- `npm run verify` 241/241；十组 UI 回归全绿，含 430/390/360/320 布局。
- 0.8.50 首领小怪提示在同一局真实显示「2 只」→清掉一只后变「1 只」。
