## 三、纯 PIL 亮度抠图参数

1. 打开转 RGBA；numpy 算 `R+G+B` 三通道和。
2. **alpha 掩膜**：`和 < 45 → 0（背景）`，否则 255（与 0.4.9 素材库同一阈值，95 会切穿暗色主体）。
3. **羽化**：alpha 先经 `ImageFilter.SMOOTH_MORE` 平滑一次，再把 `alpha < 8` 的像素置 0（防止羽化把主体边缘羽没）。
4. 按内容 bbox 裁紧，**contain 等比缩放**（保持宽高比、完整容纳于目标盒）后居中粘贴到透明画布：
   - 玩家 → **160×200** RGBA；
   - 精英怪 → **160×160** RGBA。
5. 落盘 `game/assets/`。

> 规格核对：现有 `player-full-warrior/mage/taoist.png` 3 张为裁紧规格（157/150/146×200，内容 bbox 贴边），`monster-full-*.png` 统一 160×160 居中。本轮 18 张动作帧按显式步骤落在固定 160×200 画布（居中、便于动画帧锚点一致），10 张精英怪落在 160×160；与既有 3 张裁紧底图的差异已在本文与进度文档注明。
