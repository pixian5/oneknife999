## 一、0.3.2 新产生/暴露的待办（按优先级）

### P0（建议下一轮）

1. **刷怪经验收益再评估**：本轮允许「清完目标后继续刷怪仍给 50% 经验」，可能导致玩家在低关刷满再走。建议用 `balance-sim` 对照「重复击杀给 0 / 给 50%」两种策略，确认是否需要收紧。
2. **击杀升级的成长曲线回归**：本轮 e2e 只放宽了等级断言，尚未补充「故意刷怪到本关上限」的专项用例。建议新增一个浏览器用例：首关刷满 → 断言等级卡在 Lv.2（上限），通关后仍为 Lv.2。

### P1

3. **键位互换**：当前冲突只提示不绑定，可增加「若目标键已被占用则自动互换」的选项。
4. **键位方案预设**：可提供「WASD 默认 / 单手 / 左手」预设，一键切换。
5. **手柄支持**：键位系统已抽象出 action，接入 Gamepad API 时可以复用 `KEYBIND_ACTIONS`。
6. **设置面板扩展**：把音效、伤害数字、画质等选项并入同一设置弹窗，避免右上角按钮继续膨胀。

### P2

7. **升级反馈强化**：升级时全屏金色粒子/短动画（目前只有音效 + toast + 日志）。
8. **经验来源可视化**：击杀飘字显示「+13 EXP」，让玩家直观看到经验来源。
9. **键位导入导出**：与存档导出一起提供，方便换设备。

## 二、纪律与提醒

- 每次改动后必须跑：`npm run verify` → `npm run test:ui` → `npm run test:ui:levelup` → `npm run test:ui:regression`；改动战斗/成长逻辑时追加 `npm run test:e2e`。
- 键位数新增时，必须同时更新 `KEYBIND_ACTIONS` 与 `game/README.md` 操作说明，二者是玩家可见事实源。
- 文档命名沿用 `<日期>-<时分>-<标题>-<模型名>.md`，新增后同步 `文档索引.md` 与 `docs/README.md`。
