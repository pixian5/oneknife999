# 下一步待实现（0.3.7 之后）

> 模型：DeepSeek-V4.1-Flash｜时间：2026-10-24 03:38

## P0（直接影响玩家对「变强」的感知）

1. **角色面板展示总防御**（半轮工作量）
   防御词缀现在真的生效了，但界面没有任何地方显示玩家总防御，玩家重铸出「防御 +N」时无法确认收益。建议在角色 / 装备面板补「生命 / 攻击 / 防御」三行，防御取 `playerDefense()`。

2. **自动拾取 + 掉落品质光柱**
   当前需要在掉落物附近按 F，清怪节奏被打断；品质光柱能让橙装掉落有反馈。注意城镇内 F 的双重语义（掉落 > 秘藏 / 节点 > 杂货商）。

3. **三步新手引导**
   首图引导移动、普攻、进杂货商；目前新玩家不知道 F 能开店、不知道 X 是普攻。

## P1（战斗深度）

4. **防御词缀收益量化**
   难度探针增加一组「带防御词缀」的对照（同一关卡、同一职业，只改 `affixes`），输出承伤与死亡数差异，避免再出现「显示有效、实际无效」或「实际过强」的隐性失衡。

5. **攻击类型化前摇**：重击 / 范围 / 毒圈使用不同蓄力时长与颜色，让玩家能按攻击类型做决策。

6. **施法硬直与打断**：技能释放期间玩家不可移动，被重击打断返还部分资源。

7. **破甲层数可视化**：怪物头顶显示破甲剩余时间与减防比例。

## P2（工程与扩展）

8. `balance-sim` 补前摇 / 全局闸门 / 商店模型，让数值调整能先跑模拟器。

9. 难度探针扩面：`ONEKNIFE_PROBE_STAGES=5,15,25`、法师 / 道士对照。

10. perf 门禁化：CI 里跑 `npm run perf`，阈值 p99 ≤ 4ms、零 20ms+ 长帧。

11. 图鉴 / 套装成就、移动端真机触控验证、多人服务器最小验证。
