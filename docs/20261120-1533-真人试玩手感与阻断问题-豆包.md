# 真人试玩记录：从选职业到第一只怪（0.8.42）

- 时间：2026-11-20 15:00–15:33
- 方式：浏览器页面级操作（真实视口 1280×960，看画面 → 读 HUD → 决策 → 点击/按键），不使用 Playwright 机器人脚本
- 入口：http://127.0.0.1:4174/（普通入口，无 e2e 参数）
- 职业：战士（生命 368 / 攻击 37 / 防御 22）
- 结果：约 33 分钟只完成 1/8 清剿，1 次击杀，金币 40→50，经验 13/100，引导走到第 3/3 步

## 我作为玩家实际做了什么

1. 选战士，读右侧面板与任务链，按提示用键盘走出营地（引导 1/3 完成）。
2. 在怪物堆附近尝试“点击怪物锁定”，连续点了 6 次左右，只有 1 次真正锁定成功（赤牙猎犬，提示“已锁定，按 X 或点击普攻攻击”）。
3. 锁定后按 X，第一下没有伤害；走到 49 距离内才打出 33 点伤害，第二下补刀击杀（暴击 40）。
4. 击杀后引导跳到 3/3“靠近掉落光柱拾取”，但现场没有光柱，掉落数组为 0。
5. 想打开装备栏看刚捡到的东西，点右侧装备格，装备面板没开，角色反而朝那个方向走了一段。
6. 打开顶部“技能”“设置”两个面板，确认能开，但正文文字很小。

## 阻断性问题（按玩家受阻程度排序）

### P0-1 右侧 HUD 与底部技能栏“看着能点，其实点不到”

- 点装备格（1080,622 附近）没有任何面板弹出，角色坐标从 630,1067 变到 900,880，等于把点击当成了走位指令。
- 点底部“普攻”区域会弹出“附近没有可攻击目标”的提示，但同时角色也被带向该处（330,1100），说明按钮命中与画布点击在打架。
- 影响：玩家第一次想换装备/看背包，就会把角色送进怪堆。这是新手最先遇到、也最致命的一类误操作。

### P0-2 点击怪物锁定的命中区远小于看上去的怪物

- 怪物立绘约 60–70 px 高，可点击判定只有 `radius + 22`（世界单位），换算到屏幕约 30 px。
- 实测 6 次点击怪物，5 次变成“点地移动”，角色直接走进怪物怀里；只有 1 次成功锁定并弹出锁定提示。
- 影响：引导第 2 步明确写“点击怪物锁定”，但玩家按字面操作大概率失败，还会误走位。

### P0-3 攻击距离缺乏可读反馈，“按了没反应”无法自查

- 战士攻击距离 70 世界单位；实测角色与怪物在画面上几乎叠在一起（世界距离仍有 382）时按 X 完全不掉血，也没有“距离过远”的提示，只有极短的 toast。
- 只有站到 49 距离内才出伤害；红色攻击圈很细，在火焰背景上几乎看不清。
- 影响：玩家会以为按键坏了或游戏卡了，而不是“没进范围”。

### P1-4 引导第 3 步与现场不一致

- 首杀后引导写“靠近掉落光柱拾取（消耗品自动拾取，装备按 F）”，但本次击杀 `drops` 为 0，画面没有任何光柱。
- 影响：玩家在原地找不存在的东西，怀疑自己漏捡或游戏出错。

### P1-5 击杀后的怪物很快原地重生，清剿进度像卡住

- `mob-13` 击杀后 `alive=false`，约 1 分钟后同一 id 又在 49 距离处存活；HUD 仍是“清剿 1/8”。
- 影响：玩家分不清“这只我杀过没有”，重复打同一只，进度感很差。

### P1-6 普攻的悬浮说明会一直压在技能栏上

- 在“普攻”区域悬停/点击后，“普通攻击 对当前锁定目标造成 100% 属性伤害…”的黑色说明块长时间停在画面中下部，遮住技能 1、技能 2 与怒气条。
- 影响：战斗中挡视线，且没有明显关闭方式。

### P1-7 面板字号偏小、信息密度过高

- 技能面板正文约 11 px，设置面板 10 行键位挤在一起；右侧同时塞了属性、关卡、区域导航、12 格装备、任务链。
- 影响：1280×960 下需要凑近看；关键数字（升级进度、清剿进度）反而不如装饰条醒目。

### P2-8 缺少暂停与基础设置

- “设置”只有键位，改不了音量、画质、UI 缩放，也没有暂停。战斗中想停一下只能切窗口。

### P2-9 目标信息太薄

- 左下只有“赤牙猎犬 68/68”，没有距离、是否在攻击范围、是否被遮挡；怪物头顶血条与角色贴图重叠时难以辨认。

## 建议的修复顺序

1. 把右侧装备/背包、底部技能与普攻改成真正可点的 DOM 层（或给画布命中区做 UI 优先判定），杜绝“点 UI 等于走位”。
2. 点击锁定判定从 `radius + 22` 放大到立绘包围盒（至少 +40），并在鼠标悬停时给怪物描边/指针变化，让玩家知道“这里能点”。
3. 目标在范围外时持续显示“距离过远/正在接近”，并把攻击圈改成半透明填充而非细线；锁定目标加一个明显的准星。
4. 引导第 3 步要么保证首杀必掉一件装备，要么改成“清理剩余怪物”，别指向不存在的光柱。
5. 明确重生规则：要么击杀后不再重生，要么在 HUD 上写清“怪物会重生，清剿按击杀数累计”。
6. 悬浮说明 1.5 秒自动收起，或移出技能栏区域。
7. 设置里加 UI 缩放（100%/125%/150%）与暂停。

## 方法与偏差说明

- 浏览器工具的真实按键注入（press_key）在本环境无法稳定驱动该 canvas 游戏，因此移动/攻击使用页面内 `KeyboardEvent` 派发；这与真人按键走同一条 `keydown` 逻辑，动作速率 193 单位/秒、普攻间隔约 0.8 秒，和手按接近。
- 点击、面板开关均为真实坐标点击，未调用任何游戏内部接口；仅用 `runtime.state` 读取坐标/血量做核对。
