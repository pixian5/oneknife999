# 0.8.50 首领小怪提示与试玩存档连续性（豆包）

## 真人试玩现场
战士 Lv1、无装备，清完 8/8 后进入首领区。目标卡只写“击败裂碑领主”，没有提示首领身边的小怪。连续 4 次死亡诊断：
- `裂碑领主`：boss 93%，距离 18
- `赤牙猎犬`：boss 93%，距离 887
- `灰烬侦察者`：boss 81%，距离 65

其中 3 次死于小怪包夹，不是首领本体。玩家一直点普攻自动锁首领，小怪没人处理，5 条命只磨掉首领 170 血。

## 修复
`objectiveView()` 在步骤 2 统计首领 180px 内仍存活的小怪：
- 有：`普通怪清剿已完成。首领身边还有 N 只小怪，先清小怪或用范围技能再打首领。`
- 无：恢复原文案。
同时把 `view.text` 加进任务卡刷新签名，小怪清掉后文案立即变。

## 验证
- 新增 `tests/ui-boss-adds-hint.cjs`：清怪进度设为 8/8，断言目标卡出现“还有 2 只小怪”和“先清小怪/范围技能”。
- `npm run verify` 240/240，九组 UI 回归全部 PASS。

## 浏览器关闭与测试存档
- 游戏会写 `oneknife999-prototype-save-v4` 到 localStorage，关标签页/刷新不会清档。实测刷新两次回 0.8.49 后仍保留 3/8。
- Browser Use 若换了浏览器配置文件或环境，localStorage 会丢，看起来就是“从头开始”；自动化 Playwright 用例本身也刻意每次新档。
- 真实试玩要跨会话续档，应使用游戏“导出/导入”存档，或保持同一浏览器 profile。
