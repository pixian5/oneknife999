## 本轮完成

**铭牌上移 + 飘字避让**，解决「人物、野怪的血条 / 名字被遮挡」。

### 三个根因

1. 伤害飘字画在 `y - radius - 12`，正好落在铭牌的血条行上（暴击 18px、一刀时刻 25px 覆盖更大）。
2. 铭牌与实体轮廓间隙只有 8px（首领 14px），首领饰环、前摇环、中毒 / 破势环伸进血条。
3. 结构性问题：铭牌在 `drawEntity` 里逐实体绘制，之后所有世界绘制（技能预览、玩家、粒子、飘字）都画在它上面。

### 三处改动

| 文件 | 改动 |
|---|---|
| `game/src/render.js` | 新增 `NAMEPLATE_HEIGHT` / `NAMEPLATE_GAP` / `nameplateTop()` / `floatYAboveNameplate()` / `playerNameplateTop()` / `floatYAbovePlayer()`；间隙 8→20、14→26；`drawNameplate` 从 `drawEntity` 移出，在 `drawWorld` 最后按 y 升序统一绘制；玩家铭牌拆为 `drawPlayerNameplate()` 一并参与排序 |
| `game/src/main.js` | 伤害 / 落空 / `999` 飘字改用 `floatYAboveNameplate`；受伤 / 中毒 / 治疗 / 升级 / 连击 / 恢复点 / 重铸提示改用 `floatYAbovePlayer` |
| `VERSION` / `package.json` / `README.md` | 0.4.0 → 0.4.1 |
