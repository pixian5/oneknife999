# 自动拾取、品质光柱与三步新手引导（0.4.3）

- 日期：2026-10-28 08:16
- 模型：GLM（bigmodel-api/GLM-5.3 会话）
- 版本：0.4.2 → 0.4.3
- 范围：路线图 P1-5 / P1-6 / P1-8 / P1-9 全部四项。

## 改动

### P1-5 自动拾取 + 掉落品质光柱

- **自动拾取**（main.js `autoPickupPass`，update 每帧调用）：走过掉落点 60px 内自动拾取非装备类物品（生命药水 / 回元露 / 金币袋 / 印记碎片 / 材料），材料走 `stackMaterial` 与手动拾取同规则堆叠；**装备仍需按 F 手动拾取**，保留 12 格背包的管理决策（docs/03 装备掉落是核心循环，不做全自动）。
- **品质光柱**（render.js `drawDrop`）：掉落按品质显示不同高度的垂直光柱——白 24 / 蓝 32 / 紫 44 / 橙 58，紫橙带缓慢脉动（橙更快），底部渐变到透明。玩家在屏幕边缘即可判断"这波掉落值不值得绕路"，对应 docs/03「高品质装备有地面表现」的核心承诺。

### P1-6 三步新手引导

新档（chooseClass 初始化）出现顶部引导横幅，三步顺序推进、每步 toast + 日志反馈：

1. **移动**：WASD / 方向键 / 摇杆累计位移 > 130px；
2. **战斗**：击败 1 只普通怪（衔接普攻默认键 X 的教学）；
3. **拾取**：靠近掉落光柱拾取（自动拾取或按 F 均可完成）。

`player.guideStep` 随存档持久化（1/2/3 进行中、99 完成）；旧档与未开始引导的档加载即视为完成，不会看到横幅。完成文案顺带教学通关条件（清怪 + 首领 → 出口开启）。

实现要点：`advanceGuide(nextStep)` 顺序守卫（完成步 99 的前置是第 3 步）；钩子分布在 update（位移检测）、defeat（击杀）、collectDrops（手动拾取）与 autoPickupPass（自动拾取）。

### P1-8 难度探针防御词缀对照组

`tests/difficulty-probe.cjs` 新增 `ONEKNIFE_PROBE_DEFENSE_AFFIX=1`：每关先跑基线装备臂，再跑「每件基线装备 +1 条防御词缀」的对照臂（词缀值 = config.js 防御条目按关卡等级的中位滚动，`1 + 0.16×(等级-1)`），两臂各按 PROBE_RUNS 取中位数，末尾输出 `DEFENSE AFFIX stage N 基线 X死/Ys → +防御词缀 …（死亡 ±n，耗时 ±ns）` 差值行，量化防御词缀的真实收益（0.3.7 修复防御词缀参与承伤后，一直缺一个可度量的收益数字）。默认关闭，行为与旧版一致。

### P1-9 难度探针扩法师 / 道士

探针自 0.3.6 起就支持 `ONEKNIFE_PROBE_CLASS`，但从未实际跑通过 mage / taoist。本轮以 `RUNS=1 STAGES=5` 实测两个职业（结果见下方验证），确认远程职业的「停射程边缘 + 一刀一撤」模型可用，后续发布前抽样可覆盖三职业。

## 已知边界

- 自动拾取半径 60px 固定，不做「寻宝词缀扩拾取范围」的联动（词缀池中的寻宝组尚未实装，留给装备扩展轮）。
- 引导横幅不做遮罩 / 高亮描边（保持零依赖实现）；三步文案在改键后通过 `keyLabel` 显示当前键位。
- 探针对照臂的词缀值取中位滚动，未模拟「重铸卷真实消耗」的经济成本——它度量的是战斗收益，不是性价比。
