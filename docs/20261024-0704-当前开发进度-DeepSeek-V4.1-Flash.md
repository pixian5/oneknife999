## 四、本轮发现的问题（未修，待决策）

0. **死亡后首领满血重置放大了难度波动（优先处理）**：0.4.0 探针同一构建三次为 0 死 / 57s、8 死 / 210s、1 死 / 71s。波动不是数值回退，而是「死亡 → `loadMap(…, true)` 重置地图实体 → 首领满血」形成正反馈：一次失误就要从头再打满血首领，死亡越多耗时越长、越容易再死。真实玩家体验同样糟糕。建议改为「复活后首领保留已损失生命（或只恢复到 50%）」，既稳定探针，也让失败一次不至于全盘重来；这会改变既有战斗规则，需你确认后再做。

1. **装备战力与三围的换算仍不直觉**：「战力」是综合分（攻击 + 生命/防御加权），tooltip 同时出现「有效战力 50」和「攻击 +45」，玩家可能仍疑惑两者关系。下一步可考虑在面板加一个「伤害估算」或把战力拆成两项。
2. **重铸仍是纯随机**：只能看到旧→新，无法锁定想要保留的词缀。若要提升付费 / 材料价值，可加「锁定 1 条词缀、成本 ×1.8」的规则（需先补 shop.js 单测与报价表）。
3. **探针仍未覆盖法师 / 道士**（0.3.9 遗留）。
