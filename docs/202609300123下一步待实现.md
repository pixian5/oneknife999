## 四、遗留问题与风险（本轮更新）

1. 快进验收（`fast=1`，25 倍伤害）只证明百图结构可达，**不代表真实速度下的数值平衡**；正式平衡必须用真实速度模拟，不能用快进结果替代。
2. `.test-artifacts/`（截图与 e2e 日志）已加入 `.gitignore`，不进入版本库。
3. 百图 e2e 全量回归耗时较长（本机约 30 分钟），维持「push 只跑校验 + UI 冒烟、百图回归手动或每周触发」的分层策略。
4. 帧率探测在无头 Chrome 下关闭了垂直同步与 GPU 垂直同步（`--disable-frame-rate-limit --disable-gpu-vsync`），测的是 CPU 侧 rAF 管线开销，不完全等价于真机 GPU 光栅化负载；且为桌面 1440×900 视口，移动端仍需真机采样。
5. Prettier 范围有意排除 `game/game.css`、`game/index.html` 与 `docs/`；CSS / HTML 改动仍由 `npm run test:ui` 与 `npm run test:ui:regression` 守住。
