# 0.8.57 篝火按 F 反馈与三职业全通回归

## 问题

三职业百关真实试玩中，篝火是“靠近后被动恢复”，但玩家按 F 没有任何反馈，容易误判篝火失效。F 在附近没有掉落、补给箱、场景点、城镇商人时只提示“附近没有可拾取物品”，没有解释篝火规则。

## 修复

`game/src/main.js` 的 `collectDrops()` 在城镇分支之后补篝火分支：

- 若 `nearRestPoint()` 为真，显示“篝火：停留即可恢复生命与符力，无需按 F”，然后返回。
- 不改变篝火恢复速度，不改变任何战斗数值，只补交互反馈。
- 分支顺序保持“掉落 → 补给箱 → 场景节点 → 城镇商店 → 篝火”，不会抢走正常拾取与交易。

## 验证

- 真实键鼠从第 100 关城镇走到篝火 `(1041,687)`，按 F：Toast 文本为“篝火：停留即可恢复生命与符力，无需按 F”。
- 页面加载 0.8.57（`fetch('src/main.js')` 与 `sw.js` 均含 0.8.57）。
- `npm run verify`：244/244 通过。
- `npm run test:ui`：desktop 1440×900、mobile 390×844、mobile-360 三档全部 PASS。

## 备注

三职业 100/100 终局存档保持有效，未因本次 UI 文案修改而重跑百关；改动只增加一条无副作用的提示分支。
