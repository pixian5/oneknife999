# F100 承伤拆分与回响阶段复活限流（豆包）— 0.8.88

## 一、结论

0.8.87 只砍 F100 回响 HP 的收益有限，根因不在回响血量，而在 **回响阶段死亡后把已清掉的普通怪全部重建**。0.8.88 先把承伤拆成互斥来源，再按数据把 F100 营位 12→6，并在“清完 5 只、回响未死”的同图复活里只保留最后 3 只杂兵。真实键鼠 F100 从 **392.8s / +23**（6 营位、未限流）降到两样本 **268.6s/+14**、**267.9s/+15**（中位 **268.25s/+14.5**），两场均 `completed=true`、`bossDefeated=true`、`resourceClaimed=true`。

## 二、0.8.88 诊断口径

`game/src/runtime.js` 的 `createDiagnostics()` 新增两组互斥桶，旧 `damage` / `hits` 原样保留，避免既有探针断裂：

- `normalMob`：普通图小怪命中。
- `abyssMob`：深层小怪命中（`state.abyssFloor > 0` 且攻击者不是 boss）。
- `bossNormal`：首领本体普攻。
- `bossSpecial`：首领特殊技生成的危险区引爆；`spawnHazard(boss)` 给这类 hazard 打 `bossHazard=true`。
- `hazard`：普通地面危险区。
- `poison` / `reflect` / `threat`：中毒、反伤、热浪分别记账。

`game/src/main.js` 的 `recordDamage(source, amount, bucket = source)` 同时写旧口径与互斥桶；普通怪命中按 `attacker.boss ? "bossNormal" : state.abyssFloor > 0 ? "abyssMob" : "normalMob"` 归类。这样 `damageSources` 相加等于真实总承伤，能直接判断下一刀该砍谁。
