# B 组普通怪回血修复与 0.8.83

- 日期：2026-11-24 16:29
- 版本：0.8.83
- 范围：只改 B 组显式实验的死亡回填语义；默认仍是 A 组满血重建，不改 F90 回响规则、不改 A 组。

## 1. 触发证据

F90 回响 B 后半段复验（`?abyssPreserve=1`）时观察到同一只 `深渊帝陵不灭战魂`（21828 HP）：

- 玩家第一次死亡后打到约 8302/21828；
- 玩家再死一次后查回 17361/21828；
- 现象是“越死越回血”，与 B 组本意“保留已损生命、降低复活后的重复劳动”相反。

## 2. 根因

旧实现 `preservedAbyssNormalHp(maxHp, hp, ratio)`：

```text
lost = maxHp - hp
return maxHp - lost * ratio
```

`ratio=0.5` 时是“保留剩余伤害的一半”。8302 已损 13526，下一次变成 `21828 - 13526*0.5 ≈ 15065`，实测约 17361；每死一次，已损伤害被再减半，怪物向满血回升，B 组无法靠多次死亡累积进度。

## 3. 0.8.83 修复

新语义：**死亡后普通怪血量上限压到 `maxHp*ratio`，且只降不升**。

```text
if ratio <= 0: return maxHp        // A 组旧行为
if hp >= maxHp: return maxHp       // 满血怪不处理
ceiling = round(maxHp*ratio)
return min(hp, ceiling)            // 低于上限保持原血，绝不回升
```

效果：

- 21828 HP、8302 血：8302 < 10914，保持 8302，不再回到 17361。
- 21828 HP、17361 血：压到 10914。
- 低于 50% 的怪保持原血，不会因为死亡被“治回半血”。
- A 组 `ratio=0` 仍完全满血重建，默认行为不变。
