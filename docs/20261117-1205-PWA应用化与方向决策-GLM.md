## 二、PWA 实施（0.8.36）

**克制原则：素材 108MB 绝不全量预缓存**（首次安装就会爆存储配额）。

| 件 | 实现 |
|---|---|
| manifest.webmanifest | standalone 全屏、主题色 #101820、三尺寸 icon（192/512/maskable） |
| 图标 | 从现有 `logo-word.png` 生成（深色底 + logo 居中 56%）：icon-192 / icon-512 / apple-touch-icon(180) |
| Service Worker（sw.js） | **壳预缓存**（index/game.css/manifest，装完离线可开）+ **素材按需缓存**（cache-first，访问过的离线可用）+ **导航网络优先**（更新即时生效，离线回退缓存壳）；activate 清旧版本缓存 |
| iOS 三件套 | apple-touch-icon + apple-mobile-web-app-capable（全屏）+ status-bar black-translucent + 标题「一刀999」 |
| 启动画面 | 品牌 logo + 「烬阳服务器连接中……」占位，main.js 初始化完成即撤（消除 JS 加载白屏期） |
| 注册开关 | `!TEST_MODE` 才注册——**e2e/探针/perf 路径零影响**（Playwright 每次新 context，SW 本就不跨会话，双保险） |
| 版本纪律 | SW 缓存键 `oneknife999-v0.8.36` 与 main.js `CURRENT_APP_VERSION` 随 VERSION 手动同步；**deploy-hf.py 加一致性校验**，三处不同步直接拒绝部署（防"旧缓存永不失效"或"每次全量重取"） |

## 四、给后续 AI 的操作提示

- 发布新版本时**必须同步三处版本**：`VERSION`、`sw.js` 的 `CACHE_VERSION`、`main.js` 的
  `CURRENT_APP_VERSION`——deploy 脚本会拦截，但本地忘了改会浪费一轮排查。
- SW 的更新语义依赖「index.html 引 sw.js?v=版本」与导航 network-first，改缓存策略前先读
  sw.js 头注释。
- 若未来做素材全量离线包，走按章节的分包预缓存（玩家玩到哪章缓存哪章），不要一次性拉 108MB。
