# 产品总纲

## 产品定位

《一刀999》不是独立副本制 ARPG，而是持续存在的传奇类 MMORPG。一个服务器中的玩家共享地图资源、BOSS 刷新、装备市场、敌友关系和王城历史。装备价值来自稀缺、流派用途、可交易性和争夺故事。

## 核心玩家

第一核心人群是喜欢刷怪爆装、战法道、行会战争的成熟玩家；第二人群是喜欢交易、收集和经营装备的轻战斗玩家；第三人群是每天 20~60 分钟、周末愿意参与组织活动的移动端玩家。

不以重度副本背板、卡牌构筑或赛季清档玩家为主要目标。

## 核心循环

### 60 秒

找到刷怪点 -> 判断怪物与敌对玩家 -> 击杀 -> 查看地面掉落 -> 拾取或争夺 -> 决定继续深入还是回城。

### 30 分钟

完成一个明确目标 -> 获得技能、装备或材料进度 -> 参与一次精英/BOSS/遭遇战 -> 整理和交易 -> 设置下一件装备追求。

### 一周

提升等级与装备 -> 加入行会并参与据点 -> 准备王城物资 -> 周三资格战 -> 周六王城战 -> 分红和重设敌对目标。

## 独有卖点

### 一刀时刻

玩家完成职业职责积累破势槽，槽满后强化下一次核心技能。第一次剧情触发固定显示 999，之后全部使用真实伤害。战士表现为单次斩击，法师把多段法术压缩成一次爆发，道士引爆毒并联动召唤物。

一刀时刻不影响 BOSS 最后一击归属，不绕过 PvP 控制递减，不在商城出售独占词缀。

### 服务器历史

九章主线和王城结果共同写入服务器年表。结果影响事件、NPC、王城设施和外观，不删除玩家资产或封锁地图。

## 内容支柱

1. 野外刷怪与精英巡逻。
2. 地图 BOSS 和固定世界 BOSS。
3. 三职业组队与职业技能书追求。
4. PK、红名、悬赏和死亡爆装。
5. 行会据点、资格战和王城战。
6. 玩家摆摊、拍卖和装备生产消费。

## 首发范围

- 1~100 级和 1 转入口。
- 战士、法师、道士三个职业。
- 16 张地图、14 个区域 BOSS、1 个终局 BOSS；灰烬村没有 BOSS。
- 300 件装备、6 套套装、12 个装备部位。
- 单服目标同时在线 800 人；王城和世界 BOSS 实例上限 240 人。
- 移动端优先；团队达到 18 人以上时双端同步首发，否则 PC 延后。

## 不做事项

- 不直接出售顶级装备、技能书、强化材料、等级、转生和 PvP 属性。
- 不用赛季清空核心资产。
- 不做无风险无限挂机产出高级装备。
- 不让城主封锁普通玩家主线、基础职业技能和交易所。
- 不复制既有传奇产品的专有名称、地图、美术、怪物、技能和音效。
