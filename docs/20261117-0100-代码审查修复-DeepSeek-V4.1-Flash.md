# 0.8.31 代码审查修复（12 项）

本轮基于对 0.8.30 的逐模块审查（main/render/combat/persist/drops/skills/shop/input/monster-abilities/elite），修复 12 个有代码证据的缺陷：P1 × 4、P2 × 8。

## 一、P1（安全 / 数据丢失 / 终局循环）

### P1-1 导入 v2/v3 旧档会清空装备

**问题**：`sanitizeSavedGame` 只从顶层 `saved.equipment` 读装备，而迁移函数允许旧档只写 `player.equipment`；导入流程又是「先净化再迁移」，于是先生成 12 槽全 `null` 覆盖原装备。

**修复**：
- `persist.js`：`const sourceEquipment = saved.equipment ?? saved.player?.equipment ?? {}`
- `main.js importSave`：改为 `migrateSave(parsed)` → `sanitizeSavedGame(migrated.saved)`

**回归**：`sanitizeSavedGame：旧档只存在 player.equipment 时装备不被清空`。

### P1-2 导入字段可形成存储型注入

**问题**：`sanitizeItem` 只清理 `name/desc/glyph/affix.label`，未校验 `slot` 与 `setKey`。渲染层把它们拼进 `<img src="assets/equip-${slot}.png">` 与 `title`，可注入事件属性并持久化到 localStorage。

**修复**：
- `slot` 走白名单：`EQUIPMENT_SLOT_KEYS ∪ {consumable, currency, material}`，非法直接丢弃该物品
- `setKey` 走 `cleanText` 截断
- 物品数值逐字段钳制（`ITEM_LIMITS`：power 100k、value 1M、enhance 15、blessing 100、count 1M、词缀 999）

**回归**：`非法 slot 会被拒绝`、`物品数值超过上限时被钳制`。

### P1-3 深层按 T 进入主线而非下一层

**问题**：`input.js` 先判 `primaryExit()`，而复用地图几乎都有普通出口，`abyssFloor` 不变但深层倍率仍在。

**修复**：`if ((state.abyssFloor || 0) > 0) { enterAbyss(); return; }` 置于 `primaryExit()` 之前。

### P1-4 骨卫可被锁定并计入击杀

**问题**：场景节点 `nearestAlive` 与目标恢复都不过滤 `friendly`，骨卫可被设为目标，击杀后还加经验/掉落/通关进度。

**修复**：
- `drops.js computeSiteEffect`：`alive` 过滤 `!friendly && !npc`
- `main.js` 目标恢复：同样过滤
- `defeat()` 入口：`if (!target || target.friendly) return`

**回归**：`computeSiteEffect：scout 不会把友军骨卫当成目标`。
