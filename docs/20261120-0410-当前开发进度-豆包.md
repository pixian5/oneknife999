## 本轮完成

1. **定位并修复「连玩 4–5 关浏览器被杀」的根因**：问题不在云主机，而在渲染层贴图永久缓存——2048×2048 怪物动作帧单张解码 16MB，一关 4 种怪 × 4 帧约 256MB，旧的 `spriteCache` / `tintCache` 从不淘汰，4GB 机器必然 OOM。详见 [贴图缓存内存治理](20261120-0410-贴图缓存内存治理-豆包.md)。
2. **`game/src/render.js` 落地治理**：按 key 前缀降采样（地图底图 2048 / 章节图 1280 / 首领 512 / UI 128 / 其余 256）、解码后丢弃原大图、贴图 128MB + 染色 24MB 双预算 LRU、并发解码上限 6、新增 `spriteCacheStats()`。
3. **`game/src/main.js`**：`__ONEKNIFE_E2E__.spriteStats` 暴露缓存统计，供自动化回归断言。
4. **`tools/playthrough.cjs`**：接入 CDP 堆采样、`spriteStats` 记录、背包换装/拆解与技能加点，供长程实玩复测。
5. **版本同步**：`VERSION`、`package.json`、`main.js CURRENT_APP_VERSION`、`sw.js CACHE_VERSION`、`README` 当前版本五处统一到 0.8.41。
