## 本轮（0.6.0 → 0.6.1）完成内容

### 1. 怪物行为系统（0.6.0）

**问题**：106 种怪物共享同一套 AI。`config.js` 里为每种怪撰写的技能描述
（「毒牙：叠加一层中毒」「残军意志：首次受到致命伤害时保留少量生命」）**只用于悬停提示框的文字**，
没有任何代码实现——玩家看到的所有怪本质上是「血量/攻击/防御三个数字不同的同一个东西」。

**实现**：新增 `game/src/monster-abilities.js`，把 112 条技能描述归纳为：

- **8 种攻击形态**：基础 / 二段 / 三段 / 蓄力重击（击退）/ 远程投掷 / 冲锋 / 范围横扫 / 锁链拖拽
- **19 种被动**：中毒 / 减速 / 打断 / 干扰 / 资源压制 / 药水封锁 / 技能封锁 / 周期护盾 /
  首击减伤 / 残血减伤 / 近战反伤 / 致命保留 / 玩家残血增伤 / 同类增伤 / 攻速叠加 / 自身残血增伤
- **2 种亡语**：死亡毒区 / 死亡复原一次

`resolveAbilities` 用 suffix 匹配兼容章节前缀（「冰封冰壳魔」→「冰壳魔」），106 种怪零遗漏。

### 4. 难度实测与调平（0.6.1，本轮最有价值的部分）

用非快进探针 + A/B 对照（`?e2e=1&noabilities=1` 关闭全部行为）量化，得到一个**推翻初始判断的结论**：

> 第 15 关从 1 死涨到 4-5 死，**真凶不是行为系统**——关掉全部行为仍有 3 死。
> 真正原因是怪物类型 4→9 种后刷怪构成变化：12 个刷位覆盖全部 9 档，同屏平均强度上升。
> 行为系统本身只贡献约 1 次死亡。

据此做两轮调平：

1. **行为强度**：10 项下调（远程射程 2.4→1.9、减速幅度 0.55→0.68、同类增伤上限 0.5→0.35 等）。
2. **刷怪档位**：新增 `spawnTier` 分段——章内前 5 关用常规 6 档，后 5 关混入精英 3 档。

调平后探针数据：

| 关卡 | 调平前 | 调平后 |
|---|---|---|
| 5 | 0 死 / 47s | 0 死 / 52s |
| 15 | 4-5 死 / 59-76s | **2 死 / 64s** |
| 19（精英档） | — | 1 死 / 64s |
| 45 | 3 死 / 109s | **0 死 / 63s** |
