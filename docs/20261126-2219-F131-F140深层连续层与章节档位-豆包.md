# F131–F140 深层连续层与章节档位（0.8.94 / 豆包）

## 结论

0.8.94 用一组“深层 131+ 章节档位”替代逐层补丁，真实键鼠一次连续跑完 F131–F140：

- 十层全部 `completed=true`、`bossDefeated=true`、`resourceClaimed=true`，没有中途改数值、没有换档重跑。
- 总用时 **1,625.3s（27 分 05 秒）**，均值 **162.5s/层**，中位 **136.05s/层**。
- 死亡从 960 到 **1,052（+92）**，平均 **+9.2/层**。
- 单层峰值用时 **F140 291.0s**；单层峰值死亡 **F139 +21**；清怪阶段最重的是 **F138 +10**（总 +11，回响仅 +1）。
- F140 的 153,037 HP 回响在 18 次死亡内被打完，药水 5→0，说明“整十层压力留给回响”的设计仍成立，暂不需要再砍 F140 回响。

## 为什么 0.8.94 改成章节档位

F130 之后换章回到第 1 章（`chapterIndex 0`），基础 HP 回落，但层数攻击倍率继续线性上升。0.8.94 改前先取 F131 实体读数：默认普通怪攻击 **712–915**，6 只里 **4 只越过 791.5** 的两击必死阈值（玩家 1,583 血，两击 791.5+/击）。如果继续按层打补丁，会每 2–3 层碎一次。

因此本版不再逐层加分支，而是按“章节档位”统一：

| 层段 | 普通怪 `hp/attack/defense` | 说明 |
| --- | --- | --- |
| F131–F137 | `0.65 / 0.65 / 0.8` | 换章第一段；下调攻击让普通怪落在三击区间 |
| F138–F139 | `0.63 / 0.63 / 0.8` | 层数攻击倍率再涨一档，再降 0.02 |
| F140 | `0.60 / 0.60 / 0.8` | 整十层，普通怪让位给回响 |

- F130、F126、F127–F129、F120、F110、F108、F99、F90 等已验收层全部保持不变。
- `bossScale` 未改：F140 仍走整十 `1.25×0.65`，F138/F139 仍走普通 `0.55`（0.8.93 的 F127–F129 `0.45` 不外扩）。
- F141 及以后不纳入本版，避免用未采样层段推公式。

改后预测：
- F131 普通怪 HP 6,092–7,639、攻击 468–600。
- F138 普通怪最高攻击 768、深渊化 863（刻意保留两击压力）。
- F139 最高 773；F140 最高 767。
- F140 回响预测 HP 153,037、攻击约 1,382。

## 与 0.8.93 的对比

- F121–F130 按最终样本逐层相加为 1,786.4s、+108 死；F131–F140 为 1,625.3s、+92 死。十层总时长接近，死亡少 16，说明章节档位把“两击必死→死亡重建”的放大链压住了。
- F130 首样本 276.4s/+13、第二样本 136.1s/+4，说明同一配置的方差很大；F131–F140 只取一轮连续样本，不能把 291.0s 当成 F140 固定成本。下一轮应优先补 F139/F140 第二样本。
- F131–F134 都在 120s 内或附近（118.5/84.5/103.8/99.0），F135 突然 214.3s；F136 又回到 95.8s。F135 的尖峰是 `sting` 机制与药水节奏，不是档位公式失效，不应回调 F135 的普通怪系数。
