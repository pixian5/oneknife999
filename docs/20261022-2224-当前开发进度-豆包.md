## 本轮完成（P1#2 词缀/强化收益上 HUD）

0.2.5 引入 12 部位 / 强化 +15 / 词缀后，装备悬停已显示词缀与强化等级，但 HUD 战力数字仍按装备原始 power 汇总、背包与装备面板没有有效战力数值、+15 满强化无视觉反馈。本轮补齐三处：

### 1. HUD 战力汇总改为「有效战力」

- `renderPlayer`：战力 = 职业基础攻击 + 等级成长 + **12 部位 `effectiveItemPower` 之和**（原为 `item.power` 原始值）+ 防御×2。
- 效果：HUD 顶部战力数字立即反映强化（+8%/级）与攻击词缀的收益；签名含 power，强化/换装后自动刷新。
- 实测：+15 武器（power 120 + 攻击词缀 17）有效战力 281，HUD 总战力 857。

### 2. 装备面板 12 槽位

- 每槽位新增 `<span class="slot-power">有效战力</span>`（右下角）。
- +15 满强化：槽位加 `maxed` class（金色发光边框 + 内辉）与左上角 `MAX` 角标。
- 悬停 title 补充「有效战力 N」。
- 祝福值角标移至槽位底部居中（避免与战力重叠）。

### 3. 背包格

- 每格新增有效战力小字（底部居中）。
- 悬停 title 补全词缀明细与有效战力（原只显示名称与 desc）。

### 4. 样式

- `game.css`：新增 `.equipment-slot .slot-power` / `.equipment-slot .slot-max` / `.equipment-slot.maxed` / `.inventory-slot .slot-power`，`.slot-bless` 改为底部居中。
