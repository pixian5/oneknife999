# 状态图标 HUD 接入与透明化（0.8.75）

## 做了什么

把 0.8.74 的第六批状态图标从“概念稿”接到游戏 HUD：

- 新增 `tools/build_status_icons.py`：纯 PIL 圆形蒙版，把 5 张黑底 JPEG 裁切、缩放、透明化，输出 128px RGBA PNG 到 `game/assets/status-*.png`。
- `game/index.html` 玩家血条下新增 `#playerStatusStrip`：中毒、减速、眩晕、致盲四枚 32px 图标。
- 目标栏新增 `#targetStatus`：只显示当前目标的破甲（26px）。
- `game/src/render.js` 新增 `renderStatusIcons()`：每帧读 `state.player` 与当前目标，控制显隐、层数与剩余秒。
- `game/src/runtime.js` 增 `stunTimer/slowTimer/blindTimer/poisonTimer` 等初始化字段；`main.js` 在怪物 stun 命中时单独记 `stunTimer`，换图/复活清空状态计时。
- `game/game.css` 新增状态条与角标样式；`#targetHint` 选择器从 `span:last-child` 改为 id，避免新增目标状态容器后窄屏两行规则失效。

## 为什么破甲不跟玩家血条

`armorBreakTimer` 是**目标实体**身上的 debuff（0.4.2 起铭牌下写“⚔ 破甲 -15% · x s”），不是玩家自身状态。如果塞进玩家状态条，玩家会误以为“我破甲了”。现在：

- 玩家状态条：中毒、减速、眩晕、致盲（自身状态）。
- 目标栏：破甲（当前目标减益），目标切走立即收起。

## 为什么单独加 `stunTimer`

`applyOnHitPassives` 的 stun 分支原来只写 `state.player.attackTimer = max(..., duration)`。`attackTimer` 同时是普攻冷却，正常出手也会被写成 0.4–0.5s，不能拿它当“眩晕”判据；否则每次普攻都会误亮眩晕图标。因此单独维护 `stunTimer`，只由 stun 命中写入、逐帧递减。

## 透明化方式

没有下载 rembg/u2net：

- 每张图手工给一个正方形裁切框，先把不同徽章直径拉齐；04 的徽章本身比其它小一圈，单独裁紧。
- 4× 超采样画圆形 alpha，再缩到 128px，避免锯齿。
- 输出 `128×128 RGBA PNG`，5 张共约 158.8KB。中毒/减速/致盲保持原色；03 眩晕提亮 1.55×、05 破甲提亮 1.5×，否则 32/26px 下几乎看不清。
- `透明底预览.jpg` 用棋盘格检查圆形外无残留黑角，并给出 64/32px 两档。

## HUD 规格

- 桌面：状态条 32px 图标，间距 6px，角标 `×层数` / `剩余秒s`。
- 移动：仍用 32px；侧栏行高从 96px 提到 140px，让玩家卡完整露出状态条；360/320 窄屏用 140px，320×568 再降到 127px 并把状态条上边距归零，保住画布 190px 基线。
- 眩晕没有角标：持续时间 0.5–0.6s，加秒数会闪。
- 毒素角标是层数（`×3`），不是剩余秒；减速/致盲/破甲角标是向上取整的秒数，和铭牌文字同口径。

## 未做与限制

- `test:ui:status` 是**渲染回归**，不是真实战斗触发；还需用蛛/蝙蝠/雾区在真实战斗里逐类触发截图。尤其 stun 只有 0.5s，真实战斗截图要抓帧。
- 04 致盲图标仍是“闭眼红缝”，在 16px 可能读成两只红眼；目前 HUD 用 32px，暂不缩 16px。
- 剩余 7 枚（灼烧、流血、冰冻、护盾、治疗、狂暴、疾行）没有状态逻辑，未建空槽。
- JPEG 源仍留在 `美术素材-CogView/第六批-状态效果图标/`；游戏内只用透明 PNG。`game/assets` 从 706 增至 711。
- 换图/复活清空状态计时是行为修正：以前减速/致盲可能跨图残留；如果后续希望“深层延续状态”，需要另做设计，不要直接回退。

## 复现

```bash
python3 tools/build_status_icons.py

npm run verify
ONEKNIFE_CHROMIUM_PATH=/usr/local/bin/chromium npm run test:ui:status
```

> 本机 VM 没有 Google Chrome，浏览器回归需显式给 `ONEKNIFE_CHROMIUM_PATH=/usr/local/bin/chromium`；默认 `chrome` channel 会报找不到 `/opt/google/chrome/chrome`。
