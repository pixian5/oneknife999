## 三、本轮落地内容（P0）

### 3.1 新增 `game/src/feedback.js`（纯逻辑，可单测）

- `COMBO_RULES`：3 秒窗口、每 5 连击 +8 金币、上限 99、只加金币不改经验。
- `advanceCombo(combo, dt)`：倒计时推进与到期清零。
- `registerComboKill(combo)`：连击 +1、重置窗口、返回里程碑与奖励金币。
- `resolveGuideTarget({...})`：按「清剿最近普通怪 → 首领 → 前进出口」三阶段选指引目标，跳过 NPC，首领复活时回退固定坐标。

### 3.2 连击系统

- `runtime.js` 新增内存态 `fx`（连击、震屏、升级闪光），`setState` 与换图/复活时重置。
- `main.js` 击杀时登记连击，2 连击起在世界内飘出连击数字，5 的倍数加金币并写入战场记录。
- `render.js` 在屏幕顶部居中绘制「N 连击 + 剩余秒数」，临近结束淡出。

### 3.3 目标指引箭头

- `drawGuideArrow()`：绕玩家 54px 的彩色箭头，下方显示「目标名 · N 格」（30px = 1 格），距离 < 80px 隐藏。
- 纯绘制，不写存档、不改相机，不影响点击坐标。

### 3.4 打击感强化

- **屏幕震动**：满破势爆发 / 一刀时刻 / 首领击杀 / 升级触发，仅渲染层平移（不改变点击命中）。
- **升级光环**：`fx.levelUp` 1.1 秒，金色圆环 26→96px + 26 粒金色粒子 + 「LEVEL UP」飘字。
- **怪物挥击弧**：怪物命中玩家瞬间 `entity.attackFlash` 0.18s，朝玩家方向画红色弧。

### 3.5 移动端与可读性

- **长按普攻**：按住普攻按钮每 100ms 检查一次，仅当锁定目标进入普攻距离时出手，抬手/取消立即停止，按钮显示按下态。
- **技能资源态**：资源不足时技能按钮 `opacity: .5`、消耗数字变红。
