## 二、F61 回落确认章节轮换

- F60 107433 → F61 16094，回落 **85.0%**，与 F50 91432 → F51 13732 的 -85.0% 一致。
- F61 / F41 = 16094 / 11370 = **1.415**；F51 / F41 = 1.208，说明同一个第 1 章每轮十年整体抬高约 17–19%。
- F65 / F45 = 32037 / 23156 = **1.383**；F55 / F45 = 1.192，F65 / F55 = 1.161。
- 结论：F61 的回落不是回退 bug，而是 `buildAbyssMap()` 的 `(f-1)%10` 章节重置；深层倍率仍按层累积，所以下一轮同章节的绝对 HP 仍高于上一轮。
