# 20261028-0930 合并美术线与逻辑线：0.5.2 冲突决策记录（GLM）

## 背景

仓库在 0.3.8（`61fe92f`）之后分裂为两条平行开发线：

- **逻辑线**（origin/GitHub，本地）：0.4.3 自动拾取 + 品质光柱 + 三步新手引导、0.4.4 红名爆装落地回填与召唤物字段收口，另合并了远程 0.4.2 平行分支的「复活保留首领生命」（`restoreDamagedBoss`）。
- **美术线**（gitcode）：0.4.4~0.5.1 共 8 个提交——战斗实体贴图、全身立绘 + 程序化动作、章节氛围图场景底图、UI 图标全量补齐、150/200 张素材库。

两线在 `game/src/render.js` 上正面冲突（逻辑线重写了铭牌几何与绘制层级，美术线重写了实体贴图与铭牌锚定）。本轮以逻辑线为主干合并美术线，版本统一为 **0.5.2**。

## 冲突解决决策（render.js 四处）

### 1. 铭牌几何：融合而非二选一

- 美术线主张「名牌锚定贴图头顶」（`脚底 - 贴图高 - 间距`），逻辑线主张「0.4.2 阶梯避让 + 视野裁剪」。
- **决策**：保留 `spriteHeight()`（贴图尺寸），`nameplateTop()` 采用美术线的头顶锚定公式；`drawWorld` 里 0.4.2 的阶梯避让与按 y 排序逻辑不变，在其基础上整牌上移。两者正交：锚定决定基准位置，避让解决贴脸互压。
- 玩家铭牌同样改为「脚底 y+24 - 贴图高 112 - 间距 8」，与 `drawPlayer` 的精灵绘制基准一致（`PLAYER_SPRITE_HEIGHT` / `PLAYER_FOOT_OFFSET` 常量共享）。

### 2. 玩家血条归属：回归最上层独立绘制

- 美术线把玩家血条内嵌进 `drawPlayer()`（随玩家绘制顺序，会被粒子/飘字覆盖）；逻辑线 0.4.1 已将其拆为 `drawPlayerNameplate()` 并在 `drawWorld` 最上层统一绘制。
- **决策**：采纳美术线的**贴图精灵与动作动画**（攻击前倾、金色刀光弧、移动浮动/待机呼吸），**移除内嵌血条**，由 `drawPlayerNameplate` 接管。可读性回归（`test:ui:nameplate`）的硬指标依赖这一层级，不能回退。

### 3. 品质光柱：叠加而非替换

- 逻辑线：白/蓝/紫/橙四档高度 + 紫橙脉动（docs/03 品质地面表现承诺）；美术线：单张金色光束贴图。
- **决策**：品质渐变色柱为主（保留品质区分），金色光束贴图以 0.4 透明度叠加其上；贴图未就绪时静默跳过，光柱仍独立成立。

### 4. 商店重铸行：图标 + 锁定芯片并存

- 美术线用 `equip-{slot}.png` 图标替换字形；逻辑线有词缀锁定芯片（≥2 条可锁、报价 ×1.8）与锁定状态文案。
- **决策**：图标用美术线，词缀芯片与锁定逻辑（`affixChips`、`lockActive` 价格提示、🔒 标记）全部保留。

## 残余风险

- 铭牌锚定公式从「半径几何」改为「贴图高度」，如果某些实体贴图缺失（回退几何图形），铭牌会偏上（`spriteHeight` 仍按贴图尺寸算，而实体画的是小圆）。视觉上偏高但不遮挡，属可接受；后续可在 `drawNameplate` 里按 `spriteReady` 分支取不同基准。
- 美术线 0.5.0/0.5.1 的 218 张动作帧素材仍是素材库资产、未接入渲染（美术线自身的遗留项），本轮不动。
