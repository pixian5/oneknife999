# 0.8.10 回归稳定性与经济模型

本轮两件事：把上一轮暴露的 `blind` 随机假失败修掉，并把 `balance-sim` 从「只有产出」补成「产出 + 消耗」的完整经济模型。

## 一、`test:ui:blind` 随机假失败

**现象**：0.8.9 上连续两次报「雪原猎手在 30 秒内没有命中玩家（hp 386 → 386）」，第三次 PASS。用 `HEAD~1` 建 worktree 对照，0.8.8 一次即 PASS，说明是时机波动而非代码回归。

**根因**：测试站在刷怪点旁 40px 静等怪物主动命中，怪物巡逻路径与前摇节奏存在随机；30 秒窗口在部分种子下会空转。

**修复**（`tests/ui-blind-passive.cjs`）：最多 2 轮，每轮重新载入初始存档恢复满血再等 25 秒；仍未命中时输出 `BLIND retry`，避免把随机写成回归。

**验证**：连续 3 次 PASS（blind 1.60 / 1.67 / 1.63s）。

## 二、经济模型补全（`balance-sim`）

**问题**：此前的百图模拟只统计掉落、装备与强化，没有商店购买与重铸，金币只有入口没有出口，无法发现「后期金币无限堆积」。

**新增**：

| 模块 | 规则 |
|---|---|
| 商店补货 | 药水 < 2 瓶买药水（90）；武器词缀 < 2 且无卷轴时买卷轴（200）；+8 以上无矿石时买矿石（60） |
| 强化材料 | +8 起每次强化消耗 1 件黑铁矿石（与游戏内一致） |
| 词缀重铸 | 复用 `shop.js` 的 `reforgeQuote` / `reforgeAffix`：词缀 < 3 时按报价消耗金币 + 1 卷重铸 |
| 统计输出 | 每关输出「词缀 N / 重铸 N / 金 N」，汇总输出买货次数、重铸次数、累计金币消耗 |

**三职业百图模拟结果**：

| 职业 | 死亡 | 买货 | 重铸 | 金币消耗 | 末期结余 |
|---|---:|---:|---:|---:|---:|
| 战士 | 7（stage_005 单关 4 死） | 140 次 | 94 次 | 205,273 | 18,123 |
| 法师 | 0 | 105 次 | 91 次 | 173,945 | 49,825 |
| 道士 | 0 | 113 次 | 92 次 | 188,307 | 35,094 |

**判读**：

- 经济出口成立：三名职业都花掉 17–20 万金币，末期结余 1.8–5 万，没有出现「到后期金币无限堆积」。
- **战士第 5 关单关 4 死**是唯一过难信号（`stage_005`），建议用 `difficulty-probe` 复测该关；法师/道士 0 死与此前「法师承伤仅战士 55%」的判断一致，难度曲线仍偏软。
