## 代码接入

- `render.js renderBoss`：按 `assets/boss-${boss.name}.jpg` 动态换首领立绘，`onerror` 回退默认裂碑领主图。
- `render.js renderTravelConfirm`：按 `target.chapter` 设 `--travel-bg: url(assets/chapter-0N.jpg)`，进图确认弹层显示目标章节氛围图（CSS 用渐变遮罩叠底）。
- `render.js renderEquipment`：12 槽位全部插入 `<img class="slot-icon" src="assets/equip-{iconKey}.png">`（左右手镯/戒指共用一张）。
- `render.js renderInventory`：背包格图标按 `item.slot` 映射（消耗品/货币/材料/部位；左右共用）。
- `index.html`：首领立绘 `<img>` 补 `id="bossPortrait"`。
- `game.css`：新增 `.slot-icon` 样式（100% 覆盖格内）、`.travel-confirm-box` 背景引用 `--travel-bg`。

## 踩坑与经验

1. **Boss 立绘文件名必须与 `boss.name` 完全一致（中文）**：renderBoss 用 `assets/boss-${boss.name}.jpg` 拼接，旧首领裂碑领主原名只有 `boss-liebei.jpg`，直接接会导致头像 alt 文本兜底。解法：复制一份中文名文件，命名规则统一，`onerror` 仅作兜底。
2. **image_gen 短链下载偶发 `RemoteDisconnected`**：不是素材问题，urllib 4 次重试 + sleep 2s 即可，重试后全部成功。
3. **同一 prompt 系列批量生成**：手镯图标（双环绞丝）被生成成戒指形态、腰带/靴子带浅灰底——AI 对「手腕环形饰品 vs 戒指」区分度有限。因手镯/戒指同为环形、展示尺寸小，先接受，后续可单独重生成。
4. **装备图标裁边 4%**：生成图边缘常有装饰性细边框（金色线框），裁掉后再缩 512 更干净；Boss 立绘裁 3% 去四角题字留白。
5. **旅行弹层背景用 CSS 变量 + 渐变遮罩**：`background: linear-gradient(..., rgba(...)), var(--travel-bg) center/cover`——图片天然叠暗色渐变，文字可读性不受影响。
6. **headless 截图验证旅行弹层**：chromium 无交互键，用静态测试页复制弹层 DOM + 设 `--travel-bg` 变量验证 CSS 生效，测完即删（测试页中文 OCR 乱码是 headless 缺 CJK 字体，正式游戏无此问题）。
