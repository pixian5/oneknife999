## 第零步：环境搭建（首次，约 10-20 分钟）

```bash

node -v

# 2. 克隆仓库（gitcode 在国内云电脑更快，GitHub 备用）
git clone https://gitcode.com/laotongtian/oneknife999.git
cd oneknife999
# 若 gitcode 失败：git clone https://github.com/pixian5/oneknife999.git

# 3. 依赖（约 200MB，含 playwright）
npm install

# 4. Playwright 浏览器（约 150MB，仅首次）
npx playwright install chromium

# 5. 关键环境变量：本项目测试默认驱动系统 Chrome，云电脑没有——必须切到自带 chromium。
#    写进 shell 配置（~/.bashrc 或 ~/.zshrc），每次新终端都生效：
export ONEKNIFE_CHANNEL=chromium

# 6. 验证基线：159 个单测必须全绿，否则环境有问题，先排查再开发
npm run verify
```

（用户 AGENTS.md 里可能已有），配置 `git remote set-url` 或 credential helper。
拿不到就只本地提交，并在汇报里说明。

**注意**：仓库 `.git` 约 226MB（含 171MB 美术素材），克隆需要几分钟属正常，不要中断重试。

   → balance-sim 经济模型 → 战斗深度（施法硬直）。

   实现与设计冲突时，如实标注偏差并记录「待对齐」，不要静默偏离——
   项目里已有两处这样的诚实偏差（精英词缀未实现、套装 2/4/6 vs 设计 3/5/8）。
3. **实现**：代码中文注释；纯逻辑下沉独立模块（参照 combat/skills/drops/endgame 风格），
   随机数必须可注入以便单测；`docs/16-复核修复记录.md` 记录了历史踩坑。
4. **验证（缺一不可）**：

   - 改了数值/行为 → 非快进探针实测 + noabilities A/B 对照
   - 大改 → `npm run test:ui` + `npm run perf`
5. **文档**：①`docs/年月日-时分-标题-你的模型名.md` 技术记录；②规则类改动写入**分卷**

   ④文档索引登记。
6. **版本**：+0.0.1，满十进一（VERSION、package.json、README 三处同步）。
7. **提交**：中文 commit message，写清动机与验证结果；推送双远程（凭据见上）。

## 铁律（违反会真实翻车）

1. **不要用 fast 模式测行为与难度**。`?fast=1` 伤害 ×25，怪被秒杀，被动来不及触发。
   难度数据只能来自非快进探针。
2. **不要凭感觉调难度数值**。必须 A/B 对照分清真因。
3. **不要动 `spawnTier` 分段**（maps.js：章内前 5 关用档位 0-5、后 5 关 0-8）。
   取满 9 档会让第 15 关死亡中位数从 1 涨到 5——实测过的。改它必须重跑探针。
4. **不要跳过 Prettier**。批量正则改写后 `verify` 必挂——曾误伤过 `ENHANCE_RULES.rates`
   （同为单行数组）。改完先格式化再单测。
5. **无头浏览器一律走 `ONEKNIFE_CHANNEL=chromium`**（云电脑没有系统 Chrome；
   macOS 本机才是默认 chrome 通道——不要把云电脑的配置带回本机，反之亦然）。
6. **perf 基线云本不可比**。云电脑是软件渲染，`npm run perf` 的绝对帧率与 p99
   与 macOS 本机（6000+ fps / p99 1.2ms）差一个数量级。跑门禁用：
   `ONEKNIFE_PERF_P99_MAX=12 npm run perf`——**over20ms 长帧 = 0 仍是硬指标**，
   p99 只看趋势不比绝对值，汇报时注明云环境。
7. **不要重写 git 历史**。`.git` 226MB 的瘦身需 `git filter-repo`，破坏性操作，
   必须用户单独确认。
8. **下载大文件前告知用户**（npm install、playwright 浏览器、克隆都已列在环境搭建里，
   除此之外新增下载要先说明体积）。
9. **探针耗时预期**：非快进探针每关 5-10 分钟真实时间，跑三关二十分钟以上是正常的，
   不要中途判定卡死。

## 项目速查

- 架构：`game/src/` 18 个 ES Module。纯逻辑层（combat/skills/drops/shop/feedback/
  monster-abilities/endgame，随机可注入可单测）与状态层（main/runtime/render/input）分离。
- 状态机：`runtime.js` 的 `state` 是唯一全局；存档 v4（`persist.js`，迁移表驱动）。
- 行为系统：`monster-abilities.js`——8 攻击形态 + 19 被动 + 2 亡语，
  `resolveAbilities` 按 suffix 匹配章节前缀名，106 种怪零遗漏（单测守着）。
- e2e 接口：`window.__ONEKNIFE_E2E__`（快照含 attackShape/passives/shield/guideStep/
  difficulty/bestiaryCount）。URL 参数：`?e2e=1` 测试模式、`&fast=1` 快进、
  `&noabilities=1` 关闭行为。
- 探针环境变量：`ONEKNIFE_PROBE_CLASS`（warrior/mage/taoist）、`ONEKNIFE_PROBE_STAGES`
  （关卡号）、`ONEKNIFE_PROBE_RUNS`（默认 3 取中位数）、`ONEKNIFE_URL`（换 noabilities）。
- 素材：`game/assets/` 543 文件 171MB。动作帧 `monster-full-{名}-{idle|walk|attack|hit}.png`、
  `player-full-{class}-{action}.png`，渲染层三级回退（动作帧→静态立绘→几何图形）。
- 文档：`docs/README.md` 分卷索引与冲突优先级；`文档索引.md` 全量索引；
  新文件命名 `年月日-时分-标题-你的模型名.md`。
- 验证债清单：法师/道士未实测、精英八词缀未实现、深层复用地形、图鉴无奖励、
  20 张兜底图未透明化、60 张地图素材未接入、移动端未真机验证。
