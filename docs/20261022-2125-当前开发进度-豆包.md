## 一、玩法内容（命中 0.2.4「下一步待实现」P1/P2 多项）

### 1. 装备系统扩展（docs/03，P2#1）

- **3 部位 → 12 部位**：武器 / 头盔 / 项链 / 衣服 / 左手镯 / 右手镯 / 左戒指 / 右戒指 / 腰带 / 靴子 / 勋章 / 玉佩（`config.js` 的 `EQUIPMENT_SLOTS`，含固定生命加成与中文标签）。
- **强化 +1~+15**（`ENHANCE_RULES` + `enhanceQuote` 纯函数）：+1~+5 必成，+6~+8 成功率 70%，+9~+12 为 40%，+13~+15 为 20%；失败不降级、不销毁；+10 起失败积累祝福值，满 100 下次必成；金币成本 = 70 × 1.5^目标等级，+8 起额外消耗 1 件材料类物品。
- **词缀**（`AFFIX_POOL` + `rollAffixes`）：主属性（攻击）/ 生存（生命、防御）/ 资源（恢复）四类，0~2 条、同组不重复，数值随掉落者等级缩放；随机数由参数注入，可单测复现。
- **有效战力**：`effectiveItemPower` = 基础 power × (1 + 8%×强化等级) + 攻击词缀；`equipmentHpBonus` / `equipmentDefenseBonus` 供生命与承伤公式使用；`combat.js` 的 `computeDamage` 改按有效战力计入，`runtime.js` 的 `equipmentHp` 改为 12 部位汇总。
- **生成图 12 槽位掉落轮转**（`maps.js`）：除武器/项链/战靴外，每关再按 9 个轮转槽位滚动掉落两件（前一件紫色、后一件蓝色），96 张生成图覆盖全身 12 槽位。

### 2. 技能升级（docs/02，P2#2）

- `SKILL_UPGRADE`：每级 +6% 技能倍率、上限 10 级、每升 1 级得 1 技能点；技能结算按 `skillLevels` 放大倍率。
- 升级发放技能点（`main.js` 升级结算处）；`K` 键或右上角「技能」按钮打开弹窗，面板展示旧值 → 新值与升级按钮；升级按钮与关闭按钮事件委托绑定。

### 3. PK 单机演示（docs/05，P2#5）

- `PK_RULES`：Lv.20 前不能主动攻击玩家；击杀白名武者 +100 罪恶值、红名阈值 300；罪恶值只在危险区击杀普通怪时下降（每只 -2），安全区挂机不下降；红名死亡掉落 1 件穿戴装备。

- HUD：罪恶值胶囊（红名显示红色）、击杀/死亡/通关统计行；`runtime.js` 新增 `isRedName`。

## 三、验证结果

- `npm run verify`：语法 + Prettier + **57 个单测全部通过**（0.2.4 为 49，新增 8 个：装备 6 + 存档迁移/归一 2）。
- `npm run test:ui`：桌面 1440×900 / 移动 390×844 / 窄屏 360×640 三视口冒烟通过（含虚拟摇杆拖拽）。
- `npm run test:ui:regression`：HUD 静止帧不重建、首领倒计时递减、拾取后面板按需刷新、大写键移动——全部通过（存档已按 v4 构造）。
- `npm run perf`：平均 **5470 fps**、p95 0.5ms、p99 0.8ms、最差帧 33.8ms（一次性 1 帧超 33ms，非持续）。较 0.2.4 基线（6527 fps / 最差 5.5ms）平均帧率下降约 16%，主要来自新增的怪物 AI 逐帧计算、12 部位装备网格与任务链/统计渲染；p99 仍远低于 16.7ms，暂无需分层缓存。
- `npm run test:e2e`：**战士百图 100/100 通过、Lv.41、累计死亡 23 次（单关增量均在守卫阈值内）**；含 v2→v4 迁移、重置清三代、装备资产自动保存、损坏存档回退、每关经济/死亡断言，以及旅行确认弹层适配。
