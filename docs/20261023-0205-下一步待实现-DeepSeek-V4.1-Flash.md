## P1（建议按顺序推进）

### 1. 技能语义对齐（最高优先）

问题：技能描述与实现不符，四个技能实际只是倍率差异，Build 感弱。

- 破甲斩：命中后目标防御 -15% 持续 4s（新增 `armorBreak` 字段，`computeDamage` 读取）。
- 震地冲：向目标位移 140px、击退并短暂无敌 0.2s。
- 召唤骨卫：生成 12s 实体骨卫（40% 攻击、跟随、自动索敌），而非一次性伤害。
- 生息法阵：4s 内每秒回 8%，离开法阵失效。
- 法师穿透：沿锁定方向命中直线上最多 3 个目标。

验收：新增技能语义单测；`npm run balance` 复跑（三职业全通、无单关死亡 >3）；百图 e2e 复跑。

### 2. 怪物攻击前摇与可视化

- 普攻 0.45s / 首领 0.6s 前摇，前摇期间显示红色蓄力环；脱离范围即落空。
- 用 `attackCooldown`（普攻 1.2s / 首领 0.9s）替换当前每帧随机判定。
- 风险：改变承伤节奏，必须复跑 balance-sim 与 e2e 并记录死亡数变化。

### 3. 金币消耗出口（城镇杂货商）

- 药水 30 / 回元露 45 / 黑铁矿石 60 金币，词缀重铸 150 金币/次。
- 复用现有弹窗样式，交互键可在键位设置中改。
- 目标：金币、材料、印记形成闭环，解决「越攒越多」的空转感。

### 4. 拾取与掉落表现

- 自动拾取开关（默认开，仅金币/药水/材料），装备保留手动确认。
- 品质光柱（白/蓝/紫/金）+ 稀有掉落屏幕边缘提示。
- 背包满时掉落保留地面并高亮，不静默丢失。

### 5. 新手引导（前 3 分钟）

- 三步遮罩：移动 → 锁定并普攻 → 拾取与背包。
- 写入 `oneknife999-tutorial-v1`，设置内可重看；仅新档首次触发。

### 6. HUD 减负

- 760px 以下默认折叠「战场记录 / 任务链」为一行摘要，点击展开。
- 保留「当前关卡 / 装备 / 背包 / 目标」四块核心信息；新增折叠交互用例防回归。

### 7. perf 门禁化

- 阈值 `p99FrameMs ≤ 4ms`、`over20ms = 0`、`avgFps ≥ 1000`，纳入 CI。
- 基线：0.3.3 平均 3887 fps / p99 1ms / 最差帧 9.6ms。
