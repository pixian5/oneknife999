## 生成与处理

- `image_gen` 13 批 × 2 张生成 24 张素材，统一「传奇页游暗金风」：深褐暗红渐变底、鎏金描边、主体发光、无文字。
- 坑：btn-skill / btn-settings 两张被 AI 生成成「带一排功能图标栏的界面截图」，PIL 裁中央 62% 去装饰条后为纯徽章。
- 特效素材（fx-arrow / fx-beam）为黑底，PIL 亮度抠图（RGB 和 <95 透明 + 羽化）转透明；光柱为全幅光效（主体占比 100% 正常）。
- 全部 PIL 裁边缩至 96-128px 落地 `game/assets/`。

## 接入点

- `index.html`：10 处 `section-icon` 改 `<img>`；7 个顶栏按钮文字前插 `btn-*.png`。
- `game.css`：`.section-icon` / `.btn-ico` / `.avatar-img` / `.shop-good-ico` / `.currency-ico` 样式。
- `render.js`：玩家头像 `avatar.innerHTML = <img player-{classId}.png>`（替代 glyph）；金币/印记 HUD 前插货币图标；杂货商商品改 `goods-{id}.png`（material 映射 ore 图）；重铸行改 `equip-{slotKey}.png`；`drawGuideArrow` 程序化三角形改为 `fx-arrow` 贴图（未就绪回退三角形）；`drawDrop` 叠加 `fx-beam` 光柱（0.4 透明度）。
