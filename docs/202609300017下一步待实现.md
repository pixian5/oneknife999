## 四、遗留问题与风险（本轮发现）

1. `pointOnPath`（`game/src/geometry.js`）只支持两段贝塞尔路径：单段路径在 progress > 0.5 时会返回 NaN。当前所有地图路径都是两段（14 个数值），未触发；共享给服务端或新增单段路径前需要加保护。
2. 快进验收（`fast=1`，25 倍伤害）只证明百图结构可达，**不代表真实速度下的数值平衡**；正式平衡必须用真实速度模拟，不能用快进结果替代。
3. `.test-artifacts/`（截图与 e2e 日志）已加入 `.gitignore`，不进入版本库。
4. 百图 e2e 全量回归耗时较长（本机约 30 分钟），已改为「push 只跑校验 + UI 冒烟、百图回归手动或每周触发」的分层策略。
