# 立绘实心重抠与血条头顶（豆包）— 0.4.7

- 时间：2026-10-25 09:05
- 触发：用户反馈 0.4.5 抠图「抠得过分，人物野怪内部被抠走成空心，应实心；血条应放头顶而非人物中心」

## 问题根因

0.4.5 的 PIL 四角种子 BFS 抠图对暗色系怪物立绘失败：立绘主体（暗绿僵尸、暗灰侦察者等）与暗色背景**同色调渐变**，基于「背景色差」的手工算法无法区分主体与背景——

- 旧算法（edge_tol=34）：沿背景渐变边缘扩散时穿透主体内部轮廓，抠出**空心**（用户所见问题）；
- 本轮尝试的种子色差放大 / 梯度约束变体：暗色主体整体被误判为背景，主体占比掉到 1.5%–6%（腐毒僵尸 5.6%、灰烬侦察者 6.2%、赤牙猎犬 18.6%），即「实心算法」把整只怪抠没了；
- 梯度墙（Sobel 幅值 >110 停止扩散）：主体占比 1.5%–5.0%，更差——立绘背景并非均匀渐变，含岩石/烟雾纹理，与主体同样低梯度。

**结论**：色差类算法全部证伪，必须用显著性检测（不依赖背景颜色）。

## 解决方案：rembg u2net 显著性抠图

- `pip install rembg onnxruntime`；u2net 模型 176MB 首次自动下载（约 6s），CPU 推理 512px 每张约 7s。
- 对 31 张立绘全部重抠：`player-full-{warrior,mage,taoist}` ×3（高 200）、`monster-full-{16 怪名}` ×16（高 160）、`boss-full-{12 名}` ×12（高 256），裁剪包围盒 + LANCZOS 等比缩放到目标高。
- 效果（绿底合成验证）：腐毒僵尸主体占比 5.6%→48.7%、灰烬侦察者 6.2%→59.7%、赤牙猎犬 18.6%→86.1%、裂脊尸卫 67.1%、枯骨游魂 50.7%、玩家战士 73.8%、幽冥鬼帝 68.0%、裂碑领主 76.4%——**全部实心完整**，玩家金甲红披风火焰长刀、腐毒僵尸青绿铠甲短剑、灰烬侦察者兜帽枪械、幽冥鬼帝骷髅黑袍权杖均完整保留。
- 教训：AI 生成的角色立绘背景常与主体同色调（暗色场景 + 环境纹理），任何背景色差算法都不可靠；显著性检测（u2net/isnet/bria-rmbg）是唯一稳定路径。bria-rmbg 2.0 模型 1.02GB 曾在沙箱重置中丢失，u2net 176MB 更轻量可靠。

## 血条/名牌锚定头顶

- `render.js drawNameplate`：名牌 top 从「贴图中心上移半高」改为「脚底 - 贴图高 - 间距」（怪物 `footY=y+radius*0.55`、Boss `y+radius*0.9`，间距怪物 36 / Boss 44）。
- `render.js drawPlayer`：玩家血条 top 从 `y-56`（压头部）改为 `y+24-112-8`（脚底 - 贴图高 112 - 间距 8）。
- 浏览器验证（autologin 注入 Lv.5 战士 + Playwright canvas 元素截图）：无任何资源 404；玩家全身实心金甲红披风、怪物实心魔物形象、血条与名牌均在贴图头顶（黑面板 + 绿血条位于怪物身体上方）。

- 浏览器：贴图资源零 404；三张特写确认玩家/怪物/Boss 实心立绘 + 血条头顶。
