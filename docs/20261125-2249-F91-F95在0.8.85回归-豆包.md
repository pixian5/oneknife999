## 3. 操作陷阱：`abyssBest` 不能高于当前起始层

第一次运行把 `currentMapId=abyss-F91` 与 `abyssBest=95` 混用，F91 完成后按 T，`enterNextAbyss` 走 `Math.max(abyssFloor, abyssBest)+1`，直接跳到 `abyss-F96`，导致 F92–F95 没有测到。日志为 `/tmp/f91-f95-085.log`。

修正为 `abyssBest=91` 后重新从 F91 起跑，才得到本文 5 层结果。回归夹具必须满足：

- `abyssBest` 等于当前起始层，或至少不高于当前层；
- `currentMapId`、`abyssFloor`、`abyssBest` 三者一致；
- 当前层 `visitedMaps=false`、`mapProgress` 为空，才能拿到首次进入 +1 并正常按 T 推进。
