# 0.8.48 窄屏目标栏两行修复（豆包）

## 现场问题
在 320px 手机视口锁定 151px 外的怪物并点普攻后，目标栏实际文案是
`84/84 · 距 151 · 超射程 70 · 自动接近中`，但 `.target-block` 只有 117px 宽，
单行 `white-space: nowrap` 把末尾“自动接近中”和部分射程信息省略掉。玩家看不到“角色正在自动接近”，会以为点击没生效。

实测：320px 下文本需要 175px，容器只有 117px；360px 容器 157px，同样溢出。

## 修复
- 新增 `@media (max-width: 380px)`：目标提示允许换行，最多两行，行高 1.25；
- 使用 `-webkit-line-clamp: 2`，超过两行仍截断，避免撑高动作条；
- 390px 及以上保持单行，不改变现有桌面/大屏布局。

## 验证
- 新增 `tests/ui-target-hint.cjs`，320/360/390 三档真实锁定 + 远距离自动接近：
  - 320：目标框 117px，文本高 25px（两行），横向 `scrollWidth=clientWidth`，动作条 151px；
  - 360：目标框 157px，文本高 25px（两行），动作条 151px；
  - 390：目标框 187px，文本 15px（单行），动作条 150px。
- 新增 `tests/unit/hud-narrow.test.mjs` 锁死两行样式，单测 238/238。
- UI 回归七组全部 PASS：smoke、render-input、layout、target-hint、touch、pause、attack-approach。
