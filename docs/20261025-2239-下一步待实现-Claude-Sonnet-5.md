## P0：承接本轮（铭牌 / 可读性）

1. **铭牌防重叠布局**：怪群贴脸时铭牌仍会互相压（720 样本最差 57.7%）。可选方案：按屏幕 x 分桶做简单避让（同列铭牌纵向错开固定 8px 台阶），或对非目标怪只显示血条不显示名字。代价是铭牌位置会随邻怪变化轻微跳动，需要先确认是否接受。

3. **铭牌可读性回归用例**：把本轮的插桩检测固化为 `tests/ui-nameplate.cjs`——对每帧做铭牌矩形与后续绘制相交检测，断言「飘字 / 特效环命中铭牌 = 0」，防止后续新增特效再次压住血条。
