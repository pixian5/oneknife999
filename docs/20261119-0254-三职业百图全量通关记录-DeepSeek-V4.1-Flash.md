## 三、复现命令

```bash
# 1) 起服务（仓库根目录）
python3 -m http.server 8080 --directory game &

# 2) 浏览器：本容器 Playwright 1.63 需要 chromium-headless-shell 1243，
#    官方 CDN 对 aarch64 是 fallback 慢链；用 npmmirror 的 1155 arm64 包替代（见 4.2）
D=/root/.cache/ms-playwright/chromium_headless_shell-1243/chrome-headless-shell-linux-arm64
ln -sf "$D/chrome-linux/headless_shell" "$D/chrome-headless-shell"

# 3) 单职业百图（战士）
ONEKNIFE_CHANNEL=chromium \
ONEKNIFE_URL='http://127.0.0.1:8080/?e2e=1&fast=1' \
ONEKNIFE_CLASSES=warrior ONEKNIFE_RUNS=1 ONEKNIFE_RESUME=1 \
node tests/e2e-100-shots.cjs | tee /var/log/e2e-100.log

# 4) 双职业并发（法师 + 道士）
ONEKNIFE_CHANNEL=chromium \
ONEKNIFE_URL='http://127.0.0.1:8080/?e2e=1&fast=1' \
ONEKNIFE_CLASSES=mage,taoist ONEKNIFE_RUNS=2 ONEKNIFE_CONCURRENCY=2 ONEKNIFE_RESUME=1 \
node tests/e2e-100-shots.cjs | tee /var/log/e2e-mage-taoist.log
```

耗时参考：单职业（1 并发）约 **50 分钟**；双职业（2 并发）约 **70 分钟**（并发下每关从 ~21 s 变 ~37 s，CPU 是瓶颈，不是游戏）。

## 四、本轮环境坑

### 4.1 容器又重置了一次（第三次）

`/opt/oneknife999`、8080 进程、`/opt/oneknife-start.sh` 全消失，`/root/.cache/ms-playwright` 也被清空。按 `scripts/container-deploy.sh` 重建后继续。**再次验证：只有 push 到远端的提交与外部实例能留到下轮。**

### 4.2 Playwright 1.63 的 headless shell 在 aarch64 上装不上

- `npx playwright install chromium --only-shell` 从官方 CDN 拉 `153.0.8010.12` 的 `linux-arm64` fallback 包，实测 **约 47 KB/s**（114.7 MB 要 40 分钟），中途失败。
- `@sparticuz/chromium` 能装（走 npm 镜像 12 s），但解压出来是 **x86-64**，aarch64 直接 `Exec format error`。
- 华为云镜像 `mirrors.huaweicloud.com/playwright/...` 返回 SPA 404 页，不可用。
- npmmirror 的 `builds/cft/153.0.8010.12/` **只有 linux64**，无 arm64；但 `builds/chromium-headless-shell/1155/` 有 `chromium-headless-shell-linux-arm64.zip`，**21 MB/s 下载 102 MB 只用 5 秒**。
- 落地方式：解压到 `chromium_headless_shell-1243/chrome-headless-shell-linux-arm64/`，把 `chrome-linux/headless_shell` 软链为期望的 `chrome-headless-shell`，补 `INSTALLATION_COMPLETE` 标记。Playwright 1.63 驱动 Chromium **133** 跑完全部 300 关次，零协议错误。

### 4.3 目录枚举接口的坑（npmmirror）

`registry.npmmirror.com/-/binary/playwright/...` 返回 JSON 目录；`cdn.npmmirror.com/binaries/playwright/...` 对同一路径 404。排查时先列目录再拼文件名，别凭印象拼 URL。
