# 0.8.43 真人操作层修复：锁定命中区、射程反馈、首杀保底掉落

- 时间：2026-11-20 17:18
- 版本：0.8.42 → 0.8.43
- 依据：`docs/20261120-1533-真人试玩手感与阻断问题-豆包.md` 的真人试玩记录
- 原则：只修“玩家看得见、按得着”的操作层，不动职业数值与关卡结构

## 改了什么

### 1. 点击锁定改为“立绘胶囊”命中

旧逻辑：`distance(point, entity) < entity.radius + 22`，只覆盖脚底约 30px。怪物立绘是“脚在实体坐标、身体向上延伸”的画法，点胸口/头部会落到实体上方几十像素，被判成点地走位。

新逻辑（`game/src/input.js` `entityClickHit`）：从脚底到 `spriteHeight(entity) * 0.62` 画一条竖直胶囊，横向容差 `radius + 32`。点立绘任何部位都能锁定；悬停可锁定目标时画布指针切成手型。

### 2. 把普攻射程画出来

- `game/src/render.js` 新增 `drawAttackRange()`：角色脚下画射程圈。无目标时极淡；锁定且在射程内为青色实心圈；超出射程转为红色，并向目标画一条红色虚线。
- 目标栏补距离：`132/132 · 距 92 · 超射程 70`。目标栏宽度 150→176px，避免被截断。
- `normalAttack` 无目标时报告最近敌人距离：`最近的 腐烬矿工 距离 234（射程 70），先靠近`；超射程时提示 `正在接近 X：距离 234，进入 70 内才出手`。

### 3. 首杀保底掉落 + 刷新后补引导补给

- 新手引导第 3 步要求拾取，但普通怪掉落率只有 42%。现在 `guideStep === 3` 的首次击杀至少掉 1 件（`guideKillDrop` 只触发一次）。
- 地面掉落不跨会话保存：若玩家在引导第 3 步刷新，读档时在角色右侧 70 距离补一瓶“回元露”，走近自动拾取即完成引导。

### 4. 装备槽改为两段式强化确认

旧版单击装备槽直接扣金币强化，玩家想查看装备时会误触。现在第一次点击只弹报价（部位、+N、消耗、成功率），按钮高亮 3 秒；3 秒内再点一次才真正执行。空槽点击提示“该部位还没有穿戴装备”。

### 5. 普通怪重生 11–20 秒 → 28–45 秒

刚清掉的怪十几秒就站起来，会让“清剿 1/8”读起来像没生效。首领 42 秒、NPC 90 秒不变。

## 仍需注意

- 目标栏在 1280×960 下已能完整显示；更窄视口仍需按 0.8.14 的窄屏规则复核。
- 装备槽两段式确认的 3 秒窗口是固定值，若玩家反复误触仍可能连点成功，后续可改为“确认按钮独立渲染”。
- 重生时间拉长会降低刷怪密度，深层的刷装备节奏需要再跑一轮数据确认。
