# 0.8.53 首领战冻结小怪重生（豆包）

## 真人试玩现场
跑回首领区后，先把身边 4 只小怪清掉，目标卡从「2 只」降到「0 只」。开始打首领后，28–45s 的重生周期又把 1–2 只小怪塞回首领脚下，目标卡在 1/2 只之间来回跳。

结果：首领从 900 打到 831，玩家连续死亡到第 8 次；每次刚打掉一点血就被小怪围住。

## 修复
`updateEntities` 先取当前存活首领，判断 `bossFight = boss.aggro || boss.hp < boss.maxHp`。首领交战中，首领出生点 260px 内的普通怪尸体不再递减 `respawn`，等首领死亡或脱战后自动恢复倒计时。首领满血且未仇恨时不影响正常刷怪。

## 验证
新增 `tests/ui-boss-trash-hold.cjs`：
- 把首领设为受伤/仇恨，选一只 220px 内普通怪，`alive=false, respawn=0.12`；等 320ms 仍保持死亡。
- 把首领血量回满、清除仇恨，再等 320ms，小怪恢复复活。

实测 PASS（裂脊尸卫）。`npm run verify` 241/241。
