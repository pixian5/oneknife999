# 0.8.80 地图威胁与专属精英

- 版本：0.8.80
- 日期：2026-11-24 01:45（CST）
- 模型：豆包
- 上一版：0.8.79（地图阵容差异化 + 威胁标签，提交 `56614be`）

## 一、目标与边界

0.8.79 已经把矿尘 / 灼热 / 腐雾 / 雷暴 / 潮汐写进 `generatedMap().threat`，但只显示在目标卡和进图日志里，玩家实际感受不到区别。0.8.80 只做两件事：

1. 把五类威胁从“标签”接成**轻量、可读、可躲**的环境机制；
2. 每章 3 张生成图放一名**地图专属精英**，给百图重复阵容一个可记忆的“地名 + 称号”。

明确不做：

- 不新增第 11 章、新职业、新怪物物种；
- 不重做伤害公式、不引入新的随机命中率；
- 不把威胁做成多层叠加的无解惩罚；
- 不改 100 图布局、普通怪数值表与 Boss 数值。

## 二、威胁运行时

新增 `game/src/threat.js`，只放纯规则与计时，DOM、日志、音效留在 `main.js`。

| id      | 名称 | 实际效果                                                                 | 关键参数                                    |
| ------- | ---- | ------------------------------------------------------------------------ | ------------------------------------------- |
| `dust`  | 矿尘 | 野外玩家造成的伤害降到 92%                                               | `damageMult 0.92`                           |
| `heat`  | 灼热 | 每 5 秒扣 2% 最大生命，只压到 1 HP，不直接致死                           | `interval 5`、`hpRatio 0.02`                |
| `rot`   | 腐雾 | 药水与生息法阵回复都降到 72%                                             | `potionMult 0.72`、`healMult 0.72`          |
| `storm` | 雷暴 | 每 8 秒在玩家脚下生成 1.2 秒预警圈，基础伤害 7% 最大生命，按防御正常减免 | `interval 8`、`radius 110`、`hpRatio 0.07`  |
| `tide`  | 潮汐 | 每 7 秒减速 1.6 秒到 65% 移速                                            | `interval 7`、`duration 1.6`、`factor 0.65` |

### 2.1 接入点

- `createState()` 增加 `threat: null`，作为纯瞬态字段，不写入存档。
- `loadMap()` 改为 `state.threat = createThreatRuntime(map.threat)`；**不能把整张 map 传给 `createThreatRuntime`**，函数签名只接收 threat 对象。
- `update()` 在 `updateEntities()` 之后、`updateHealZones()` / `playerDamage()` 之前调用 `updateThreat(dt)`，雷暴危险区当帧进入既有 `state.hazards` 结算。
- `resolveDamage()` 读取 `threatDamageMultiplier()`；矿尘只乘在玩家输出上，不改怪物输出。
- `usePotion()` 的 32% 基础回复乘 `threatPotionMultiplier()`；安全区判定与矿尘共用 `nearTown() || nearWaterWell() || nearRestPoint()`。
- `updateHealZones()` 的 8%/秒法阵回复乘 `threatHealMultiplier()`，同样传入安全区判定。
- 雷暴危险区沿用 `drawHazards()` 的 1.2 秒倒计时：`life=1.2`、`fade=0.5`、`kind="storm"`，不新增第二套地面预警渲染。
- 新增 `state.hazardsSpawned` 与 `recordHazard("storm", "spawned", 1)`，让 UI 回归能确认“雷暴真的落圈”，而不是只读到一个冷却数。

### 2.2 安全区与防连招

- 城镇、水井、篝火统一用 `nearTown() || nearWaterWell() || nearRestPoint()` 判定；安全区内：
  - 灼热不扣血；
  - 雷暴不落圈；
  - 潮汐不减速；
  - 矿尘不降伤害；
  - 腐雾不压药水 / 法阵回复。
- 安全区只抑制事件、不冻结计时；计时到点仍会重置周期，避免“在城镇里把计时器卡到 0，出门第一帧必吃一发”。
- 灼热最低只压到 1 HP，不让玩家在挂机时被环境伤害直接杀死；雷暴是可见预警圈，允许致死。
- 潮汐的 `slowFactor` 取 `Math.min(现有因子, 0.65)`，已有更强减速时不会被“潮汐”反向加速。

## 三、地图专属精英

数据放在 `game/src/maps.js`：

- `EXCLUSIVE_ELITE_SLOTS = [4, 6, 8]`：每章第 5、7、9 张生成图（章节内 slot 4/6/8）放专属精英。
- `CHAPTER_ELITES`：10 章 × 3 个唯一称号，共 30 个；第一章为焦土督军 / 断旗老兵 / 荒道刽子手，第十章为帝陵守灯人 / 金纹殉葬卫 / 终殿执戟者。
- `EXCLUSIVE_ELITE_AFFIXES`：每章 3 套固定双词缀，互斥对已避开（狂怒-追猎、护卫-守财）。
- `generatedMap()` 把专属精英固定落在本图**最高档刷怪点**，写入 `exclusiveElite = { name, affixes, reward: "material", spawnIndex }`。

`createEntities()` 的处理：

1. 先按原规则掷普通精英；
2. 把 `exclusiveElite.spawnIndex` 强制覆盖为 `{ exclusive: true, title: 称号, affixes }`；
3. 普通精英上限改为“总上限 3，其中专属占 1”，即专属 + 最多 2 只普通精英；没有专属的地图仍是 3 只普通精英，不缩减原系统。

展示与数据隔离：

- `entity.name` 仍是基础怪名，保证 `resolveAbilities()`、图鉴键、击杀统计不被 30 个新名字污染；
- `entity.elite.title` 只用于铭牌、目标栏、锁定日志；
- 铭牌等级行显示 `Lv.x ◆ 专属称号`，词缀行显示 `专属 · 词缀A · 词缀B`；基础怪名保留在目标栏 / tooltip / 锁定日志（`称号·基础怪名`），避免 118px 名牌被压缩；
- 目标栏与提示卡显示 `称号·基础怪名`。

## 五、边界与后续

- 矿尘用固定 8% 减伤，不做随机 miss：确定性回归依赖固定伤害序列，随机 miss 会让 258 个单测和长跑统计噪声变大。
- 灼热不直接致死是刻意保守；如果后续实测“深层挂机无代价”，再考虑把 1 HP 保护改成“连续两次灼热才允许致死”，必须单独版本验证。
- 雷暴基础伤害为 7% 最大生命，实际承伤会按防御减免；深层高生命下仍会同步放大；0.8.81 复验 F91–F95 时重点看“雷暴 + 首领技能”的叠加致死率。
- 专属精英目前复用八条通用词缀，没有新增地图专属词缀；先验证“唯一称号 + 固定组合”的辨识度，再决定是否为每章加专属词缀。
- 30 个专属名不进图鉴，避免图鉴总数从 106 变成 136；如果后续要做“精英图鉴”，应单开一个 30 条的子集，不混主图鉴。
