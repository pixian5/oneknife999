## 实际尺寸质检

新增 `tools/cogview_item_preview.py`：

- `总览-16张.jpg`：4×4 总览，带编号、槽位与名称。
- `实际尺寸对照.jpg`：桌面 46px、移动 29px 两行 1:1，以及 92px 的 2× 放大参考。
- `预览清单.json`：16 张最终文件、类别、来源说明与尺寸口径。

结论：

- 46px 下 16 张全部可辨；29px 下靠剪影与主色区分。
- 最稳：01 剑、02 盔、04 甲、07 紫晶戒、08 灰黑印记戒、10 靴、11 紫焰勋章、12 青玉、13 红药瓶、14 黑岩、16 金币。
- 03 链条在 29px 下只剩“金弧 + 紫点”，仍能认出项链，但链条会消失。
- 05 与 06 都是深色护腕/手镯；05 靠金边，06 靠龙鳞与紫眼区分，29px 下差异偏弱。
- 09 是横向带状物，容易被看成项圈/腰封；作为腰带轮廓成立。
- 15 横向卷轴在 29px 下是“黄色长条 + 紫点”，能认出卷轴，但纸色偏亮。

## 质量与限制

- 全部为 JPEG、RGB，无 alpha 通道，右下角“AI生成”水印仍在。
- 模型对“宝石”有强先验：08b 明写黑曜石，仍给紫晶；最后只能把“宝石”整个删掉，改纯黑狼首印记，才拿到区分度。
- “青玉璧 + 无链”会被理解成桌面玉镜：12b 出现底座与散珠；改成“红绳悬空、无底座、无支架、无桌面”后才得到 12c。
- “黑铁矿石 + 块”容易生成方块/科幻箱：14 首轮是青色发光立方体；改成“粗糙不规则碎块、绝非方块/立方体/箱子”后才得到 14b。银矿脉仍被替换成暗红余烬。
- “卷轴”很容易触发卡通描边：15c 仍是白边、亮黄纸；15d 强写“写实厚涂、PBR、不要描边”后风格才统一，但纸面仍偏亮黄。
- 05 的“锁链 + 小锁”两轮都未生成，最终只是厚护腕；文件名已按实际画面注明“锁腕”，但不能误判为有锁。
- 10 更像现代工装靴，不是东方重甲战靴；46px 仍能认出靴子。
