# 0.8.46 Service Worker 缓存新鲜度修复（豆包）

## 现场问题
真实浏览器打开 `http://127.0.0.1:4174/` 时，先出现 0.8.44 旧页面；连续刷新后 HTML 已是新版（有暂停按钮），但职业选择页只剩标题，三张职业卡全空，游戏不可进入。

## 根因
`game/sw.js` 对 js/css 使用 cache-first。导航请求拿到新 `index.html` 后，仍从旧缓存返回 `render.js`；新 `main.js` 已 import `getViewZoom`，模块图加载失败，`setupClasses()` 没有执行。控制台只有 meta 弃用告警，网络面板 js 请求状态为 ok，说明是缓存命中而非 404。

## 修复
- 导航、js、css、webmanifest 全部改为 network-first：`fetch(request, { cache: "no-cache" })`，网络失败才回退 `caches.match`。
- 图片仍保持 cache-first，避免重复下载美术资源。
- 缓存版本升到 `oneknife999-v0.8.46`；`install` 继续 `skipWaiting`，`activate` 删旧 cache。
- 新增 `tests/unit/sw-freshness.test.mjs` 两条源码契约，锁死代码文件 network-first 与导航不复用 HTTP 缓存。

## 验证
`npm run verify` 通过 235/235。真实浏览器连续刷新两次后恢复：旧存档正常加载、职业卡不再空白、暂停按钮可见。
