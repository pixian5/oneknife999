# F121–F130 深层连续层实测与 F126/F127–F130 降档（0.8.92 → 0.8.93）

## 背景

0.8.91 已把 F111–F120 全部跑通并发布。本轮继续用真实键鼠脚本向北测 F121–F130，目标不是单看“能不能通”，而是找出“死亡即满血重建”造成的数值断层。测试目录为 `saves/abyss-runs/20261126-f121-f130-0891/`，使用隔离存档，每层完成立即写 `floor-deaths.jsonl`；不调用 E2E `strike`、不注入战斗数据。

## 0.8.92：F126 双深渊化层

F126 是 `f % 3 === 0` 的双深渊化层。原公式真实键鼠 **397.4s/+44、120 次普通怪循环只到 3/5、`completed=false`**：

- 普通怪：13,365–16,795 HP
- 深渊化：23,747 / 27,643 HP
- 承伤：`abyssMob` 89,282 / 91 次命中，`normalMob=0`，`bossNormal=781`，`bossSpecial=3,279`

脚本在 120 次清怪循环耗尽后仍去打回响，把回响打死但 `kills=3`，形成“提前击破”的假完成。结论：F126 与 F108/F110 同型，墙在普通怪，不在回响。`normalTuning` 只给 F126 加 `{ hp: 0.75, attack: 0.75, defense: 0.8 }` 后：

- 普通怪：10,028–12,582 HP
- 深渊化：17,801 / 20,728 HP
- 真实键鼠：**151.2s/+8、5/5、`completed=true`**，回响 66,060，药水 1→1

## 0.8.93：F127–F130 的两击必死阈值

F126 修好后，F127 仍是 **347.5s/+35**（清怪 +19、回响 +16，回响 73,524），F128 更直接进入死循环：**3/5 时死亡已 +33**，单只普通怪要死十余次，脚本耗尽循环仍未完成。

从页面实体表取到根因：

- 玩家最大生命：**1,583**
- F128 普通怪单次攻击：**956–1,191**
- F128 回响单次攻击：**916**

两次命中即 1,912–2,382 伤害，远超 1,583；玩家每次死亡后 5 只任务怪全部满血重建，形成“打不完一只”的循环。F127 的 1,111 普通怪攻击与 916 回响攻击同型，所以 347.5s/+35 不是操作方差，是阈值问题。

修复不是继续按单层加药水，而是把攻击压到“两击后仍能活着”的区间：

| 层   | 普通怪 `normalTuning` | 普通怪攻击（含深层倍率） |      回响 `bossScale` | 回响攻击（约） |
| ---- | --------------------- | -----------------------: | --------------------: | -------------: |
| F127 | `0.65 / 0.65 / 0.8`   |                  584–722 |                `0.45` |            750 |
| F128 | `0.65 / 0.65 / 0.8`   |                  618–747 |                `0.45` |            750 |
| F129 | `0.65 / 0.65 / 0.8`   |                  622–843 |                `0.45` |            750 |
| F130 | `0.60 / 0.60 / 0.8`   |                  596–717 | `1.25 × 0.65`（不变） |       约 1,300 |

F129 的两只深渊化怪攻击 802/843，仍是两击；这是刻意保留的深层压力，普通怪已回到三击区间。F130 是整十层，普通怪再降到 0.60，压力集中到 142,637 HP 的回响与三阶段，而不是清怪阶段。

代码只改 `game/src/maps.js` 的 `normalTuning` 与 `bossScale`；F126 的 0.75 档、F125 及以前、F130 的整十回响档位均保持不变。单测新增：

- F127–F129 系数必须为 `0.65/0.65/0.8`
- F127–F129 普通怪单次攻击不得超过 774
- F127 普通怪实体 HP 9,334–12,038
- F130 系数必须为 `0.60/0.60/0.8`，普通怪攻击不得超过 717
- F126 仍为 `0.75/0.75/0.8`

## 结论

- F121–F130 已全部真实键鼠完成，`completed=true`、`bossDefeated=true`、`resourceClaimed=true`。
- F126 的墙是双深渊化普通怪 HP 与攻击，0.75 档可通；F127–F129 的墙是“单次攻击 > 791.5”导致的两击必死，0.65 攻击档可通；F130 保留整十回响压力，只降普通怪。
- 深层调参应先算“玩家最大生命 / 单次伤害”的命中次数，再决定 HP 系数；只降 HP 不降攻击，仍会被两击打回营地并触发满血重建。
