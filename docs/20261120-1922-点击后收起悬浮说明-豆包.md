# 0.8.49 点击后收起悬浮说明（豆包）

## 现场问题
真实浏览器里用鼠标点“普攻”后，光标自然停在按钮上。`normal-attack-button:hover .skill-tooltip` 让 226px 宽的说明一直展开，正好压在左下目标栏和操作引导之上。玩家一边打一边看不到目标血量/距离，画面显得很乱。技能键点完也一样。

## 修复
- 普攻/技能按钮 `pointerdown` 时加 `tooltip-suppressed`；
- `pointerleave` / `pointerout`（真正移出按钮）时移除，恢复悬浮说明；
- CSS 对 `.tooltip-suppressed` 强制 `display:none`，不依赖鼠标是否还在按钮上。

- 新增 `tests/unit/tooltip.test.mjs` 两条源码契约。
