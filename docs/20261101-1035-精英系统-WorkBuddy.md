# 0.8.13 精英系统：八条词缀落地、每图确定性精英与四条战斗接入点

- 日期：2026-11-01 10:35
- 执行：WorkBuddy
- 上游：`docs/04-地图怪物与BOSS.md`「精英词缀组合」八条词缀；0.8.12 刚把怪物行为原语的「配置→结算」链路锁进契约测试，本轮直接复用这套原语与守卫。

## 一、为什么现在做

前几轮的优先级一直是「先修正确性、再堆内容」。0.8.12 的契约测试把 18 个被动 × 18 组参数锁死之后，精英系统才有安全的地基——它是行为系统的组合层，不是新造一套战斗逻辑。

同时这是内容深度上性价比最高的一步：100 关的怪物配置早已齐备，缺的是「同一关里出现值得单独应对的个体」。

## 二、八条词缀怎么落地

设计原文有八条，单机版没有组队、没有独立技能实体、没有持久增益 buff，其中三条必须做等价映射。所有差异都写进了 `docs/04` 的「实现落地」表，不让文档再欠账。

| 词缀 | 实现 | 差异 |
|---|---|---|
| 狂怒 | 生命 <20% 时出手闸门 ×0.75 | 无 |
| 护卫 | 首领受伤时 220px 内护卫代受 30%，护卫会掉血会死 | 单机只有区域首领 |
| 回响 | 玩家 3 秒内施法，精英下次命中 ×1.4 | 用余波增伤代替「复制技能」 |
| 分裂 | 死亡生成 2 只 35% 血 / 60% 攻弱体 | 无 |
| 追猎 | 移速 ×1.15，玩家半血 ×1.3 | 「低血目标」只有玩家 |
| 守财 | 离刷新点 >140px 受伤 ×0.6 | 无 |
| 净化 | 清空破势 + 技能冷却 +1.5s，6 秒一次 | 无增益 buff，映射为破势/冷却压制 |
| 毒爆 | 死亡留下半径 80 的毒区 | 与孢子爆裂同机制 |

三个需要新状态的接入点：

- **回响**需要知道「玩家上次施法距今多久」。加了 `state.player.lastSkillAge`，施法清零、每帧累加、上限 99，不依赖真实时钟（`Date.now()` 在 fast-forward 下会失真）。
- **净化**需要频率限制，否则每次普攻都清破势会把玩家打废。给实体加 `purgeCooldown`，6 秒一次。
- **护卫**要在首领承伤时找替身。结算顺序是：先过防御被动 → 守财减伤 → 护卫分摊 → 护盾吸收 → 致命保留。护卫分摊放在护盾之前，因为「替首领挨打」应该先于首领自己的护盾生效。

## 三、生成：确定性 + 兜底

```js
seededRandom(`${map.id}:${index}`)  // mulberry32，种子是地图 id + 刷怪点序号
```

- 每图 1~3 只，概率 12%；**概率全部落空时兜底 1 只**——否则一张图可能完全没有精英，玩家感知不到系统存在。
- 前 20 关 1 条词缀，之后 2 条；互斥对 `狂怒×追猎`、`护卫×守财`（都偏提速或都偏拖时间，同时出现会把反制窗口压没）。
- 位置与词缀在同一张图内固定：玩家重进不换位，e2e 与探针可复现。

强度取「生命 ×1.8、攻击 ×1.15」：击杀成本明显上升，但不会被一发带走。经验与金币 ×2 作为正反馈。

## 四、视觉

- 脚下金色旋转虚线弧（`drawEntity`），远看即可与普通怪区分；
- 铭牌金色描边 + 名字前 `◆` + 上方一行词缀名（`狂怒 · 追猎`），接战前就能读到，满足 04 分卷「0.5 秒以上可读提示」；
- 裂生体不带光环、不带词缀，避免玩家误判。

铭牌宽度保持 118px 不变（只在名字前加 1 个字符），`ui-nameplate` 复跑 0 遮挡。

## 五、测试

**单测 11 条**（`tests/unit/elite.test.mjs`）：哈希确定性、种子序列可复现、互斥不被抽签绕过、词缀条数随关卡、四条数值修正的阈值两侧、强度参数边界。

**UI 回归 1 条**（`tests/ui-elite.cjs`，新增）：用存档直接进 30/45/60/90 关，逐图断言
「精英 1~3 只 / 20 关后 2 条词缀 / 无互斥组合 / 精英生命约为同名普通怪 1.8 倍」，
再用 e2e 的 `strike()` 击杀全部精英，断言分裂体数量 = 分裂精英 ×2、毒爆危险区数量对得上、裂生体不带词缀、无 pageerror。

`strike()` 是新增的 e2e 专用接口（直接扣血走完整 `defeat()` 流程），不参与生产逻辑。

## 七、没做完

- **奖励词缀不影响装备品质**：设计里守财→金币/黑铁、分裂→药材，当前只做了金币/经验 ×2 与守财的金币标记，掉落品质提档留到 v2（要动 `drops.js` 的品质掷骰，风险与收益不匹配）。
- **「同线连续三只相同高威胁词缀 10 分钟冷却」未实现**：单机只有一条刷新线，没有多线并发的语境。
- **精英没有独立图鉴条目**：击杀仍记在基础怪名下，避免图鉴从 106 种膨胀到 106+N。
- **没有精英专属掉落表**：先用经验/金币双倍替代。
