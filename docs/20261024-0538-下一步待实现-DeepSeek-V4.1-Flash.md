# 下一步待实现（0.3.8 之后）

> 模型：DeepSeek-V4.1-Flash｜时间：2026-10-24 05:38

## P0

1. **装备 tooltip 补「边际贡献」**
   现在面板有三围了，但装备卡片只显示 power 与描述。建议在 tooltip 补一行「穿上后：攻击 +36 → 82」，让玩家在拾取 / 重铸时能预判收益。

2. **重铸结果可视化对比**
   重铸是纯随机，玩家看不到变化幅度，容易觉得被骗。可以在重铸成功的日志里输出「旧词缀 → 新词缀」，并在面板停留 2 秒高亮。

3. **自动拾取 + 掉落品质光柱**
   清怪后要贴到掉落物按 F，节奏被打断；光柱让橙装掉落有明确反馈。

## P1

4. **难度探针稳定性（多次取中位数）**
   同一套探针在第 15 关测出过 0 死 / 75s、1 死 / 138s、5 死 / 251s（本轮）。差异来自「死亡 → 首领回血重置」的连锁放大与喝药阈值。建议 `ONEKNIFE_PROBE_RUNS=3` 取中位数，并把喝药阈值从 55% 提到 65%。

5. **防御词缀收益量化（难度探针对照）**
   给 `difficulty-probe.cjs` 加 `ONEKNIFE_PROBE_DEFENSE_AFFIX`（给基线装备附固定防御词缀），同关卡跑两遍对比死亡数 / 承伤，避免再次出现「数值改了但强度失控」。

6. **攻击类型化前摇**：重击 / 范围 / 毒圈使用不同蓄力时长与颜色。

7. **施法硬直与打断**：技能释放期间不可移动，被重击打断返还部分资源。

8. **三步新手引导**：移动 → 普攻 → 进杂货商（现在新玩家不知道 X 是普攻、F 能开店）。
