# 技能图标全套接入（0.4.2）

> 撰写：豆包（doubao）｜2026-10-25 06:41｜版本：0.4.1 → 0.4.2

## 背景

0.4.1 完成主界面/职业/首领视觉升级后，技能栏仍是文字按钮（普攻/技能/药水），与传奇页游观感差距明显。本轮补齐 **14 张 AI 生成技能图标**并接入技能栏，同时补跑 0.4.1 遗留的完整验证闭环。

## 素材（14 张，约 6MB）

| 文件 | 内容 | 接入位置 |
|---|---|---|
| `skill-attack.png` | 双剑交叉普攻 | 普攻按钮 `.attack-icon` |
| `skill-potion.png` | 红色生命药水 | 药水按钮 `.potion-icon` |
| `skill-warrior-0..3.png` | 破甲斩/旋风扫/震地冲/焚天斩 | 战士技能按钮 |
| `skill-mage-0..3.png` | 雷矛术/焰痕地带/烈焰震环/天火陨星 | 法师技能按钮 |
| `skill-taoist-0..3.png` | 蚀骨咒/召唤骨卫/生息法阵/镇魂符 | 道士技能按钮 |

统一风格：深色底 + 暗金描边 + 元素发光（火焰/雷电/风/符光）。用 `image_gen`（seedream_5.0_flash）1:1 生成后下载，PIL 后处理：
- 通用裁边 4%（去金框/白边，主体更满）；
- 焰痕地带裁中央 40%（原图两侧多了 10 个圆形装饰图标）；
- 蚀骨咒裁中央 70%（原图四角有骷髅装饰）。
输出 512×512 PNG。

## 代码改动

- `game/src/render.js` `renderSkills()`：技能按钮模板插入 `<img class="skill-icon" src="assets/skill-${state.classId}-${index}.png">`（classId 已入骨架签名，换职业自动重建）。
- `game/index.html`：普攻按钮加 `.attack-icon`（skill-attack.png）、药水按钮加 `.potion-icon`（skill-potion.png）。
- `game/game.css`：
  - `.skill-button` padding 7px → 30px 6px 7px（顶部留出图标位）；`.skill-icon` 绝对定位左上 23×23、圆角+暗金描边+投影；
  - `.normal-attack-button` 同改为 padding-top 30px + `.attack-icon` 左上定位；
  - `.potion-button` 加 22×22 `.potion-icon`（红光晕投影）。

## 验证（本轮补全 0.4.1 缺口）

- **`npm run verify`：107 单测全绿**（0.4.1 时云电脑无 node_modules 未跑，本轮 `npm install` 后补齐）。
- **`npm run test:ui`：桌面 1440×900 / 移动 390×844 / 360×640 三视口 PASS**。
- **`npm run test:ui:regression`：渲染输入回归 PASS**。
