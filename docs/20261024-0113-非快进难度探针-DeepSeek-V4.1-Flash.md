# 非快进难度探针（0.3.5 → 0.3.6）

- 日期：2026-10-24 01:13
- 模型：DeepSeek-V4.1-Flash
- 版本：0.3.6

## 一、问题：死亡数失去参考价值

百图 e2e 走 `?e2e=1&fast`：玩家伤害 ×25，怪物常在前摇期间就被打死，因此死亡数反映不了真实难度（0.3.4 是 0 次死亡，0.3.5 变成 18 次，两轮都没有改战斗数值）。`balance-sim` 也不走浏览器，且没模拟前摇 / 攻击闸门（见 0.3.4 文档说明），同样测不到真实承伤。

目标是给「数值是否被改坏」一个可复现的闸门：不携带 `fast`，按正式数值结算，抽样中段关卡跑通并给出死亡数与模拟耗时上限。

## 二、实现：`tests/difficulty-probe.cjs`（`npm run test:difficulty`）

### 1. 只快进虚拟时间，不快进伤害

- `page.clock.install()` + `page.clock.runFor(ms)`：用 Playwright 虚拟时钟推进游戏时间，几十秒内跑完十几分钟的战斗，但伤害、怪物前摇、全局出手闸门全部按正式数值结算。
- 与 e2e 的关键区别：URL 不带 `fast` 参数，`computeDamage` 不做 ×25。

### 2. 玩家基线（避免测出「裸装必然死」的噪音）

| 基线 | 取值 | 理由 |
|---|---|---|
| 等级 | 主线曲线（与 e2e `expectedGrowth` 同源） | 到第 N 关时的正常等级 |
| 技能 | 全部技能点平均分配到 4 个技能 | 不点技能的玩家数值明显偏低，会误判难度 |
| 装备 | 本关掉落表里的前 4 件（`maps.js` 的 `map.drops`，用 Node 动态 import 读取） | 捡到当前关掉落的最低配；裸装会被首领反复秒杀 |
| 药水 / 金币 | 6 瓶 / 4000 金币 | 正常玩家的补给量 |

> 裸装实测：第 15 关首领把 Lv.13 战士打死 11~13 次。死亡会 `loadMap` 复活并让首领**满血重置**，于是「死—复活—首领重置」形成死循环，探针永远打不完。这就是必须给基线装备的原因。

### 3. 玩家操作模型

- 近战贴脸、远程停在射程边缘（`approachDistance = 攻击距离 - 12`）。
- 普攻与技能交替（`x` 与 `1~4` 轮换），避免只靠普攻打穿首领。
- 血量 < 55% 喝药（每 4 个循环检查一次）；血量 < 60% 或中毒 3 层时回安全点脱战回血。
- **近战打首领走「一刀一撤」**：首领攻击距离是 `radius + 70 ≈ 104px`，出手后 0.32s 后撤约 70px 就能让 0.6s 蓄力环落空。

### 4. 判定与输出

- 单关：死亡数 ≤ `ONEKNIFE_PROBE_MAX_DEATHS`（默认 6）、模拟耗时 ≤ `ONEKNIFE_PROBE_MAX_SECONDS`（默认 900s），且该关 `completed`。
- 每关输出 `PROBE RESULT stage N <mapId> Lv.x deaths=n seconds=x`，汇总行 `DIFFICULTY PROBE PASS ...`。
- 每 50 个战斗循环打印一次进度（目标血量 / 玩家血量 / 死亡数），卡住时能看出卡在哪。

## 三、踩坑记录（都已在代码注释里标注）

1. **同一页面连跑多关会互相污染**：实测同一 page 先跑第 5 关再注入第 15 关，第 15 关死亡数从 2 次暴涨到 17 次（虚拟时钟累积 + 关卡自动推进 + 存档写回叠加）。改为每关新建 context/page 后稳定在 0~2 次。
2. **最大生命必须用游戏侧的值**：探针一开始自己算 `职业基础 + 等级×18`，漏掉装备生命加成（第 15 关 4 件装备 +135 HP），把「半血」误判成「满血」，撤退逻辑整体失效。现由 `snapshot()` 直接提供 `player.maxHp`（含装备）。
3. **横移躲不掉首领**：首领攻击距离 104px，横移 240ms 仍在范围内，被连续命中。必须后撤（拉开到 104px 外）才能让蓄力环落空。
4. **撤退阈值过高会死循环**：85% 就撤退会变成「撤退—回营地—再进场」的无限循环，把 DPS 测成 0；改成 60% / 3 层毒后才稳定。

## 四、实测结果（默认 warrior，第 5 / 15 关）

| 关卡 | 等级 | 基线装备（战力） | 死亡 | 模拟耗时 |
|---|---|---|---|---|
| 第 5 关 | Lv.6 | 本关 4 件 | 0 | 59s |
| 第 15 关 | Lv.14 | 本关 4 件 | 0 | 52s |

- 法师抽样（`ONEKNIFE_PROBE_CLASS=mage` 第 5 关）：0 死 / 41s。
- 波动区间：第 15 关单跑多次为 0~2 死 / 52~89s，上限 6 死有足够余量。
- 单关真实执行时间约 2~3 分钟（虚拟 60~90s 战斗 + 快照开销），默认两关合计约 4~5 分钟。
