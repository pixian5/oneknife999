# 响应式布局与侧栏信息分级（0.8.14）

> 起因：README 的「下一步」里放着「桌面端 HUD 信息分级基线」，一直没动，因为没有回归测试，说不清「分级」要满足什么。这一轮先把视口矩阵铺开量一遍，结果量出来的问题比预想的多：**不是排版不好看，是按钮跑到视口外、面板内容被静默裁掉、最常见手机尺寸根本没进紧凑布局**。

## 一、基线：量出来的 7 个问题

用 Playwright 在 9 个视口（1440×900 / 1280×720 / 1024×768 / 900×700 / 768×1024 / 430×932 / 390×844 / 360×640 / 320×568）读真实盒模型：

| # | 问题 | 证据 |
|---|---|---|
| 1 | 顶栏按钮跑出视口 | 1024×768、900×700 下「保存」「重置」`right` 超出 `innerWidth`；768×1024 下「导出/导入/保存/重置」四个全在外 |
| 2 | 顶栏按钮被压成竖排单字 | 768×1024 截图里显示为「技/能」「难/度」——`.icon-button` 缺 `white-space: nowrap`，`.top-actions` 缺 `flex-wrap: nowrap`，flex 收缩把按钮压窄后中文逐字换行 |
| 3 | 桌面侧栏静默裁切 | 1440×900 下 7 个面板里 **6 个** `scrollHeight > clientHeight`；`side-panel` 是 `grid-template-rows` + `overflow: hidden`，高度不够就直接切掉。截图里「装备」只剩一条 10px 高的金色边（512×512 图标的顶边） |
| 4 | 最常见手机尺寸没进紧凑布局 | 紧凑分级写成 `@media (max-width:760px) and (max-height:760px)`。390×844、393×852、412×915、430×932 全部高度 >760，走的是堆叠布局：顶栏 125px、侧栏被 fixed 动作条压住、画布只剩 360px |
| 5 | 320×568 整页溢出 | `document.scrollHeight` 591 > `clientHeight` 568，出现纵向滚动 |
| 6 | 手机动作条重叠 | 普攻按钮被压到 36px，「普攻 / 100% 攻击」压在技能条图标上 |
| 7 | 任务链与当前关卡信息完全重复 | 两张卡都在显示「012·遗痕·苍月荒径」「击败 6 只普通怪物 3/6」「首领未破」 |

第 1、3 条为什么一直没被发现：`ui-smoke` 只测 1440 / 390 / 360 三个视口，且只断言顶栏按钮不溢出；侧栏裁切没有任何断言。

## 二、修复

### 1. 侧栏：从「固定行高 + 裁切」改为「自然高度 + 自身滚动」

```css
.side-panel { display: flex; flex-direction: column; gap: 6px; overflow-x: hidden; overflow-y: auto; }
.side-panel > section { flex: 0 0 auto; }
.event-log { max-height: 168px; overflow-y: auto; }
```

原来 `grid-template-rows: auto auto auto auto minmax(66px,1fr) auto` 把 7 个面板硬塞进视口高度，`overflow: hidden` 让「塞不下」表现为「看不见」而不是「可以滚」。改为 flex column 后每个面板拿自己需要的高度，总高超出时侧栏滚动，日志单独限高滚动。

### 2. 面板顺序：首屏给装备

`玩家 → 当前关卡 → 区域导航 → 装备 → 任务链 → 战场记录 → 背包`

装备是玩家最常看的信息（强化、词缀、战力贡献），原来排在任务链后面，1440×900 首屏根本看不到。现在首屏 4 个面板完整可见。

### 3. 区域导航：8 节点 4 行 → 单行横滑

```css
.side-panel .region-list { display: flex; gap: 5px; overflow-x: auto; }
.side-panel .region-node { flex: 0 0 104px; }
```

8 个关卡节点原来占 4 行 × 52px ≈ 240px（侧栏 700px 的 1/3），现在是 90px 一行，为装备与背包腾出约 150px。

### 4. 任务链：删掉与「当前关卡」重复的两行

原来的 `quest-current` 块有「当前任务 · 关卡名」「目标 · 首领状态」「奖励 · 经验」三行，前两行与右侧「当前关卡」卡逐字重复。只保留奖励与经验（任务链独有信息），顺带删掉失去引用的 `bossMark` 与 `entryTitle()` 以及 `.qc-title` / `.qc-goal` 两条死样式——上一轮刚做过「定义了没人读」的审计，不能再往里加。

### 5. 手机：统一形态，不再绑 `max-height`

```css
@media (max-width: 760px) {
  .app-shell { display: flex; flex-direction: column; height: 100dvh; overflow: hidden; }
  .game-layout { flex: 1 1 auto; display: grid; grid-template-rows: minmax(0, 1fr) 96px; }
  .action-bar { position: static; flex: 0 0 auto; }
}
```

关键是把动作条从 `position: fixed` 改成流式，`.app-shell` 变成 `100dvh` 的 flex 容器：顶栏、画布区、动作条各自占一份，不再依赖 `height: calc(100dvh - 58px - 158px)` 这种跟着别处改动就失效的魔法数字。

### 6. 手机：存档四按钮进设置面板

顶栏 9 个按钮在 390px 下必然两行（125px）。存档类操作（导出/导入/保存/重置）是低频操作，移到「设置」弹层里，顶栏只留技能/难度/图鉴/设置/音效五个。设置面板里新增 `.settings-save-row`（桌面 `display: none`），点击通过代理转发到原按钮：

```js
document.querySelectorAll("[data-save-action]").forEach((button) => {
  button.addEventListener("click", () => {
    const source = { export: "exportBtn", import: "importBtn", save: "saveBtn", reset: "resetBtn" }[button.dataset.saveAction];
    if (source) $(source).click();
  });
});
```

不复制逻辑，两条入口永远走同一段代码。

### 7. ≤360px：隐藏按钮图标保顶栏一行

320px 下品牌区 + 5 个按钮（每个 53px）放不进 304px 内容宽，必然换行成两行（73px）。去掉 16px 的按钮图标后每个按钮 32px，一行放下，顶栏 41px。

### 8. 手机动作条：一行 flex → 两行 grid

```
[摇杆] [当前目标] [普攻] [药水]
[———— 怒气条 + 四个技能 ————]
```

原来一行 flex 在 390px 下把普攻压到 36px 并与技能图标重叠；网格把第一行固定成四列、第二行整行给技能，普攻恢复到 54×62。

### 9. 其他

- 手机首领卡从左上角 150px 宽的卡片压成左下角一行（`首领情报` + 脉冲点），避免与右上角「步骤 1/3」卡在 300px 宽的画布上互相遮挡。
- 手机战斗提示去掉 `WASD`（触屏无意义），缩短到一行放得下。
- 761–900px：标题 19px 单行、状态徽章竖排、药水按钮隐藏键位字母。
- 761–1000px：隐藏世界页脚（8 段小字挤成一排读不出来，且首领/出口/篝火信息在画布与侧栏都有等价展示）。

## 三、新增布局回归 `tests/ui-layout.cjs`

9 个视口 × 4 类断言，`npm run test:ui:layout`：

1. **一屏之内**：document/body 无纵横向滚动，动作条不越界；
2. **顶栏**：可见按钮不溢出、高度 ≤40px（拦竖排）、中心点可命中；顶栏看不到存档按钮时，设置面板必须有四个操作；
3. **侧栏**（≥761px）：每个面板 `scrollHeight - clientHeight <= 2`、高度 ≥40px，且滚到底能看到最后一个可见面板；
4. **画布**：宽度 >260px，高度按视口分级（桌面 420 / 平板 420 / 手机 190–360）。

这套断言的价值在第 3 条：它把「面板被裁」从「没人看得见」变成「CI 红」。

## 六、没做完 / 已知取舍

- **手机横滑卡片的裁切是有意的**：`side-panel > section` 固定 96px 高、内容 `overflow: hidden`，所以「玩家卡」下半部分（升级进度条）在手机上要横滑到该卡也看不全。要彻底解决得给每张卡做手机专用精简版，属下一轮。
- **任务链节点仍是纯文字**：10 个节点在小屏下靠 `title` 悬停看剧情，触屏没有悬停。
- **桌面侧栏仍是滚动**：1440×900 下 1223px 内容 / 700px 视口，滚 523px 看任务链与背包。做成 tab 分组需要改状态与大量测试，本轮没动。
- **320×568 画布只有 229px**：顶栏 41 + 标题 40 + 侧栏 88 + 动作条 150 = 319，已接近这个尺寸的物理极限。
