# 下一步待实现（0.8.43 之后，豆包）

- 时间：2026-11-20 17:18
- 依据：真人试玩 + 0.8.43 操作层修复后的遗留项

## 优先（玩家可感知）

1. **移动端触屏复测**：胶囊命中在 9 种视口 / iOS Safari / 微信内置浏览器上是否稳定；右手摇杆 + 左手技能的冲突。
2. **Boss 点击命中**：Boss 立绘 110–210px，胶囊只覆盖到脚上 62%，大体型首领头部可能仍点不到；需要按 `spriteHeight` 全高判定。
3. **设置面板升级**：加 UI 缩放（100/125/150%）和暂停；技能/设置正文 11px 在 1280×960 已偏小。
4. **目标栏窄屏适配**：176px 宽度在 0.8.14 窄屏规则下是否挤压技能栏，需要 9 视口回归。

## 数值 / 节奏

5. **道士深层过强**：拆伤害构成（本体 / 骨卫 / DoT）后给召唤或首领上限一个明确改动，再跑 41–100 真实速度。
6. **重生间隔的刷怪密度**：28–45s 是否让深层刷装备变慢；如需保持密度，可只在深层恢复短重生。

## 工程

7. **射程圈性能**：每帧一条 arc + 一条虚线，低端机需在 perf-probe 里确认无回归。
8. **装备确认窗口可配置**：3 秒写死在 input.js，后续抽到常量并加单测。
9. **真人试玩流程固化**：把“选职业→出营地→锁定→首杀→拾取→开面板”写成浏览器脚本，作为每次发版前的真人路径冒烟。
