# 0.8.52 死亡后立即落盘（豆包）

## 真人试玩发现
首领打到 599/900（67%）后，玩家在首领脚下被灰烬侦察者击杀。页面状态 `deaths` 从 5 涨到 7，但 localStorage 存档还停在死亡 5、血量 229、坐标首领脚下。

原因是 `die()` 只做诊断、回营地、保留首领血量，没有调用 `persistGame()`；下一次落盘要等击杀/升级等事件。玩家死完直接关浏览器，再打开会看到死亡数回退、金币回退，像这段死亡没发生过。

## 修复
`die()` 在 `loadMap()` 回到安全营地、回填红名掉落后调用 `persistGame()`，把递增后的死亡数、复活坐标、金币、经验立即写入 `oneknife999-prototype-save-v4`。

首领当前血量仍不进存档：读档后首领满血。这条限制单独保留，避免把“同图复活保留 bossHp”和“跨会话磨血”混在一起。

## 验证
新增 `tests/ui-death-save.cjs`：选战士后把 hp 置 0，等待死亡结算，断言：
- state 死亡数 +1；
- localStorage 死亡数与 state 一致；
- 金币一致；
- 复活坐标落在 townRect 内。

实测 `deaths=1`、复活 `330,1100`。`npm run verify` 241/241。
