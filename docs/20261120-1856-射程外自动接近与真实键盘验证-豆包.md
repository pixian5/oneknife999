# 0.8.47 射程外自动接近与真实键盘验证（豆包）

## 真实玩家现场
0.8.46 在真实浏览器中，目标距离 90 时点“普攻”：角色会开始移动，但只弹“正在接近 … 距离 90”，走到 70 内不会自动打；提示里的 90 还会一直留着，和 HUD 的“距 13”互相打脸。玩家必须再点一次攻击，手感像按键没生效。

## 修复
- 新增 `player.autoAttackId`：射程外点一次普攻，记录“要打哪只怪”，角色自动接近；进入射程且冷却结束后自动出手一次。
- `tickAutoAttack()` 在主循环 `updateEntities` 之后检查，目标死亡、切换目标、距离仍远都不会误触发。
- 玩家主动点地面、键盘/摇杆移动、暂停、重新选择目标都会清空自动接近意图，手动操作永远优先。
- 删除带固定距离的“正在接近…”toast，避免走位后残留旧数字；目标栏改为显示 `超射程 70 · 自动接近中`，到位或自动攻击完成后自动消失。
- 新增 `tests/ui-attack-approach.cjs`：150px 外点普攻 → 断言自动接近意图、目标栏文案、自动出手扣血、意图清空，并用真实 `keyboard.press("x")` 验证键盘仍能继续攻击。

## 验证
- `npm run verify`：237/237 通过。
- UI 回归：`ui-smoke`、`ui-render-input-regression`、`ui-layout`、`ui-touch-target`、`ui-pause`、`ui-attack-approach` 全部 PASS。

## 真实浏览器复测
- 赤牙猎犬 90px：点普攻后角色自动进入 13px 并打出 151→117，不需要第二次点击。
- 真实键盘 X（Browser Use 用 `hotkey("x")` 注入）可连续击杀 `腐烬矿工`，击杀计数 0/8 → 1/8，并自动拾取 `回元露`。
- `press_key("x")` 在该工具下不派发按键，`hotkey("x")` 正常；这是工具差异，不是游戏键位失效。
