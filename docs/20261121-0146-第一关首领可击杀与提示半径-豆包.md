# 0.8.54 第一关首领可击杀与提示半径（豆包）

## 真人现场

### 提示半径漏报
0.8.53 复跑到首领区时，玩家在 `1805,865`，两只裂脊尸卫距玩家 41/49、距首领 188/189。目标卡仍显示“前往首领区域”，没有提示小怪。原因是 0.8.50 的统计半径写死 180px，而 0.8.53 的首领战小怪冻结区是 260px；两只卫兵刚好卡在 180–260 之间。

### 首领数值
0.8.53 首关首领 `900 HP / 36 攻 / 18 防`。真实 Lv2 无装备战士最好一次打到 831/900（92%），死亡累计 8；本次复测又达到死亡 9。玩家普攻对首领约 24 点，需要 38 次命中；首领 36 点伤害约 11 次打死玩家，没有装备与药水时容错极低。

### 胜利后的补刀
0.8.54 实测击杀首领时玩家只剩 64 HP，首领附近残存小怪继续攻击，玩家在“已通关、前往出口”阶段死亡，死亡数从 9 变 10。胜利结算到手，但体验像“赢了也算输”。

## 修复

1. `objectiveView()` 的小怪统计半径从 180 改成 260，与 `updateEntities` 的首领战冻结区一致；文案从“首领身边”改为“首领附近”。
2. 首关 `裂碑领主` 调整为 `720 HP / 30 攻 / 12 防`，保留 2 阶段与 7 秒裂隙技能。实际击杀用了 3 瓶城镇药水（90 金币/瓶），证明 Lv2 无装备可开荒。
3. `defeat()` 首领分支新增余波清场：首领倒下时，260px 内普通怪直接死亡、刷新 42 秒，不结算经验/金币；260px 外不受影响。避免刚赢就被杂兵补刀。

## 验证

- 真实 0.8.54：从检查点回到首领区，买 3 瓶药，首领从 720 打到 0；目标卡进入步骤 3/3，金币 597，存档 `bossDefeated=true`、`completed=true`、`rewardClaimed=true`，按 T 进入 `pine_forest`。
- `tests/ui-boss-victory-clear.cjs`：把一只小怪放到首领 80px、另一只放到 600px，调用 `defeat(boss)` 后近处死亡、远处存活、`bossDefeated=true`、胜利动作窗口 >0。
- `tests/unit/first-boss-tuning.test.mjs`：锁定 720/30/12 与提示半径 260。
- `npm run verify` 243/243；十三组 UI 回归全绿（含新增 boss victory clear）。
