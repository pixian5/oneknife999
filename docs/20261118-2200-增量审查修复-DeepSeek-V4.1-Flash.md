# 0.8.39 增量审查修复（P1×3 + PWA）

对 0.8.33→0.8.38 的增量代码做审查后修复 4 项，其中 3 项是「配置写了但没人消费」的死代码，1 项是会直接卡死首访用户的 PWA 缺陷。

## 一、烬火章 aggroMult 从未生效（P1）

**问题**

```js
// maps.js:47,55 登记
MAP_DIFFICULTY_OVERRIDES[stage] = { aggroMult: 0.63, ... };
// maps.js:1432 透传
difficulty: { attackMult, hazardMult, aggroMult: difficulty?.aggroMult || 1, ... }
// main.js 消费端仍是常量，且全仓库 grep aggroRange = 0 命中
if (!entity.aggro && canAggro && ... && distToPlayer < 190) entity.aggro = true;
```

0.8.34 宣称的「41–50 入场 1 秒集火」修复完全空转，41 关仍 4 死；后续探针会把「已修」当基线，难度归因失真。

**修复**

- `maps.js` 新增纯函数 `aggroRangeFor(difficulty) = Math.round(190 * (difficulty?.aggroMult || 1))`
- `main.js createEntities` 为普通怪写入 `aggroRange`
- `updateMonsterAI` 进战用 `entity.aggroRange`，脱战按同比例缩放（340/190≈1.79）

**验证**：第 41 关 190→120；未登记关卡保持 190。

## 二、深层「深渊化怪」永远不会刷出（P1）

**问题**

```js
const pick = Math.min(order.length, 5 + ((f - 1) % 3));   // 5/6/7
...order.slice(0, pick).concat(abyssOnly.map(...))        // 深渊怪在索引 pick / pick+1
monsterSpawns: ...([x,y,tier,...]) => [x,y, tier % pick, ...]  // 只能落 0..pick-1
```

布局生成器只产出 0..6 档，取模永远够不到 7/8 ——「每 3 层 2 只深渊化怪（hp×1.6/攻×1.15）」零生效。

**修复**：每 3 层把前两只刷怪点固定落在深渊档位 `pick + index`，其余仍按 `tier % pick`。

**验证**：F3/F6/F9/F12 的 `monsterSpawns` 档位包含 7、8（新增单测「回归8」）。

## 三、裂隙层精英参数被静默丢弃（P1）

**问题**

```js
// main.js:237 传入
forceChance: map.riftFloor ? 0.3 : undefined, affixCount: map.riftFloor ? 2 : undefined
// elite.js:83 签名里没有这两个字段 → 解构忽略
export function rollElite({ mapId, index, monsterCount, order, random, force = false })
const count = order > ELITE_TUNING.singleAffixBefore ? 2 : 1;   // 深层 order=-1 → 永远 1 条
```

**修复**：签名补 `forceChance / affixCount`，用 `?? ELITE_TUNING.chance` 与 `?? order 规则` 保持默认行为不变。

**验证**：`forceChance:1 + affixCount:2` 必出双词缀；默认参数下行为与原来一致。

## 四、PWA 首访后离线永久停在启动画面（P1）

**问题**

```js
const SHELL = ["./", "./index.html", "./game.css", "./manifest.webmanifest"];  // 缺 src/*.js
.catch(() => cached);  // 走到这里 cached 必为 undefined → respondWith(undefined)
```

SW 注册发生在整张模块图加载完之后，首次会话的 21 个 `src/*.js` 全绕过缓存；离线重开时 index.html 能出（壳缓存），但 main.js 取不到 → `#bootSplash`（z-index 99）永久停留。

**修复**

- SHELL 补齐 21 个 `./src/*.js`
- 静态资源 `.catch` 返回 504 空响应兜底；导航分支同样兜底
- `index.html` 增加 8 秒启动画面超时（main.js 未执行时也能撤占位）
- `CURRENT_APP_VERSION` / `CACHE_VERSION` 同步 0.8.39
