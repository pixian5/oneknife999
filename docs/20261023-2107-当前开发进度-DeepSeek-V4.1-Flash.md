## 一、本轮完成：金币消耗出口（docs 优化方案 P0 第一项）

### 1. 新增纯逻辑模块 `game/src/shop.js`

- `SHOP_GOODS`：生命药水 90 金币 / 黑铁矿石 ×1 60 金币 / 词缀重铸卷 200 金币，`effect` 字段决定购买后写回哪个玩家字段。
- `buyShopItem(goodId, { gold })`：商品存在性 + 金币校验，返回 `{ ok, good, price, reason }`，不修改状态。
- `REFORGE_RULES` + `reforgeQuote(item, { gold, scrolls })`：重铸金币成本 = 120 + 40×强化等级 + 60×词缀条数，另需 1 张重铸卷；依次拦截「未穿戴 / 缺卷 / 金币不足」并给出原因。
- `reforgeAffix(item, { level, random })`：纯函数，已有词缀随机重掷 1 条，白板装备新附 1 条，新词缀避开已有属性 key，不修改传入对象。

### 2. 玩法接入

- 玩家新增 `reforgeScroll`（重铸卷数量，默认 0）与瞬态 `state.shopOpen`；换图 / 复活 / 走出城镇均自动收起面板，均不写存档版本。
- 城镇内且附近没有掉落物 / 秘藏 / 场景节点时，**F 键**开 / 关杂货商；F 仍是拾取键，不新增按键。
- `buyGoods`：扣金币 → 药水 / 材料（`stackMaterial` 同名堆叠）/ 重铸卷写回 → 日志 + Toast + 保存。
- `reforgeEquipped(slotKey)`：扣金币与 1 张卷 → 替换穿戴装备词缀 → 飘字 + 日志 + 保存。
- 侧栏新增 `#shopCard` 面板（商品列表 + 已穿戴装备重铸列表），签名缓存（金币 / 卷轴 / 穿戴装备词缀）驱动重建，金币不足或缺少卷轴时按钮禁用并给出原因。
