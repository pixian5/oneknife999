# 0.4.6 地图场景美术：章节氛围图接入战斗底图 + Boss 换阶段震屏（豆包）

- 时间：2026-10-25 08:00
- 版本：0.4.6（前置 0.4.5 全身立绘）

## 背景

全身立绘完成后，战斗画面最大的「廉价感」来自程序化深绿网格地图背景。把 0.4.3 已生成的 10 张章节氛围图（此前只用于旅行弹层）接入为战斗地图底层背景，让灰烬边境/苍月群岛等场景真正进入战斗。

## 本轮改动

1. **地图底层背景（render.js）**：
   - `getGroundLayer` 按 `map.chapter` 加载 `assets/chapter-{NN}.jpg`（`loadSprite` 缓存，NN = 章节号补零），`bgReady`（图片就绪态）加入静态层缓存键——图片异步加载完成后自动重建缓存层，无需手动刷新。
   - `paintGroundLayer(target, map, bgImg)`：背景图 **cover 等比裁切铺满**整张地图（居中），再叠 `rgba(10,15,13,0.66)` 压暗遮罩，保证道路/网格/Boss 状态环/实体名牌可读；图片未就绪回退原 `p.ground` 纯色。
   - 道路、城镇区、水道、网格、地标等原有装饰层全部保留绘制在背景之上。
2. **Boss 换阶段震屏（main.js）**：phase 切换瞬间 `fx.shake=0.32 / shakePower=6` + 红色炸点 `spark(#f16d66, 36)`，配合原有金色火花，增强 Boss 战气势。

- 截图留存 `.test-artifacts/map-bg-chapter01.png`。

## 踩坑与经验

1. **静态层缓存要感知异步资源**：离屏缓存层（groundLayer）按 mapId+dpr 缓存，若背景图异步加载后才就绪，缓存键必须包含 `bgReady`，否则永远画无背景版本。
2. **cover 铺满 + 压暗遮罩**：氛围图是 16:9 而地图是任意矩形，用 `max(mw/iw, mh/ih)` 等比放大居中裁切铺满；底部统一压暗 0.66 让信息层（道路/网格/名牌）优先于装饰层。
3. **换阶段震屏复用现有 fx 系统**：`fx.shake/shakePower` 已有（render 层 translate 抖动），只需赋值即可，不新增机制。
