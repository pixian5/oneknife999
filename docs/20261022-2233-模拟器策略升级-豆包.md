# 模拟器策略升级（2026-10-22 22:33）

> 记录时间：2026-10-22 22:33 · 版本：0.2.8
> 承接 [20261022-2146-真实速度数值复测-豆包.md](20261022-2146-真实速度数值复测-豆包.md)（0.2.6 首轮复测：模拟器策略偏「玩家下限」，战士前期偏难、法师 Boss 慢、后期 0 死亡、强化锁装备）。

## 本轮目标

0.2.6 复测结论之一是「强化锁装备（旧武器强化战力可能超过新白板掉落）」，且模拟器策略偏向保守（就近单杀、不主动换新武器）。本轮把策略升级为贴近真实玩家上限：

1. **换新武器重强化**：武器槽按「+10 强化折算」比较——新武器按 1.8 倍预估有效战力，超过旧武器当前有效战力才换装（避免无条件换装导致过渡期战力低谷，也避免强化锁装备）。
2. **聚怪清怪**：远程职业（法师/道士）优先打「240px 内被其他怪包围」的怪，让范围技能一次命中多只；但仅在目标距离 ≤320px 时生效（一次走位可到达），避免为远处小怪堆长途奔袭。
3. **危险区走位概率**：近战 40% / 远程 80%（原 50%/75%），近战被红圈覆盖率高、需走位回来，远程更易躲。

## 调试中排除的两个无效策略（重要经验）

- **全职业聚怪**：战士（range 70）聚怪深入怪群挨打，死亡 14→30 翻倍；范围技能收益小。修正为仅远程职业启用。
- **无条件换新武器**：新武器基础 power 更高就换，导致过渡期战力低谷（强化重置），法师/道士总耗时 +10/+12 分钟。修正为 +10 强化折算比较。
- 教训：策略升级必须量化「走位/过渡期成本」与「收益」的比值，不能只看单指标（如最终武器战力）。

## 结论

1. **模拟器已贴近「真实玩家上限」**：换新武器重强化 + 近距离聚怪后，最终武器战力全面提升（法师几乎翻倍 119→192），总耗时持平或更优（法师 33→32s），证明装备成长曲线在合理玩家策略下能正常兑现。
2. **数值平衡结论不变**：三职业百图全部可通（卡关 0）、无单关死亡 >3；战士前期（1-40 关）偏难仍可被技能点 + 强化缓解（A 段死亡 7 同旧）；法师单体输出仍最慢（Boss 24s）；后期全职业 0 死亡受 Boss 受击上限 3.5% 保护。**本轮不改任何游戏数值**。
3. **战士死亡 14→17**：换装次数增加（65→73）带来过渡期战力低谷，全部 <3 次/关；真实玩家在「新武器值得练才换」的判断下死亡略增属合理，不构成过难信号。
4. **强化锁装备结论修正**：0.2.6 认为旧武器强化可能锁住新掉落；本轮策略证明「强化可重新打」后玩家会换新武器，装备成长曲线兑现（法师 119→192），无需改数值、无需加「强化继承」机制。
