# 城镇杂货商与词缀重铸（0.3.4 → 0.3.5）

- 日期：2026-10-23 21:07
- 模型：DeepSeek-V4.1-Flash
- 版本：0.3.5

## 一、问题：金币只增不减

百图 e2e 到终局时玩家金币约 22 万，但游戏内没有任何金币出口：强化（+1~+15）会消耗金币，可强化上限只有 15 级且装备迭代快，实际消耗极低。结果是：

- 金币失去意义，任务奖励、金币掉落、连击奖励都没有决策价值；
- docs/07「货币回收与通胀控制」在原型中完全缺失；
- 装备词缀是掉落时随机固化，玩家没有任何「养成到目标属性」的手段。

## 二、方案：城镇杂货商 + 词缀重铸

### 1. 纯逻辑模块 `game/src/shop.js`

| 导出 | 作用 |
|---|---|
| `SHOP_GOODS` | 商品表：生命药水（90 金币）、黑铁矿石 ×1（60 金币）、词缀重铸卷（200 金币）；`effect` 决定购买后写回哪个字段 |
| `buyShopItem(goodId, { gold })` | 校验商品是否存在、金币是否足够，返回 `{ ok, good, price, reason }`，不修改任何状态 |
| `REFORGE_RULES` | 重铸定价参数：`baseGold 120 + enhanceStep 40 × 强化等级 + perAffix 60 × 词缀条数`，另需 1 张重铸卷 |
| `reforgeQuote(item, { gold, scrolls })` | 返回 `{ canReforge, reason, cost, affixCount, scrollNeeded }`，依次拦截「没有装备 / 缺卷 / 金币不足」 |
| `reforgeAffix(item, { level, random })` | 纯函数重掷：已有词缀随机挑 1 条替换，白板装备新附 1 条；新词缀避开装备上已有的属性 key；不修改传入对象 |

随机数由参数注入（`queueRandom` 假随机），价格与重掷结果都能单测。

### 2. 运行层（`main.js` / `runtime.js`）

- 新增玩家字段 `reforgeScroll`（重铸卷数量，默认 0，旧存档缺省不影响读取，无需升存档版本）。
- 新增瞬态 UI 状态 `state.shopOpen`：换图 / 复活 / 离开城镇时自动收起，不写入存档。
- `collectDrops`：城镇内且附近没有掉落物 / 秘藏 / 场景节点时，F 键改为开 / 关杂货商面板。**F 仍是拾取键**，不需要新增按键，也不破坏既有 100 图 e2e 的按键序列。
- `buyGoods`：校验（`shop.js`）→ 扣金币 → 写回药水 / 材料（`stackMaterial` 同名堆叠）/ 重铸卷 → 日志 + Toast + 保存。
- `reforgeEquipped(slotKey)`：报价 → 扣金币与 1 张重铸卷 → 替换穿戴装备的词缀 → 飘字 + 日志 + 保存。
- `update` 每帧检查：离开城镇立即收起面板。

### 3. 界面（`index.html` / `game.css` / `render.js`）

- 侧栏新增 `#shopCard`（默认隐藏），包含：金币 / 重铸卷持有量、三件商品行、已穿戴装备的重铸行。
- 重铸行显示「部位：装备名 +强化」、当前词缀明细、按钮价格；不满足条件时按钮禁用并在 tooltip 给出原因（缺卷 / 金币不足）。
- 面板用签名缓存（金币 + 卷轴 + 穿戴装备 id/强化/词缀）驱动重建，签名不变不重建 DOM。
- 面板放在侧栏内而非全屏遮罩：不会遮挡画布点击，因此 100 图 e2e 的鼠标寻路、`F` 连按都不受影响（这是本轮最容易踩的坑，见下文）。

## 三、设计取舍

1. **重铸卷走独立计数而不是背包材料**：材料是「+8 起强化」的通用消耗，若把卷轴混进材料池，玩家会在不知情时把买来的卷轴用于强化。
2. **白板装备也能重铸**：否则玩家早期打到的装备永远没有词缀，重铸功能等于只在后期可用。
3. **成本随强化与词缀数上升**：避免「拿一件白板装备反复洗词缀」比强化更划算；成本公式（120 + 40×强化 + 60×词缀）对 +10 三词缀装备约 600 金币/次，与后期金币产出量级匹配。
4. **只重掷一条**：保留「装备底子 + 慢慢替换词缀」的养成过程，而不是一次洗满。

## 五、踩坑记录

- **面板不能做成全屏遮罩**：e2e 的寻路依赖 `page.mouse.click(canvas)`，全屏遮罩会吞掉画布点击；同时 e2e 每次攻击后都按 `f`，若 F 在城镇内弹遮罩会持续遮挡。最终把面板放进右侧栏（无 backdrop、不覆盖画布），才同时满足「F 打开」与「不破坏回归」。
- **出生点不在城镇内**：`ash_outskirts` 的 `townRect` 是 y 950~1250，而出生点是 y 780，因此专项测试必须先向下走 1 秒才能触发商店。
- **存档里装备有两个来源**：`persistGame` 同时写 `equipment`（顶层）与 `player.equipment`，`loadGame` 优先读顶层 `saved.equipment`；编写存档注入类测试时必须两处都改，否则穿戴装备不会被恢复。
