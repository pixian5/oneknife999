## 发现的问题：清层后残留中毒仍致死

F35 通关日志顺序：

1. 回响 18715 → 15250 → 11290 → 8320，玩家死亡 19，回营地。
2. 回响从 8320 继续打到 4360 → 18715（残星复起），玩家 HP 39 时完成。
3. 日志出现“深层第 35 层清层”“怪物不再重生”“进度已自动保存”。
4. 随后仍出现“你在野外倒下，已返回安全营地”，死亡数 20。

诊断 `diagnostics.deaths` 记录：

```json
{"killer":"中毒","maxHp":1583,"bossHpPct":null,"bossPhase":null,"distanceToBoss":null,"poison":2,"hazardsActive":0,"level":41}
```

说明不是怪打死的，也不是地面危险区：清层函数只清了怪物与 `state.hazards`，**没有清玩家身上的 `poison` 层数**。玩家站在非安全区时，`update()` 仍按 `poison * 4` 每 1.2 秒结算，直到死亡。

## 修复

- 在 `runtime.js` 新增纯函数 `clearHostileStatus(player)`：清 `poison / poisonTimer / slowTimer / slowFactor / attackTimer`，不回血。
- `main.js` 的 `clearAbyssResiduals()` 在清怪、清 hazard 之后调用它；该函数在清层当帧与已清层每帧都会执行，保证毒层不会在“已通关”场景里继续结算。
- 新增 `tests/unit/abyss-residual.test.mjs`：
  - 毒层、毒计时、减速、眩晕节奏全部归零；
  - 血量不被改动；
  - `null / undefined` 不抛异常。
