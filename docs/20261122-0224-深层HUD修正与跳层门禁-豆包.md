# 0.8.58 深层 HUD 修正与跳层门禁

## 背景

百关三职业完成后，继续用道士 100/100 存档真实进入无尽深层：第 100 关按 T 进入 `abyss-F1`，真实键鼠清掉 5 只普通怪并击破「灰烬霸主回响」；按 T 进入 `abyss-F2`，再清 5 只并击破「沧海妖皇回响」；按 T 进入 `abyss-F3`。

实际截图暴露四个复用主线的错误：

1. 区域导航显示「第 0/100 关」，因为深层不在 `MAP_ORDER`，`indexOf` 返回 -1。
2. 任务描述写「击败玄烬帝尊，结束第千次轮回」，这是第 100 关终局文案。
3. 清完一层后目标卡返回「百图征途已通关」，不提示按 T 进入下一层。
4. 非首领层可以不做任何击杀直接按 T 跳层，和 HUD 写的「完成本层目标后按 T」相反。

## 修复

- `game/src/render.js`
  - `objectiveView()` 增加深层分支：本层完成后返回「按 T 深入第 N+1 层」，不再命中百图终局。
  - `renderMapObjective()` 深层任务描述、第三项与关卡标签独立：描述写「清剿 N 只普通怪并击破回响后按 T」，第三项写「按 T 深入第 N+1 层」，标签为「进行中 / 首领层 / 本层已通关」。
  - `renderMapHeader()` 深层不再显示「100/100 通关」；未完成时明确写「完成目标后按 T 深入」。
  - `renderRegion()` 深层改为「当前层 / 下一层 / 最深纪录」三张卡，不再算 `MAP_ORDER` 的 0/100。
  - `renderQuestChain()` 深层改为本层击杀、回响状态、下一层三个节点，避免 `chapterStats` 算出 0/0。
- `game/src/main.js`
  - `enterAbyss()` 在原首领层锁之外，统一校验本层 `completed`；未完成时 Toast 报「第 N 层尚未完成：普通怪 X/Y，回响未击破」，并写 `abyss/gateLocked` 日志。

## 验证

- 真实键鼠：F1、F2 均 5/5 普通怪并击破回响；按 T 依次进入 F2、F3。F1/F2 首领均有「残星复起」一次满血复活，不是卡死。
- 未完成 F2 按 T：地图保持 `abyss-F2`，Toast 与日志均为 `floorIncomplete`。
- 完成 F2 后：目标卡「按 T 深入第 3 层」，标签「本层已通关」，动态栏不再出现「100/100 通关」。
- 新增 `tests/ui-abyss-hud-gate.cjs`：1440×900 与 390×844 两档，覆盖文案、锁层、清层后入口；PASS。
- `npm run verify`：244/244。
- 深层当前检查点：`saves/abyss-progress.json`（道士、`abyss-F3`、最深 3 层）。
