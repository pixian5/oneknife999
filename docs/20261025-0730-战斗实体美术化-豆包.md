# 0.4.4 战斗实体全美术化：玩家/小怪/Boss 战斗贴图（豆包）

- 时间：2026-10-25 07:30
- 版本：0.4.4（前置 0.4.3 完整美术库）

## 背景

用户反馈「游戏内人物和野怪没有成功应用美术」——0.4.1~0.4.3 的立绘只用于选职业卡、首领情报条等 UI，战斗画面里玩家仍是圆形几何体、怪物是圆 + 形变、Boss 是圆 + 红圈。本轮把战斗实体全部贴图化。

## 本轮产出（game/assets/，合计约 34MB）

| 类别 | 数量 | 文件 | 说明 |
|---|---|---|---|
| 小怪战斗立绘 | 16 | `monster-{名}.png` | 以 `maps.js` 实际怪物名为准（生成图复用同名）：腐烬矿工/赤牙猎犬/裂脊尸卫/灰烬侦察者/灰鬃狼/林皮蛛/松鸦盗/枯木菇人/黑岩矿工/落石魔/矿脉蝙蝠/腐毒僵尸/赤砂蝎/沙虫/沙盗斥候/枯骨游魂；1:1 裁中央 512 |
| 玩家战斗头像 | 3 | `player-{class}.png` | 三职业立绘裁上部主体（y 5%~62%）成 512 头像 |
| Boss 战斗贴图 | 复用 | `boss-{名}.jpg` | 0.4.3 已有，战斗内直接引用 |

## 代码接入（render.js）

- 新增 `spriteCache` + `loadSprite(key, src)` + `spriteReady(img)`：Image 异步加载缓存；`img.complete && naturalWidth>0` 判定就绪，未就绪自动回退原几何图形（每帧重绘天然兜底，无需回调）。
- `drawPlayer`：有 `player-{classId}.png` 时圆形 clip + drawImage（48px），未就绪回退原圆 + 眼睛点；删除残留旧眼睛点（贴图分支下多余黑点）。
- `drawEntity`：怪物用 `monster-{名}.png`（方形直贴，尺寸 = radius×2×scale），Boss 用 `boss-{名}.jpg`（圆形 clip）；npc（流浪武者）保持菱形；无贴图回退原几何圆 + morph 形变；眼睛点仅在无贴图时画；Boss 红圈 / phase 环 / 前摇环等状态圈保留（贴图之上）。

## 踩坑与经验

1. **UI 有美术 ≠ 战斗有美术**：立绘要真正进游戏，必须接到渲染循环的实体绘制层（drawPlayer/drawEntity），不能只停在选人/情报等静态界面。
2. **文件名必须以代码实体名为准**：16 个小怪名从 `maps.js` 的 `monsterTypes` 提取（此前 KEY_FACTS 的「40 小怪设计清单」与代码实际名不一致，生成图复用同名类型，16 张即可全覆盖）。
3. **image_gen 批量不稳定**：本轮 4 张/3 张批次多次 `Length mismatch`（content 比 request_list 少 1），2 张一批稳定；「腐败/尸体」等描述词触发审核误拦截，换「岩甲重卫/菌肤」等中性词通过。
4. **异步贴图兜底**：Image 加载未完成时 `spriteReady` 为假 → 回退几何图形；游戏每帧重绘，加载完成自动切换，无闪烁无回调。
5. **战斗内小实体贴图尺寸**：怪物 radius 15-20 → 贴图 30-40px，细节在低分看不清，但整体形象（红犬/岩甲/斥候）可辨识；后续如需更清晰可调大 drawImage 尺寸。
