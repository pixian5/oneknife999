# 20261028-0903 复核修复：红名爆装落地与召唤物字段收口（GLM）

## 背景

0.4.3 发布后对全部项目源码做了两轮审查（全量审查 + 逐条复核），确认两个 P2、五个 P3。本轮一次性修复全部七项，版本 0.4.3 → 0.4.4。全程静态审查 + 本地单测验证，未使用浏览器截图、未产生网络流量。

## 修复清单

### P2-1 红名死亡爆装被场景重置清空（main.js die + drops.js）

- **问题**：`die()` 把爆装 push 进 `state.drops` 后调用 `loadMap()` 复活，而 `loadMap` 第一步 `state.drops = []`——装备凭空销毁，日志却声称「掉落在倒下位置」。与 docs/05「掉落是地面实体，保护期后可拾取」的设计直接冲突。
- **修复**：
  - 新增纯函数 `drops.pickRedNameDrop(equipment, { random, x, y })`：从已穿戴槽位等概率抽 1 件，返回 `{ slotKey, drop }`（坐标抖动 ±30/±24 与原实现一致），无穿戴返回 null。
  - `die()` 改为：先抽件并清槽位 → `loadMap` 完成场景重置 → **回填掉落到新场景**。装备不会被 `autoPickupPass` 自动拾取，玩家跑尸按 F 捡回，符合单机原型的「跑尸拾回」语义。

### P2-2 坑道尸皇召唤物实体字段缺失（main.js updateBoss + skills.js）

- **问题**：召唤怪内联构造缺 `respawn / spawnX / spawnY / patrolRadius / aggro / morph`：`respawn` 缺失 → 死后 NaN 永不复活且尸体永留实体表（长 boss 战无界累积）；`spawnX/Y` 缺失 → 脱战距离 NaN（追击永不脱战）；`patrolRadius` 缺失 → 未仇恨时巡逻坐标 NaN（原地呆立）。影响第 3 关 black_rock_mine（boss 一阶段窗口、全图存活 <12 时每 8 秒尝试召唤）。
- **修复**：
  - 新增纯函数 `skills.buildSummonedMob({ type, id, x, y, level, windupTotal, random })`，字段与 `createEntities` 的普通怪模板对齐（`respawn` 刻意缺失——召唤物无复活语义）。`windupTotal` 由调用方传入，避免 skills → combat 的循环依赖。
  - `updateBoss` 召唤分支改用该函数；`updateEntities` 死亡分支对 `summonedMob` 提前 return（跳过 respawn 计时），实体表过滤扩展为 `alive || !(summoned || summonedMob)`——骨卫与召唤物尸体统一整只移除。

### P3 die() 复活血量死代码（main.js）

- **问题**：`die()` 设置 `hp = 55% / resource = 45%`，8 行后被 `loadMap` 的满血满资源重置覆盖（后者有注释声明是防低血量复活死循环的有意设计），两行赋值从未生效。
- **修复**：删除死代码，注释说明复活血量统一由 `loadMap` 满额重置。

### P3 掉落日志与自动拾取不符（main.js spawnDrop + drops.js）

- **问题**：0.4.3 自动拾取上线后，消耗品/货币/材料走近即自动入账，日志却统一写「靠近后按 F 拾取」。
- **修复**：新增 `drops.isEquipmentDrop(item)`（`rollDropItem` 同步复用，消除内联重复判断），`spawnDrop` 按类型区分文案：装备「靠近后按 F 拾取」、其余「走近后自动拾取」。

### P3 导入存档注入面（main.js importSave + persist.js）

- **问题**：`importSave` 只校验 `classId`，物品的 `name / desc / glyph / source / color / affix.label` 直接拼进渲染层 innerHTML / title / style 属性，伪造存档可注入任意 HTML（单机自伤无实际边界，但存档分享/云同步规划下即成 XSS 向量）。
- **修复**：新增 `persist.sanitizeSavedGame(saved)`：字符串字段剥除 `< > & " '` 并截断长度；颜色强制 `#rrggbb` 格式否则回退；数值字段（power/value/amount/enhance/blessing/count）强制非负整数；词缀最多 4 条；背包剔除非对象项；装备按 12 槽位白名单重建（多余键丢弃），顶层与 `player.equipment` 同步。`importSave` 落盘前必经净化。

### P3 新手引导 toast 被覆盖（main.js chooseClass）

- **问题**：引导 1/3 的 toast 弹出后 4 行即被「出城后会自动记录目标」toast 覆盖（单例 toast 后写覆盖前写），从未显示（浏览器实测证实）。
- **修复**：目标提示降级为日志，引导 toast 移到函数末尾弹出。

### P3 advanceGuide 冗余实参（main.js autoPickupPass）

- **问题**：`advanceGuide(99, "拾取")` 第二实参从未被函数签名使用。
- **修复**：改为 `advanceGuide(99)`。
