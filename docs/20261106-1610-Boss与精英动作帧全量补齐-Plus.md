## 2. 生成流程（可复现）

1. 以该角色已落地的**单帧立绘**或**同角色已成功帧**作为 image_edit 参考图；
2. prompt = 「保持外观/轮廓/配色/装备与画风完全不变，仅把姿态改为 …」+「**背景为均匀纯黑无任何粒子与地面**」+「主体完全照亮，居中构图，无文字无字母无水印」；
3. 每次调用**严格 2 张**（3–4 张会触发 `Length mismatch` 或审核拦截）；
4. 用沙箱 `/tmp/cutout.py`（纯 PIL：边缘泛洪 + 闭运算 7/7 + 内部洞填充 + 羽化，阈值阶梯 18/10 → 28/16 → 45/28）落地为 RGBA，绿底拼图目检。

- 新增 `BOSS_ACTION_FRAMES`（12 个 Boss 素材名）与 `ELITE_ACTION_FRAMES`（10 个精英名）两张白名单，避免对没有动作帧的对象拼后缀产生 404；

## 4. 关键踩坑与结论

1. **背景"看起来纯黑"不等于可抠**：模型只要有地面阴影、火星、水花、雾，泛洪就会顺着缝隙吃进主体，或让 bbox 退化成整幅（cutout 判定 bbox > 92% 即判该阈值档作废）。8 张 FAIL 全部是这个原因。
2. **有效解法**：把 prompt 写死为「背景为均匀纯黑**无任何粒子与地面**」，并用**同角色已成功抠出的帧**作参考图，而不是原始带雾参考图。重生成后 8/8 落地成功。
3. **这 8 张的教训值得记住**：凡"攻击带火焰/水花/碎石"的帧，越强调特效越容易毁掉背景，宁可让 prompt 只描述姿态。
4. **暗色主体仍会空心**：幽冥鬼将、黑岩魔像这类近纯黑铠甲，18/10 保守阈值下仍会被边缘泛洪穿透（拼图可见骨架状）。本轮未解决，已列入下轮返工。
