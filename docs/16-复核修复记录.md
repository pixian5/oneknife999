# 复核修复记录

## 版本与范围

- 版本：0.1.7
- 日期：2026-08-12
- 范围：浏览器原型的百图地图生成、普通怪资料、存档资产一致性、重置、三职业并发验收和测试稳定性。
- 非范围：多人服务器权威结算、真实 PK 爆装、支付、网络抖动和正式速度下的经济平衡。

## 问题清单与根因

| 编号 | 复核问题 | 根因 | 修复 |
|---|---|---|---|
| R-01 | `zigzag` 地图只是标签变化，实际道路仍可能近似直线 | 生成器只给道路类型命名，控制点没有强制回摆 | 在每个折返控制点交替加入 X 方向偏移和 Y 偏移，边界钳制后由 `pathTurnCount()` 计算真实转向 |
| R-02 | 后期怪物悬停资料可能退化成通用文案 | 100 图生成怪没有携带背景和技能字段，`monsterProfile()` 只能回退默认描述 | 增加 40 类后期怪物的独立背景和两条技能说明；地图生成后统一回填实体资料，悬停优先读取实体字段 |
| R-03 | 拾取装备、穿戴装备、喝药后刷新可能回退 | 关卡结算有保存，但关键资产操作没有调用 `persistGame()` | 拾取成功、装备替换、使用生命药水后立即保存 v3 |
| R-04 | 点击重置后刷新仍可能迁移旧 v2 旅程 | 重置只移除 v3，遗留 v2 会在下一次启动时再次迁移 | 重置同时移除 v2 与 v3，并在界面提示“旧存档已清除” |
| R-05 | 并发测试装备断言偶发超时 | 背包网格随每帧 UI 状态重绘，Playwright actionability 检查拿到已脱离 DOM 的按钮 | 测试在当前渲染节点上触发标准 `click` 事件，仍经由页面绑定的装备处理器，不写入游戏内部状态 |
| R-06 | 法师资源耗尽后仍可普攻 | 普攻只在技能路径扣除法力，没有普攻资源门槛 | 法师普攻在资源低于 8 时拒绝结算并提示，成功时扣除 8 点法力 |

## 结论与后续边界

本轮复核确认原型的地图结构、道路几何、怪物信息、资产保存、旧存档迁移/清除和三职业百图状态闭环已修复。`e2e+fast` 仅把本机浏览器伤害放大并快进时钟，仍不代表正式速度、多人权威资产、网络故障恢复或经济平衡已完成；下一轮应在不改变本轮存档契约的前提下补正式速度长跑和服务器端实现。
