# 0.4.5 战斗实体全身立绘：主角/野怪 2.5D 精灵化 + 程序化动作动画（豆包）

- 时间：2026-10-25 07:47
- 版本：0.4.5（前置 0.4.4 战斗贴图基础）

## 背景

用户反馈「主角仍然只是一个圆圈」——0.4.4 的 48px 圆形头像在战斗画面里看起来仍是小圆。要求主角与野怪升级为类似 3D / 2.5D / 2D 多动作的人物精灵效果，参考同类传奇页游。

## 核心方案

**全身透明立绘（PIL 抠图）+ 程序化动作动画**（纯前端 Canvas 变换，无帧序列图）：

1. **全身立绘素材**（game/assets/，新增 31 张透明 PNG，合计约 1.6MB）：
   - `player-full-{warrior,mage,taoist}.png`（三职业立绘全身，高 200 源图）
   - `monster-full-{16 怪名}.png`（高 160 源图）
   - `boss-full-{11 Boss 名}.png`（高 256 源图）
   - 抠图算法：PIL BFS 四角种子扩散，邻接色差 34 + 种子色差 70 双阈值；赤牙猎犬（红身贴背景）降阈值 20/50 重抠修复。

2. **渲染改造（render.js）**：
   - `spriteHeight(entity)`：怪物高度 `clamp(radius*4.2, 54, 110)`、Boss `clamp(radius*2.8, 110, 210)`、玩家 112px；脚底锚定（怪物 y+radius*0.55、Boss y+radius*0.9、玩家 y+24）。
   - **玩家动画**：移动浮动（坐标差检测，±3px @ 11Hz）、待机呼吸（±1.6px）、攻击前倾+前冲（attackTimer 期间 rotate 0.16rad + 位移 5px）、攻击挥击金色刀光弧（朝目标，双弧线）。
   - **怪物/Boss 动画**：呼吸浮动（按实体 id 相位错开）、攻击前摇压低微颤、出手瞬间前扑+前倾、受击抖动（hitFlash ±2.5px）；Boss 红圈 / phase 环 / 前摇环按贴图半径适配；名牌上移（y - sprH/2 - 36/44）。
   - 贴图未就绪回退原几何图形（加载异步无回调无闪烁）。

## 踩坑与经验

1. **state.classId 在顶层不在 player**：本项目 `classId` 挂在 `state.classId`（persist.js 同），0.4.4 的 `state.player.classId` 本就是 bug——当时验证截图其实是回退几何圆（"带火焰特效"为误判）。本轮修复为 `state.classId` 后贴图才真正加载（修复前 404：`assets/player-full-undefined.png`）。
2. **canvas 不是全屏**：游戏画布位于页面 (25,149) 尺寸 1046×603（非 1440×900），OCR 千分比换算必须基于 canvas 元素截图，否则实体定位全偏。
3. **chromium headless 截图时机**：`--virtual-time-budget` 下异步图片可能未加载完，需用 Playwright `waitForTimeout` 真实等待 ≥3s 后再截。
4. **PIL 抠图对同色系主体失败**：红犬（红身+暗红渐变背景）edge_tol=34 会误切身体，需降到 20；Boss 立绘带书法题字会残留文字（小尺寸下可接受）。
