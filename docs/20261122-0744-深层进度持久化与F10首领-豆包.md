# 0.8.59 深层当前层进度持久化与 F10 首领层

## 背景

0.8.58 继续深层真人推进：F3、F4、F5（裂隙层）、F6、F7、F8、F9 全部用真实键鼠清完并逐层按 T 深入；F10 首领层「玄烬帝尊的回响」27430 HP，真实击杀并触发一次「残星复起」满血复活，第二次击杀完成。

推进中发现一个真实体验阻断：深层 F10 清完后立即读档，`mapProgress` 里 `bossDefeated` 仍为 false，必须重新打满 5 只普通怪和回响。原因是 `persistGame()` 按 0.8.34 设计剥离所有 `abyss-` 进度键；对“防止无限增长”是对的，但把当前层也剥掉，刷新后无法续层。

## 修复

- `game/src/persist.js`：主线进度照旧剥离深层键，只保留 `state.currentMapId` 对应的一个深层进度键。层数增加不会让存档无限膨胀，同时当前层击杀与首领状态可恢复。
- `game/src/main.js`：`checkMapCompletion()` 的深层分支补 `progress.completed` 计算，并在本层首次完成时返回 true，触发 `autoSaveProgress()`。深层仍不发主线奖励、不参与 100/100 计数。
- 深层 `completionAnnounced` 与当前层完成度写入存档；读档后目标卡直接显示“按 T 深入第 N+1 层”。

## 验证

- 真实键鼠 F3→F10 全清，无死亡；F5 裂隙层、F10 首领层均正常。
- F10 击杀后写入存档：`abyss-F10: kills 5, bossDefeated true, completed true`。
- 刷新后仍是 `abyss-F10`，目标卡「按 T 深入第 11 层」，标签「本层已通关」。
- `tests/ui-abyss-hud-gate.cjs` 增加 `persistGame()` 后刷新断言；1440×900 与 390×844 均 PASS。
- `npm run verify` 单测 244/244。
- 检查点：`saves/abyss-progress.json`，道士、F10 完成、最深 10 层。

## 备注

F10 完成后按 T 曾实测进入 `abyss-F11`；随后恢复到 F10 完成态作为可复现检查点。深层 11 层以后尚未真人试玩。
