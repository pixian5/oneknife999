# 下一步待实现（0.3.5 之后）

- 日期：2026-10-23 21:07
- 模型：DeepSeek-V4.1-Flash
- 基准版本：0.3.5

0.3.5 已落地金币消耗出口（城镇杂货商：药水 / 材料 / 词缀重铸卷；词缀重铸：只重掷一条、成本随强化与词缀数上升）。以下是后续优先级建议。

## P0（体验缺口，建议下一轮）

1. **自动拾取 + 掉落品质光柱**
   - 现状：需要走到掉落物上按 F；城镇内 F 现在还会开商店，拾取成本进一步上升；地上掉落没有品质区分。
   - 方案：`drops.js` 定义品质色（普通/精良/稀有/传说），渲染层画光柱；靠近 60px 自动拾取，可在设置里关闭；注意 F 键的双重语义（城内开商店 / 城外地拾取）要有明确提示，避免误开商店。
2. **三步新手引导**
   - 现状：开局只有 Toast 与日志；新增的杂货商 / 重铸没有任何教学。
   - 方案：首关触发 3 个轻提示（锁定目标、按 X 普攻、前往出口），首次进城镇时追加「按 F 与杂货商交易」，只显示一次并存 localStorage。
3. **非快进难度探针**
   - 现状：百图 e2e 在 25 倍伤害快进下跑，死亡数波动大（0.3.4 为 0，0.3.5 为 18），不能作为难度参考。
   - 方案：`tests/` 新增抽样探针（如第 5/15/25 关各一段，无 fast 参数，固定 RNG），断言「死亡数上限 + 通关时长上限」，并入 `npm run test:ui:regression` 之外的可选任务。

## P1（战斗深度）

4. **怪物攻击类型化前摇**：当前所有怪物共用 0.45s 前摇与 70px 近战范围；建议按 `MONSTER_BEHAVIORS` 区分近战扇形、远程投掷、冲锋三类，各自前摇时长与提示形状不同（扇形/直线/圆圈）。
5. **技能前后摇与打断**：现在技能瞬发无施法动作；建议给高倍率技能加 0.2–0.4s 施法硬直，被命中可被打断（需同步平衡）。
6. **破甲层数可视化**：破甲目前只有飘字与日志；建议目标血条下加破甲图标与剩余秒数。

## P2（经济与工程）

7. **`balance-sim` 补齐前摇 / 闸门 / 商店模型**：让数值调整可被模拟器自测（当前模拟器仍是旧随机攻击模型，且不模拟金币消耗）。
8. **perf 门禁化**：把 `npm run perf` 的 p99 ≤ 4ms / 零 20ms+ 长帧写成 CI 断言（当前只能人工看结果）。
9. **图鉴与套装成就**：装备图鉴收集、套装 2/4 件效果、成就奖励；重铸卷可作为成就奖励出口。
10. **真机触控验证与多人服务器最小验证**：iOS Safari / Android Chrome 验证摇杆与长按普攻；docs/09 网关 + 大厅最小链路（登录、进图、广播移动）。

## 遗留提醒

- 商店面板位于侧栏、**不是全屏遮罩**：百图 e2e 依赖画布点击寻路且每个动作后按 `f`，后续若改造成模态弹窗，必须重跑 `npm run test:e2e`。
- 城镇内 F 的优先级：掉落物 > 秘藏 / 场景节点 > 杂货商。新增城镇 NPC 时要在 `collectDrops` 里继续排下去，否则会出现「按 F 开商店却拾不到东西」。
- `reforgeScroll` 是独立计数（不进背包材料池），若后续把卷轴做成材料，需要同步改 `stackMaterial` 与强化消耗逻辑，避免被当强化材料吃掉。
- 骨卫是 `friendly` 实体，已从自动索敌、指引、点击锁定与 e2e 快照中排除；新增任何「遍历 entities」的逻辑时都要继续跳过 `friendly`。
