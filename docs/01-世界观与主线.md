# 世界观与主线

## 世界规则

玄烬大陆地下存在九条龙脉，分别维持土地、火焰、潮汐、雷霆、生命、死亡、记忆、时间和王权。九座镇魔碑限制龙脉外泄，同时封住万魔祖地。任何人调用龙脉都必须支付寿命、记忆、土地活力或亡者安宁中的一种代价，剧情不得无代价复活或用梦境取消玩家选择。

三百年前，末代皇帝萧烬拔出王权碑，试图让皇权永恒。他成为无昼帝，皇州陷落，九州各自建立守军和宗门。游戏开始时，第九龙脉重新震动。

## 核心人物

| 人物 | 公开目标 | 隐藏矛盾 | 最终作用 |
|---|---|---|---|
| 守碑人洛川 | 修复九碑 | 是末代皇帝弃子 | 可继承或拒绝王权 |
| 游商绯岚 | 维持九州商路 | 曾向无昼帝出售碑位 | 决定终局补给线 |
| 铁卫秦烈 | 守住烬阳城 | 第一次王城战逃跑 | 战士援军或亡魂敌人 |
| 星术师弥罗 | 计算龙脉规律 | 逐渐认同永恒秩序 | 法师援军或副首领 |
| 御灵人青禾 | 安抚龙脉亡魂 | 身体由亡者记忆拼成 | 道士援军或封印材料 |
| 无昼帝萧烬 | 结束无尽战争 | 相信自由必然导致混乱 | 三结局终局首领 |

## 九章任务规格

### 第一章《边城尸变》

等级 1~20，地点为灰烬村、雾松林、黑岩矿坑。

1. 《井水里的铁锈》：调查村民失踪，学习拾取和装备。
2. 《矿灯不会自己熄灭》：护送矿工，第一次组队提示。
3. 《被吞掉的技能书》：击败精英尸匠，获得职业技能书。
4. 《矿底的王座》：击败坑道尸皇，得到边州龙纹拓印。

选择封矿：矿洞怪物减少 10%，安全采矿点增加；选择继续开采：黑铁产出增加 15%，精英率增加。两条路线共享主线入口。

### 第二章《烬阳旧王》

等级 18~35，地点为赤砂大漠、烬骨地宫。玩家发现烬阳城的旧王并未死亡，而是被商会秘密保存记忆。

任务包含护送补给、争夺水井、调查旧王陵和击败烬鬃兽王。选择守军路线会在王城战增加守城弩，商会路线会增加可争夺的临时交易站。

### 第三章《毒巢之心》

等级 30~55。毒骨龙母正在把复活点变成孵化场。玩家需要采集解毒草、保护净化师、深入瘴毒峡谷并击败龙母。

净化毒脉使日常地图更安全；驾驭毒脉使魔潮奖励提高但增加毒雾区域。选择结果在进入前公开。

### 第四章《冰碑裂痕》

等级 50~68。冰碑被三块行会势力分别控制。玩家必须在不强制加入任何行会的前提下取得碑片。终局选择归还冰碑或熔毁为锻造核心，改变雪州安全营地和锻造委托。

### 第五章《雷祭叛乱》

等级 60~75。三职业宗门互相指控对方破坏雷碑。玩家会分别体验战士守线、法师解阵、道士净化三个职业试炼，并只能救下一名被围困导师。

被救导师开放一种全账号技能变体；未救导师不会永久删除，其记忆将在第九章成为敌方技能。

### 第六章《海上龙宫》

等级 70~82。绯岚组织船队寻找碑材龙骨。任务包括修船、海上护送、沉船探索和深海龙王。交还龙骨降低跨服航线费用；截留龙骨给予行会军需，但航线费用提高。

### 第七章《黄泉借兵》

等级 80~90。历代王城城主被困在幽河古墓。玩家可安葬亡魂获得永久声望，也可召回亡魂成为王城战临时单位。亡魂强度固定，不继承付费属性。

### 第八章《破天之门》

等级 88~100。全服累计击败九州狂化首领开启天阙浮岛。共同开门给全服 7 天探索增益；阵营争夺让胜方先进入 12 小时，但其他阵营之后正常开放。

### 第九章《皇城终战》

1 转，地点为皇州外城和万魔祖地。前三阶段分别面对旧王军、未被救导师的记忆和无昼帝。服务器依据阵营贡献和个人选择生成三种结局：重立九碑、毁掉九碑、接管王权。

结局改变后续世界事件和王城景观，不重置装备、等级、技能、交易和行会。

## 对话和任务标准

- 单段对话不超过 80 个汉字，关键选择最多 3 项。
- 选择必须显示短期收益和长期影响类别，不显示“正确答案”。
- 主线任务不能要求固定时间世界 BOSS 最后一击。
- 失败任务允许重试，不消耗不可恢复的核心装备。
- 每章至少包含一次职业差异、一次多人事件和一次非战斗选择。

## 世界线制作规格

本卷将世界观翻译为可制作的任务、对话、地图事件和服务器状态。所有剧情内容必须满足三个约束：

1. 玩家在不读长文本的情况下能知道当前目标、风险和选择后果类别。
2. 选择改变“路线、资源倾向、NPC态度和年表”，不删除职业技能、装备、地图入口和交易资格。
3. 服务器结算后结果不可被客户端回放或重复领取；剧情奖励和战斗奖励分别拥有流水。

### 叙事事实与可变事实

**叙事事实**是所有服务器相同的规则：九条龙脉存在、无昼帝未彻底消灭、调用龙脉必须付出代价。
**可变事实**由服务器年表决定：冰碑是否熔毁、哪位导师获救、王城最终阵营、商路是否恢复。任务脚本
不能写死可变事实；读取 `world_state.chapter_choice[key]` 后选择对应文本、怪物词缀和奖励池。

## 第一章详细任务链

### CH01-01《井水里的铁锈》

- **入口**：1级，进入灰烬村后自动接取；不得要求充值、组队或职业限制。
- **步骤**：与村长交谈 -> 调查井边三个交互点 -> 在雾松林击杀8只锈爪兽 -> 回村净化井水。
- **职业差异**：战士可用“格挡示范”减少一次受击；法师可远程点燃锈藤；道士可提前看到隐藏脚印。
- **失败**：调查点被其他玩家占用时，交互对象每10秒复制一个临时镜像；击杀不足不扣除已完成数量。
- **奖励**：职业基础武器、3瓶恢复药、地图标记“安全回城点”。
- **验收**：首次进入后120秒内至少有一个可点击目标；玩家死亡后可从村口重试，不回退等级。

### CH01-02《矿灯不会自己熄灭》

- **入口**：8级，完成井水任务；队伍可由1~5人组成。
- **护送状态**：矿车生命值100，进入三个检查点各停留8秒；怪物波次按队伍人数乘以 `0.7 + 0.3*n`，上限5人。
- **公共贡献**：击杀、治疗、修理矿车和拾取燃料均计分；最后一击不额外加分。
- **敌对插曲**：危险区出口会刷新一组中立盗矿者，玩家可选择击败或绕行；绕行不判失败，但少一箱黑铁。
- **失败**：矿车生命归零，保留已经到达的检查点，下次只需重新护送未完成段。
- **奖励**：黑铁、蓝色腰带候选、首次组队成就；队伍内按有效贡献分配，不因队长离线丢失。

### CH01-03《被吞掉的技能书》

- **入口**：15级，进入黑岩矿坑；技能书模板由职业决定，不能开出其他职业不可用书。
- **精英机制**：尸匠每30秒吞噬一个地面技能书影子；玩家打断成功后获得“阅读机会”，失败则延迟20秒再次出现。
- **抢夺规则**：技能书影子属于公共目标，贡献前五名均有独立奖励包，避免单队最后一击垄断。
- **失败**：连续三次打断失败只减少额外材料，不阻断主线技能获得。
- **奖励**：第一个主动技能书、技能栏解锁、一个不可交易的技能试读卷。

### CH01-04《矿底的王座》

- **入口**：20级或完成前三任务；支持单人投影和多人公共版本。
- **首领阶段**：王座护盾 -> 尸潮 -> 矿柱坍塌 -> 尸皇暴走；每阶段都至少有一个可读预警。
- **职业要求**：不检查职业组成；战士可打断，法师可清尸潮，道士可净化矿柱，任何职业可通过基础攻击完成。
- **掉落**：个人参与包 + 地面可争夺包；首次一刀时刻在此教学，但不决定最后一击归属。
- **失败**：全队死亡后首领恢复至阶段起点而非满血；已完成阶段成就保留。

```text
choice_id
title
short_term_effect        // 立即可见的资源/路线变化
```

## NPC 状态与对话规则

### NPC 状态机

```text
未见 -> 已见 -> 接取任务 -> 任务进行 -> 任务完成待领奖
                         |                 |
                         +-> 失败冷却 <----+
已见/已完成 --(章节选择)--> 友好、谨慎、敌对、亡魂四态
```

NPC 状态存档按角色保存，世界性 NPC 另存服务器状态。对话脚本不得使用客户端时间判断“夜晚”；使用
服务器 `world_clock_phase`。同一句关键台词至少提供语音、字幕和跳过按钮，跳过只影响表现不影响任务提交。

### 文案限制与审校

- 普通气泡 32~80 个汉字，任务目标 18~36 个汉字。
- 专有名词第一次出现必须带功能解释，例如“王权分（王城阶段积分）”。
- 不用“充值即可”“最强”“百分百毕业”等承诺型词语。
- 选择项用动词开头，避免“我不知道”“随便”这种无法分析的出口。
- 每章至少一次让玩家看见已选择的世界变化，例如 NPC 服装、路障、商队或碑文。

## 公共事件与服务器年表

### 世界事件生命周期

```text
预告(24h) -> 报名/准备(30m) -> 开放(20~45m) -> 结算(60s)
  -> 年表写入 -> 奖励邮件 -> 复盘窗口(7d) -> 归档
```

预告必须显示地图、推荐等级、是否可 PK、个人贡献方式和预计结束时间。事件中途崩溃时，结算服使用
最后一个已确认的阶段快照，不以客户端画面判断玩家是否参与。

### 年表记录格式

```json
{
  "entry_id": "YEAR-000123",
  "server_id": "CN-01",
  "event_type": "chapter_choice|world_boss|castle_war",
  "subject_id": "CH04",
  "result_key": "return_ice碑",
  "occurred_at_utc": "2026-08-10T13:00:00Z",
  "participants_count": 184,
  "guild_ids": ["G-103", "G-204"],
  "rules_version": "0.0.7"
}
```

个人参与记录只保存自己的角色 ID、贡献档位和奖励流水；年表公开展示行会和阵营结果，不公开消费金额、
设备信息和未成年人隐私字段。

## 任务异常与边界

| 场景 | 正常处理 | 禁止处理 | QA 断言 |
|---|---|---|---|
| 任务 NPC 死亡 | NPC 进入保护状态，交互仍可完成 | 因剧情失败永久删除 NPC | 重新登录后状态一致 |
| 章节选择提交超时 | 显示处理中，查询 commit 状态 | 让玩家重复点选扣两次资源 | 同一 `choice_id` 最多一条提交 |
| 公共目标被抢 | 转换为贡献/助攻目标 | 让主线只能等最后一击 | 任何贡献都能完成章节进度 |
| 任务奖励背包满 | 进入任务邮件，保留流水 | 丢弃橙装或技能书 | 7天内可领取且只发一次 |
| 玩家等级超过章节 | 保留剧情，降低普通怪经验 | 阻止查看已完成剧情 | 奖励按一次性标记不重复 |
| 服务器回档 | 回滚世界结果，补发未领取资源 | 回滚玩家已获得的独立交易 | 年表标注修订而非删除 |

## 第二至第九章任务分解

以下任务不是剧情梗概，而是关卡、脚本和 QA 共同使用的最小交付单元。每个任务都包含一个可独立重试的
战斗段、一个公共或组队段、一个非战斗交互段和一个可写入年表的结果。任务目标不得依赖固定玩家数量；
人数变化通过怪物波次、目标数量和奖励包数量缩放，不能通过提高单个怪物秒杀伤害处理。

### 第二章《烬阳旧王》

**CH02-01《沙井的三面旗》**：20级接取，玩家在赤砂大漠寻找三口水井。每口井有守军、商会和中立
路线，玩家可观察补给、价格和安全差异后选择护送对象。完成任意两口即可继续，第三口提供额外声望。
公共贡献包括运水、净化、击杀和修理；敌对玩家只能争夺水井外围，不能让交互点永久不可用。

**CH02-02《旧王陵的记忆封存》**：玩家进入烬骨地宫，收集三枚记忆片。记忆片不会在死亡后丢失，重复
收集转为黑铁。法师可解读文字，战士可搬运石门，道士可安抚亡魂；三职业不同步骤都能获得相同主线
进度。选择守军或商会后，地宫的临时交易站/弩车在地图上出现，年表记录选择。

**CH02-03《烬鬃兽王》**：首领冲锋前锁定非当前仇恨目标并显示方向线，撞墙进入破甲窗口。玩家可把
破绽交给其他队伍，不要求自己完成最后一击。20%生命狂暴，地图公告只显示阶段，不公开某个玩家的
仇恨名单。失败重试时保留已收集记忆片。

### 第三章《毒巢之心》

**CH03-01《解毒草的三种用法》**：在瘴毒峡谷采集普通草、稀有草和被污染草。交给净化师可降低日常
毒雾，交给御灵人可提高魔潮奖励；两种路线都保留另一种草的图鉴。采集点每10秒轮换镜像，避免高峰
被单一队伍垄断。

**CH03-02《净化师护送》**：净化师有生命值和净化进度两个条，怪物攻击会降低进度但不会让任务永久
失败。玩家可以分头清理三条路线，治疗、护幕、打断都计公共贡献。护送失败后从最近净化碑重试。

**CH03-03《毒骨龙母》**：阶段一虫卵、阶段二毒雾、阶段三龙母吐息。虫卵是5%场地目标贡献，毒雾有
至少两条安全路线；选择净化/驾驭影响地图天气、日常奖励和 NPC 台词，不影响首领入口。

### 第四章《冰碑裂痕》

**CH04-01《三方碑片》**：玩家分别从守军、矿工和流浪术士处取得冰碑线索；可不加入任何行会。每个
线索包含一个战斗目标和一个谈判目标，谈判失败可通过补交普通材料重试，不使用装备作为不可恢复代价。

**CH04-02《冰下的锻造声》**：选择归还或熔毁前，系统展示安全营地和锻造委托的短期效果/长期类别；
确认后写 `ch04.ice_policy` 和 `choice_commit_id`。熔毁路线会开放一条锻造委托，不提高直接掉率；归还
路线会开放安全采集点，不删除矿工路线。

**CH04-03《冰霜魔主》**：首领有冰面、裂隙和寒潮三阶段。冰面会改变移动摩擦但不改变服务器命中距离；
法师控制、战士打断、道士净化均计机制贡献。全队死亡返回最近阶段快照。

### 第五章《雷祭叛乱》

**CH05-01《三宗门的证词》**：玩家分别听取战士守线、法师解阵、道士净化的证词。每份证词存在一处
矛盾，玩家可通过战斗、观察符纹或治疗伤员发现。任务不把某职业写成唯一正解，所有证词完成后开放导师
选择。

**CH05-02《只能救一个人》**：三位导师在不同路线同时受困，玩家需要在12分钟内完成一条主路线；队伍
可以分组，但每个角色只能提交一次救援。未获救导师的记忆会在第九章以可预警技能出现，奖励为对应的
全账号技能变体，不永久锁死职业技能。

**CH05-03《雷翼君王》**：场地有可关闭的雷柱和可修理的避雷塔。有效关闭、修理、打断和承伤均进入贡献；
雷柱不关闭也可用走位完成。首领狂暴不设置无法反制的全屏秒杀。

### 第六章《海上龙宫》

**CH06-01《修船清单》**：船体需要木材、龙骨、帆布和符钉，材料可由个人任务或行会军需获得。每种
材料有普通和替代来源，不要求玩家购买。修船进度按参与角色记录，离队不回退。

**CH06-02《沉船的两张航图》**：玩家可先救商队或先取龙骨，两个目标会改变后续航线费用/行会军需；
失败会留下可重试的沉船副本，不消耗转生材料。海上事件的风向由服务器阶段决定，不能被客户端时间作弊。

**CH06-03《深海龙王》**：船上、海面、龙宫三段场地。玩家可在海面完成补给和驱散，进入龙宫后按贡献
获得个人包。交还龙骨降低航线费用，截留龙骨提高军需但不改变 BOSS掉落。

### 第七章《黄泉借兵》

**CH07-01《墓门的名字》**：玩家在幽河古墓收集历代城主名字，阅读碑文可获得年表碎片；名字不要求
按顺序完成。安葬路线获得声望、召回路线获得固定强度的临时王城单位，两条路线都开放完整地图。

**CH07-02《亡魂借契》**：召回亡魂时，玩家需承担王城战中临时单位的控制风险；单位只在活动实例存在，
活动结束自动消失，不继承任何付费属性。安葬玩家在王城获得亡魂外观和称号，不被迫参加战争。

**CH07-03《黄泉教主》**：首领会召回已安葬/未安葬的技能影子，影子技能有前摇和固定反制。死亡后
从最近墓碑阶段恢复，不能通过反复重置刷双倍声望。

### 第八章《破天之门》

**CH08-01《九州狂化首领》**：全服累计击败九州首领，个人和行会都能贡献；外围补给、净化和护送同样
计入全服进度。开门条件达成后写服务器年表，重复贡献转为材料，不能再次开门重复领取7天增益。

**CH08-02《共开还是先行》**：共开给全服7天探索增益，阵营先行给予胜方12小时先进入；后者必须在12
小时后对所有阵营开放。选择面板展示资源和年表类别，不展示“最优答案”或隐藏掉率。

**CH08-03《破天神将》**：浮岛有风墙、平台和撤离点，低特效保留边缘线和落点预警。掉落神器碎片而非
完整毕业套，首批进入和后续进入使用相同基础掉落表。

### 第九章《皇城终战》

**CH09-01《外城三道门》**：旧王军、未被救导师记忆和玩家阵营分别占据一条路线。每条路线都有可见
阶段目标，玩家不必清空所有路线即可进入内城；参与不同路线改变个人年表摘要。

**CH09-02《九碑的代价》**：玩家在最终选择前查看九章选择摘要、已付出的代价和未完成的支线，不显示
其他玩家的选择。确认后写入角色和服务器状态两个流水；若双端同时操作只保留一个 commit。

**CH09-03《无昼帝》**：三阶段读取服务器选择，技能、场地和 NPC 台词改变；每种终局都保留可读预警、
两条撤离路线和个人参与奖励。结局只改变后续事件、景观和外观，不重置等级、装备、技能、交易和行会。

## 对话变量和安全渲染

对话支持角色名、职业、等级、章节选择、NPC态度和服务器年表变量。变量必须经过白名单渲染，禁止把
玩家昵称、聊天原文或服务器错误直接插入可执行脚本。超长名字、特殊字符和未加载字体都需要回退显示；
跳过对白不会跳过任务提交和奖励。

### 对话示例

```text
洛川：你看见碑上的裂纹了吗？它不是冰在碎，是记忆在逃。
[交出碑片] 立即获得安全路线；长期影响：雪州营地。
[保留碑片] 立即获得锻造线索；长期影响：委托类型。
确认后将记录在本服务器年表，不能改写其他玩家的选择。
```

选择按钮必须显示短期类别和长期类别，详细数值由系统帮助和基线引用，不在剧情文案里另写一套概率。

## 章节奖励分层

每章奖励拆成四层：

| 层 | 例子 | 是否可交易 | 失败是否补做 |
|---|---|---|---|
| 进度 | 地图入口、技能栏、年表 | 否 | 是 |
| 确定 | 绑定材料、印记、称号进度 | 否/按模板 | 是 |
| 选择 | 路线外观、NPC态度、委托类型 | 否 | 选择后不改 |
| 惊喜 | 紫装、特殊外观、额外材料 | 按掉落表 | 贡献包可补 |

主线不直接发完整毕业套；选择不能发攻击、控制、掉率和转生属性。失败重试保留进度和已领确定奖励，
随机惊喜按新的合法事件生成，不能重复领取同一 `reward_claim_id`。

## 公共任务贡献

公共任务采用个人贡献包和世界进度两条链：个人击杀、治疗、净化、承伤、打断、搬运和交互计入个人包；
服务器累计击杀或净化推进章节世界事件。最后一击不作为唯一条件，贡献前五团队可以看到自己对世界进度
的影响。贡献失活90秒取消该场资格，重新行动可以恢复资格，历史个人包不重复。

## 章节选择回滚和修订

角色一次性选择提交后不能反选；服务器级选择（例如开天门）必须在事件达成后锁定。发现技术错误时不
删除年表，而是新增修订条目：原结果、修订原因、受影响内容、补偿和新生效时间。玩家个人摘要保留原选择，
并显示“服务器状态已修订”，避免把玩家责任错误改写。

## 世界事件调度

事件排程使用 UTC，至少提前24小时预告；世界 BOSS和王城等高峰事件错开，不要求同一玩家同时出席。事件
进入准备、开放、结算、年表、邮件、归档六态；状态由服务器单调时钟和 `activity_id` 驱动。预告变更需要
新版本和公告，已经开放的事件不因客户端本地时间变化提前结束。

## 年表和个人日志的可见性

公开年表显示服务器、章节/活动、结果、参与人数、行会/阵营和时间；个人日志额外显示自己的贡献档位、
奖励流水、选择 commit 和任务重试。消费、支付、设备、聊天和未公开的其他选择不进入公共年表。

玩家可以按章节、地图、王城、BOSS、首杀、选择和修订筛选年表；筛选为空时显示空状态和回到当前章节按钮，
不把缺少记录误显示成“服务器没有历史”。

## 剧情音频和美术验收

每章至少一个可识别地标、一种 NPC服装变化、一种地图天气/光线变化和一段可跳过过场；终局选择至少有三
种景观差异。音效不承担唯一的任务目标或危险预警，低端机和静音模式仍可通过字幕、图标和轮廓理解。

## 剧情活动和战斗事件的边界

能完成。活动结算延迟时，任务卡显示已记录贡献，不让玩家重复进入造成重复奖励。

值守结束输出完成率、失败点、分支比例、回流、跳过、断线、奖励、客服和性能报告。选择比例仅用于判断
信息是否清楚，不把少数分支改成惩罚线；新章节继续尊重已有世界状态和个人选择。

叙事团队每月用服务器年表反查一次 NPC、地图景观和任务条件，确保玩家看到的世界确实反映已提交选择。

## 服务器年表

年表记录首杀、首次王城归属、九章选择、重大合服和终局。个人可查看自己的参与记录；行会事件由行会日志引用。年表只记录结果和参与名单，不公开玩家消费数据。

### 年表冲突处理

合服时若两个服务器拥有不同王城归属、首杀记录或公共事件进度，旧年表全部保留并冠以原服务器标识；新服从合服事件建立共同纪元，不把任一旧服历史改写成另一服历史。个人九章选择不参与多数表决，仍按角色维度读取。公共世界状态采用公告中明确的合并规则，并在提交前生成影响名单与预览。

发现剧情条件与年表矛盾时，先阻止新的永久选择提交，已提交结果继续可读。修复必须给出冲突事实、受影响任务、采用的新规则和回放结果；若需要补任务，只补可重复的战斗或对话步骤，不要求玩家重新放弃导师、阵营或终局选择。
