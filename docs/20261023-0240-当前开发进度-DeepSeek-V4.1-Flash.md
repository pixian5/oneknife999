| 技能 | 文案承诺 | 0.3.4 实现 |

| 震地冲（战士 3） | 冲向目标并击退 | 向目标突进最多 140px（保留目标身位）、击退 56px（按地图边界夹取），突进瞬间 0.2 秒无敌 |

| 召唤骨卫（道士 2） | 协同作战 12 秒 | 生成 `friendly` 实体：跟随玩家、300px 内自动索敌、0.9 秒出手间隔、按玩家 40% 伤害；到期消散，青色虚线环标识友军 |
| 生息法阵（道士 3） | 站阵回血 | 脚下展开半径 120 的 4 秒法阵，圈内每秒回 8% 最大生命，离开立即失效；紫色虚线圈 + 剩余时间刻度环 |

**友军隔离**：骨卫从自动索敌、范围技能目标、指引箭头、点击锁定、悬停高亮、e2e 快照全部排除，且不参与怪物复活逻辑。

### 2. 怪物攻击前摇（`combat.js` + `main.js` + `render.js`）

- 新增 `MONSTER_ATTACK_RULES` 与纯函数 `advanceMonsterAttack`：普通怪前摇 0.45 秒 / 冷却 4.0 秒，首领前摇 0.6 秒 / 冷却 1.7 秒。
- 节奏：冷却结束 + 已接战（`aggro`）+ 玩家在范围内 → 抬手（原地不动）→ 前摇归零的帧出手 → 冷却按固定值重置。
- 前摇结束时玩家已走开 / 无敌 / 进安全区 → **落空**（「落空」飘字 + 挥击弧，不结算伤害）。
- 渲染：红色蓄力环由外向内收拢，收拢到底即出手，玩家可读环走位。
- 数值校准：旧实现「每帧掷骰 + 只判定最近一只怪」，人多不叠加；改固定节奏后若照搬设计稿 1.2/0.9 秒冷却，实测沙蝎王战会把玩家秒掉（1 张图 15 次死亡）。最终方案是**全局出手闸门 `player.attackGate`（普通 3.1 秒 / 首领 1.7 秒）+ `MAX_WINDUP_ATTACKERS = 1`（同一时刻只有最近一只怪蓄力）**，把「被围」的承伤速率压回旧模型；修正后沙蝎王战连续 3 次复现均存活（结束时剩 53~131 血）。
