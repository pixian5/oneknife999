## 实施内容

### 1. 布局核心参数化（maps.js）

`generatedLayout(stageNumber, chapter)` 重构为内部 `buildLayout(key, siteIndex, chapter, townWidth, eliteAll)`，
两个薄壳：

- `generatedLayout`：`key = stageNumber`——**百图路径代码不变**（208 个既有单测全绿即证）；
- 新增 `generatedAbyssLayout(floor, chapter)`：`key = floor × 2654435761 + 977`（独立种子空间）、
  站点 `(floor×3+4)%10` 与百图错位、营地 280→320、`eliteAll` 九档全开。

### 2. 深层地图构建与注册（maps.js）

- `buildAbyssMap(floor)`（纯函数）：十章主题轮换 `(floor-1)%10`；怪物按层种子洗牌取 5~7 种、
  **数值按原始章内索引计算**（与该章基准关 `chapterIndex×10+5` 同名怪完全同源——回归 5 守住，
  实施中曾按洗牌位置计数值被回归 5 抓出，改为可预期的同源方案）；Boss 用主题章首领做「回响」，
  首领层 ×1.35（三阶段）、守门层 ×0.55；掉落复用基准关 drops（带 setKey）；**exits 恒空**；
  剧情为深层自写文案（`深层 F{floor} · 场景词`），不再套百图剧情。
- `ensureAbyssMap(floor)`（幂等注册）：写 `MAPS`/`MAP_CLEAR_RULES`（`abyss: true` 标记、
  `next: null`、kills=5 展示性目标），**不进 MAP_ORDER**——通关计数、难度解锁、任务链、
  区域导航全部基于 MAP_ORDER，天然忽略深层。

### 3. 流程接入（main.js）

- `enterAbyss`：首领层（`abyssFloor % 10 === 0`）未击败本层首领时**锁层**（toast + 日志）；
  地图改用 `ensureAbyssMap(floor)`。
- `loadGame`：`currentMapId` 为 `abyss-F{n}` 前缀时先注册该层再恢复，层数不得超过存档
  `abyssFloor`（防篡改跳层），异常回灰烬村并留 `abyssRestoreFallback` 警告。
- `checkMapCompletion`：`rule.abyss` 短路百图通关结算——不发通关文案/奖励、**不误报
  「百图征途完成」**（此前若深层 boss 被杀且 next=null 会走终局分支）；保留一条轻量清剿提示。

### 4. input.js 无需改动

0.8.31 已修过「深层内按 T 优先于普通出口」的分支；本方案的 `exits=[]` 进一步根治
`isForwardExit` 对非 MAP_ORDER id 判 `indexOf=-1`、把百图出口当深层前进出口的错位
（设计稿第一节缺陷 3）。

## 实施中修掉的两个真 bug（都被回归当场抓住）

1. **刷怪档位越界**：布局层 `eliteAll` 按 `%9` 生成档位（0-8），但每层只选 5~7 种怪，
   `monsterTypes[7]` 越界 → `PageError: undefined.hp`，且异常发生在 `persistGame` 之前
   导致层数不落盘（症状：地图切了、存档层数没变）。修复：`buildAbyssMap` 对档位按
   `tier % pick` 重映射。
2. **恢复顺序错误**：前缀重建写在 `startMap = cond ? id : "ash_outskirts"` 之后——
   else 分支已把原始深层 id 覆盖为灰烬村，前缀判断永远不成立（回归 9：刷新后回灰烬村）。
   修复：先按「存在于 MAPS **或**是深层前缀」保留原始 id，再在未注册时走重建。

两个坑都已写回设计稿对应位置的代码注释，供后续 AI 避坑。
