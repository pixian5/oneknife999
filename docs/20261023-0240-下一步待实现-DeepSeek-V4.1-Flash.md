# 下一步待实现（0.3.4 之后）

- 日期：2026-10-23 02:40
- 模型：DeepSeek-V4.1-Flash
- 基准版本：0.3.4

0.3.4 已完成技能语义对齐（破甲 / 冲锋 / 穿透 / 骨卫 / 法阵）与怪物攻击前摇（0.45s/0.6s 蓄力环 + 固定冷却）。以下是后续优先级建议。

## P0（体验缺口，建议下一轮）

1. **金币消耗出口：城镇杂货商 + 词缀重铸**
   - 现状：金币只增不减（百图末约 4.5 万），缺少回收循环。
   - 方案：城镇 NPC 商店（药水/材料包/随机词缀卷轴）+ 词缀重铸（消耗金币洗单条词缀），价格表进 `config.js`，纯函数进 `drops.js` 便于单测。
2. **自动拾取 + 掉落品质光柱**
   - 现状：需要走到掉落物上按 F，大地图清怪后拾取成本高；地上掉落没有品质区分。
   - 方案：`drops.js` 定义品质色（普通/精良/稀有/传说），渲染层画光柱；靠近 60px 自动拾取，可在设置里关闭。
3. **三步新手引导**
   - 现状：开局只有 Toast 与日志，首次玩家不清楚「锁定 → 普攻 → 技能 → 拾取 → 出口」。
   - 方案：首关触发 3 个轻提示（锁定目标、按 X 普攻、前往出口），只显示一次并存 localStorage。

## P1（战斗深度）

4. **怪物攻击类型化前摇**：当前所有怪物共用 0.45s 前摇与 70px 近战范围；建议按 `MONSTER_BEHAVIORS` 区分近战扇形、远程投掷、冲锋三类，各自前摇时长与提示形状不同（扇形/直线/圆圈）。
5. **技能前后摇与打断**：现在技能瞬发无施法动作；建议给高倍率技能加 0.2–0.4s 施法硬直，被命中可被打断（需同步平衡）。
6. **破甲层数可视化**：破甲目前只有飘字与日志；建议目标血条下加破甲图标与剩余秒数。

## P2（工程与平台）

7. **perf 门禁化**：把 `npm run perf` 的 p99 ≤ 4ms / 零 20ms+ 长帧写成 CI 断言（当前只能人工看结果）。
8. **真机触控验证**：iOS Safari / Android Chrome 实际设备上验证虚拟摇杆、长按普攻、safe-area。
9. **图鉴与套装成就**：装备图鉴收集、套装 2/4 件效果、成就奖励。
10. **多人服务器最小验证**：按 docs/09 先做网关 + 大厅最小链路（登录、进图、广播移动），再谈反作弊。

## 遗留提醒

- `balance-sim.mjs` 不复现「怪物前摇」，因此 0.3.4 的数值对照完全不变；真实承伤节奏变化以 `npm run test:e2e` 的死亡数为准，后续如果继续调前摇，需要同步更新模拟器或增加专项断言。
- 怪物出手受全局闸门 `player.attackGate` 约束（普通 3.1 秒 / 首领 1.7 秒）且同一时刻只有一只怪蓄力；若后续要做「多怪齐攻」的精英战，需要按战斗场景单独放开这两个上限并重新跑百图 e2e。
- 骨卫是 `friendly` 实体，已从自动索敌、指引、点击锁定与 e2e 快照中排除；新增任何「遍历 entities」的逻辑时都要继续跳过 `friendly`。
