# CogView-3-Flash 免费模型美术素材测试

## 目的

测试智谱清言 CogView-3-Flash 免费模型能否用于《一刀999》的美术素材生产，重点看游戏场景背景与 UI 徽章。

## 调用

- 模型：`cogview-3-flash`
- 接口：`POST https://open.bigmodel.cn/api/paas/v4/images/generations`
- 鉴权：`Authorization: Bearer <API Key>`（Key 不写入仓库）
- 尺寸：背景 `1440x720`，徽章 `1024x1024`
- 生成文件：`美术素材-CogView/`

## 结果

### 深层场景

- 文件：`美术素材-CogView/深层场景测试-1440x720.jpg`
- 1440×720，JPEG，126 KB。
- 构图有地宫纵深、锁链、熔金裂纹和紫色回响光柱，氛围接近深层主题。
- 但 prompt 明确要求“无人物”，中央仍出现一个紫色类人轮廓，不能作为干净的空场景底图。

### 里程碑徽章

- 文件：`美术素材-CogView/深层里程碑徽章-1024.jpg`
- 1024×1024，JPEG，160 KB。
- 黑金圆环、锁链、石阶纹样与紫色宝石完整，正面特写，整体可用。
- 右下角有“AI生成”水印。

## 限制

1. 免费模型强制显式水印；官方说明关闭水印需已签署免责声明的客户，本项目未签署，不能去除。
2. 返回实际格式是 JPEG，即使 URL 以 `_watermark.png` 结尾；文件扩展名已按真实格式改为 `.jpg`。
3. 尺寸只有固定枚举，没有游戏当前使用的 1600×900；`1440x720` 是 2:1，需要裁成 16:9。
4. 无透明通道，不能直接制作技能图标、透明徽章、怪物立绘。
5. 连续请求会 429，本次第二次请求立即触发，等待约 30 秒后恢复。
6. 提示词有漂移，空场景会生成类人轮廓。

## 结论

质量足够做概念稿和氛围参考，但受水印、JPEG、固定尺寸、无透明通道限制，暂不接入 `game/assets`。若后续要正式用于游戏，建议使用已获授权的无水印付费模型，或先完成免责声明签署后再切换。
