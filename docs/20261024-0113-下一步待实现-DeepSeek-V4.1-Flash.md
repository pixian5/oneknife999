# 下一步待实现（0.3.6 之后）

- 日期：2026-10-24 01:13
- 模型：DeepSeek-V4.1-Flash
- 基准版本：0.3.6

0.3.6 已落地非快进难度探针（`npm run test:difficulty`），死亡数重新具备参考价值。以下是后续优先级建议。

## P0（先修正确性，再做新功能）

1. **防御词缀接入承伤公式**
   - 现状：`equipmentDefense()` 已实现但零调用点，玩家承伤只取 `activeHero().defense`（`main.js` 怪物出手两处）。0.3.5 的重铸防御词缀完全无效。
   - 方案：承伤改传 `activeHero().defense + equipmentDefense()`；同步更新 `combat.js` 单测与 docs/11 数值基线。
   - 影响：后期承伤整体下降，必须用 `npm run test:difficulty` 复测第 5/15 关死亡数与耗时，必要时回调怪物攻击。
2. **自动拾取 + 掉落品质光柱**
   - 现状：需走到掉落物上按 F；城镇内 F 现在还会开商店，拾取成本进一步上升；地上掉落没有品质区分。
   - 方案：`drops.js` 定义品质色，渲染层画光柱；靠近 60px 自动拾取（设置里可关）。注意 F 的优先级：掉落 > 秘藏 / 节点 > 商店。
3. **三步新手引导**
   - 现状：开局只有 Toast 与日志；杂货商 / 重铸没有任何教学。
   - 方案：首关 3 个轻提示（锁定、按 X 普攻、前往出口），首次进城镇追加「按 F 与杂货商交易」，只显示一次并存 localStorage。

## P1（战斗深度）

4. **怪物攻击类型化前摇**：现在所有怪物共用 0.45s 前摇与 `radius + 70` 近战判定；建议按 `MONSTER_BEHAVIORS` 区分近战扇形、远程投掷、冲锋，前摇时长与提示形状各自不同。
5. **技能施法硬直与打断**：高倍率技能加 0.2~0.4s 施法硬直，被命中可打断（需同步平衡并复测探针）。
6. **破甲层数可视化**：破甲目前只有飘字与日志，建议血条下加破甲图标与剩余秒数。

## P2（工程与经济）

7. **`balance-sim` 补齐前摇 / 闸门 / 商店 / 重铸模型**：让数值调整可被模拟器自测（当前模拟器仍是旧随机攻击模型，也不模拟金币消耗）。
8. **perf 门禁化**：把 `npm run perf` 的 p99 ≤ 4ms / 零 20ms+ 长帧写成 CI 断言。
9. **探针扩面**：`ONEKNIFE_PROBE_STAGES=5,15,25` 纳入发布前检查；再给 mage / taoist 各跑一次第 15 关，形成职业难度对照表。
10. **图鉴与套装成就**：装备图鉴、套装 2/4 件效果、成就奖励；重铸卷可作为成就奖励出口。
11. **真机触控验证与多人服务器最小验证**：iOS Safari / Android Chrome 验证摇杆与长按普攻；docs/09 网关 + 大厅最小链路。

## 遗留提醒

- 探针的玩家模型是「一刀一撤 + 55% 喝药 + 60% 撤退」的固定脚本；改战斗节奏（前摇时长、攻击距离、闸门冷却）后，模型参数也要跟着调，否则会误判难度。
- 探针每关新建 context 是硬要求，不要为了省时间改回单页连跑。
- 商店面板不是全屏遮罩（百图 e2e 依赖画布点击与 F 连按），若改模态必须重跑 `npm run test:e2e`。
- 城镇内 F 的优先级：掉落 > 秘藏 / 场景节点 > 杂货商；新增城镇 NPC 要继续往后排。
- `reforgeScroll` 是独立计数，若改成背包材料需同步 `stackMaterial` 与强化消耗。
- 骨卫是 `friendly` 实体，新增「遍历 entities」逻辑时继续跳过。
