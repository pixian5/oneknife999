# 百图剧情与任务线

## 剧情定位

《一刀999》的百图主线不是“换地图打更高数字”，而是一场逐层拆穿世界谎言的传奇远征。玩家从保护灰烬村的普通旅人出发，先相信玄烬是灾祸、怪物是敌人、帝尊是幕后黑手；十章之后才发现三件事：

1. 玄烬既会吞噬记忆，也是维持玄烬大陆不崩毁的火种。
2. 人、魔、妖、神的战争由两条重叠时间线制造，用来持续给玄烬供能。
3. 玄烬帝尊是前九百九十九次轮回中选择独自封印灾祸的玩家自己。

“一刀999”因此有剧情含义：第一次释放一刀时刻时出现的 `999`，是九百九十九次失败人生同时挥出的记忆回声；第千次轮回的目标不是更强地重复旧答案，而是让整个大陆共同记住并分担代价。

## 核心角色

|---|---|---|

| 顾七 | 贪财盗陵医师 | 曾替司烬院检查容器，因救下失败实验者而被追杀 |
| 宁霜 | 冰封北境雪哨长 | 百年前战死者的记忆投影，完成军令后选择让自己真正消失 |
| 赤鸢 | 魔族铸炉师 | 证明魔族是初火原守护者，迫使玩家重新判断“正邪种族” |
| 无咎 | 幽冥摆渡人 | 保存被玄烬献祭者的姓名，拒绝让任何牺牲成为无名数字 |

| 九歌 | 来自未来的同伴 | 未来玩家主动切下的人性与悔意，既是盟友也是成为暴君的预警 |

| 玄烬帝尊 | 最终敌人 | 前 999 次轮回的玩家集合体，希望这一次的自己能找到不靠孤独牺牲的答案 |

## 世界规则

- **记忆守恒**：玄烬不能无代价地产生能量，每次平息裂变都要吞噬真实记忆。
- **名字锚点**：只要仍有人记得牺牲者的真名，记忆就不会完全成为燃料；无咎的生死簿因此能伤害玄烬。
- **双史重叠**：神与魔分别生活在两条真实时间线，两线被强行重叠后，双方都能拿出真实的“对方先背叛”证据。
- **容器轮回**：帝尊每次崩溃前都会重置世界，并从自己的过去筛选下一位容器。
- **共同承火**：终局第三条道路把玄烬拆成百万枚可记忆、可拒绝、可轮换的火种，不再由一个英雄永久承担。

## 第一章：灰烬边境（001–010）

主题是“敌人是否真的背叛”。玩家与阿禾追查守碑军袭村事件，最终发现她的父亲赫连烬并非叛徒，而是在没有援军的情况下主动成为封印。

| 关卡 | 地图/节点 | 剧情与任务 |
|---:|---|---|
| 001 | 灰烬村外·异兆 | 村民开始忘记亲人的名字；清理腐烬矿工，找到第一块会呼吸的碑石 |
| 002 | 雾松林·遗痕 | 追踪守碑军足迹，发现他们沿途留下疏散标记而非进攻标记 |
| 003 | 黑岩矿坑·盟约 | 救出阿禾；她要求亲手确认父亲是否成为裂碑领主的帮凶 |
| 004 | 赤砂大漠·代价 | 截住魂火车队，同时保护逃难商队；车上装的是村民被抽走的童年记忆 |
| 005 | 边境祭坛·夺印 | 破坏记忆熔铸仪式，获得半枚裂碑钥印 |
| 006 | 边境迷宫·潜城 | 进入守碑军地下城机，发现军粮和遗书都停留在百年前 |
| 007 | 边境王庭·裂盟 | 阿禾承认自己曾替司烬院监视玩家，只为换取父亲仍活着的消息 |
| 008 | 边境禁门·破门 | 读到赫连烬证词：守碑军在阻止矿脉吞噬村民记忆 |
| 009 | 边境圣台·真相 | 闻人策派兵焚毁证词；玩家守住记录，第一次公开质疑司烬院 |
| 010 | 边境终殿·章决 | 击败灰烬霸主赫连烬；他恢复片刻神智，为玩家开启苍月航道 |

章末选择不改变主线数值，但改变后续对白：把赫连烬称为英雄，阿禾会成为公开史官；继续称其为怪物，阿禾会沉默随行并在终章质问玩家。

| 015 | 苍月祭坛·夺印 | 打断王朝旧祭司继续制造海妖的仪式 |
| 016 | 苍月迷宫·潜城 | 潜入海底档案库，见到被重写前后的两版战报 |
| 017 | 苍月王庭·裂盟 | 洛汐承认沧海妖皇是她的兄长，她一直在引玩家去结束其痛苦 |

## 终局与后续钩子

主结局“共火纪元”不清除等级、装备和地图。百图完成后，章节地图进入世界事件状态：玩家携带十件遗物回访旧区域，处理共同承火带来的新矛盾。这样终局不是删档，而是把刷装、行会和王城玩法放入新的历史阶段。

三个叙事倾向由过程选择累积，不影响付费或战斗数值：

- **铭记者**：优先公开真相、保存姓名，终局由阿禾主持大陆史馆。
- **守火者**：优先救援与稳定，终局由赤鸢和弥星维护百万火种网络。
- **破局者**：优先挑战旧秩序，终局由苏烈组织神魔联合议会。

无论倾向如何，玩家都不能选择继续永久独裁，因为那会把故事退回前 999 次失败；差异体现在同伴关系、回访任务、世界事件和城镇对白。

## 游戏内呈现规则

- 进入每张地图：战场记录显示章节名、关卡节点、剧情摘要和当前角色对白。
- 当前关卡卡片：标题显示三位关号与剧情节点，描述显示叙事目标和战斗条件。
- 通关地图：战场记录追加“剧情揭示”，章末关展示该章反转和下一章钩子。
- 存档：剧情进度与地图进度使用同一关号，刷新后不会重复发放奖励；对白允许重播。
- 快进测试：只验证 100 个剧情节点均存在且与地图一一对应，不把快速点击视为玩家已阅读剧情。

## 剧情与地图母题的绑定

剧情节点与场所母题按关位同步推进，使玩家能从场景形态预判叙事任务：前哨通常承担“异兆”的警戒和求援，荒径承担“遗痕”的追踪，古寨承担“盟约”的见证，深谷承担“代价”的救援，祭坛承担“夺印”的仪式，迷宫承担“潜城”的调查，王庭承担“裂盟”的摊牌，禁门承担“破门”的证词，圣台承担“真相”的守证，终殿承担“章决”的首领选择。每章换一套地貌、怪物和颜色，但十个节点顺序保持可读的节拍。

场景细节不会替代战斗规则：拒马、断墙、祭环、门柱、王座和环柱当前是 Canvas 视觉地标，不设置隐形碰撞；玩家可以自由走位，出口仍由普通怪目标与 Boss 状态机唯一解锁。这样既让地图有传奇类战区辨识度，也不会因装饰物把角色卡死。
