### 1.2 玩法与系统

- **关卡**：十章 100 图，每关「清剿 N 只普通怪 + 击破区域首领」→ 前进出口解锁；低等级进图有游戏内确认弹层。
- **战斗**：三职业各 4 技能（单体 / 范围 / 冲锋 / 爆发 / 召唤 / 治疗）、普攻、破势槽满触发「一刀时刻」、技能倍率随技能等级 +6%/级。
- **怪物**：巡逻 → 190px 仇恨 → 340px 脱战；首领 2–3 阶段、阶段技能（落木 / 地裂 / 尾刺）、召唤小怪、地面危险区预警圈。
- **成长**：击杀经验可连续升级（本关上限 = 主线等级 + 1，终局 Lv.41）、升级回满生命/资源并发放技能点。
- **装备**：12 部位、词缀（攻击/生命/防御/恢复）、强化 +15（失败不降级、+10 起祝福值）、拆解返还材料、有效战力计入伤害公式。
- **资源**：金币、首领印记、生命药水、职业资源、材料（黑铁矿石堆叠）。
- **地图交互**：篝火（安全区回血回蓝）、秘藏补给箱、场景站点 10 种效果（集火/侦察/固守/净化/敕令等）。
- **PK 演示**：危险区白名流浪武者、Lv.20 前 PK 保护、罪恶值 ≥300 红名、红名死亡爆 1 件穿戴装备。
- **存档**：自动保存通关进度、手动保存、导出/导入 JSON、重置。
- **交互**：WASD/方向键 + 虚拟摇杆、点击寻路、点击锁定、10 动作可改键、音效开关。

### 1.3 审计结论（体验短板，按严重度）

| 级别 | 短板 | 证据 | 用户感受 |
|---|---|---|---|
| P0 | 战斗反馈单薄 | 暴击只放大飘字；无连击；升级只有 Toast；玩家受击无来源提示 | 「打怪像点数字」 |
| P0 | 大地图目标不明确 | 指引只靠 HUD 文案，怪物/首领/出口需肉眼搜索 | 「找不到怪，也找不到出口」 |
| P0 | 移动端普攻必须连点 | 普攻按钮只绑 `click`，无长按连发 | 「手指很累」 |
| P0 | 资源不足必须点击后才知道 | 技能按钮只显示冷却，无资源态 | 「点了没反应」 |
| P1 | 技能描述与实现不符 | 破甲斩无破防、震地冲无位移、召唤骨卫无实体 | 「技能只是倍率不同」 |
| P1 | 怪物攻击无前摇动画 | 每帧按概率直接扣血，只有飘字 | 「莫名掉血」 |
| P1 | 金币缺少消耗出口 | 只有强化消耗金币 | 「金币越攒越多没用」 |
| P1 | 掉落需逐个走近按 F | 无自动拾取 / 无稀有度光柱 | 「捡东西打断节奏」 |
| P1 | 新手引导缺失 | 首分钟仅靠 Toast 与日志 | 「不知道先做什么」 |
| P1 | HUD 信息密度高 | 右侧 7 个面板 + 底部动作条，760px 下挤压 | 「看不清重点」 |
| P2 | 缺少图鉴/套装/成就 | 无长期收集目标 | 「通关后没有追求」 |
| P2 | 仅单机前端模拟 | 无服务端与多人 | —— |

## 三、本轮已落地优化（0.3.3，P0）

### 3.1 连击系统（Combo）

- 规则（`COMBO_RULES`，`game/src/feedback.js`）：3 秒内连续击杀累计连击，上限 99；每 5 连击额外 +8 金币。
- 只加金币、**不改经验**，因此百图 e2e 的等级/经验断言不受影响。
- 反馈：Canvas 顶部居中显示「N 连击 + 剩余秒数」，击杀目标处飘出连击数字，里程碑写入战场记录。
- 验收：`tests/unit/feedback.test.mjs` 覆盖倒计时、清零、里程碑、上限。

### 3.2 目标指引箭头（Compass）

- 按关卡三阶段自动选目标：
  1. 清剿未完成 → 最近的存活普通怪（跳过 NPC）；
  2. 普通怪清完 → 首领实体；首领复活中 → 首领固定坐标；
  3. 通关 → 前进出口。
- 箭头绕玩家 54px 绘制，下方显示「目标名 · N 格」（30px = 1 格），距离 < 80px 自动隐藏避免遮挡。
- 验收：单测覆盖三阶段与首领复活回退。

### 3.3 打击感强化

| 反馈 | 触发 | 实现 |
|---|---|---|
| 屏幕震动 | 满破势爆发 / 一刀时刻 / 首领击杀 / 升级 | `fx.shake`，仅渲染层偏移，不影响点击命中与相机 |
| 升级光环 | 击杀升级与通关升级 | `fx.levelUp` 1.1s，金色圆环 26→96px + 26 粒金色粒子 + 「LEVEL UP」 |
| 怪物挥击弧 | 怪物命中玩家瞬间 | `entity.attackFlash` 0.18s，朝玩家方向画红色弧 |

### 3.4 移动端与可读性

- **长按普攻**：按住普攻按钮每 100ms 检查一次，仅在目标进入普攻距离时出手，避免距离外反复弹提示；抬手/取消立即停止，按钮显示按下态。
- **技能资源态**：资源不足时技能按钮变暗、消耗数字变红，不再需要点击才发现放不出。

## 四、后续优化排期（P1 / P2）

### P1-1 技能语义对齐（下一轮首选）

| 技能 | 现状 | 目标 |
|---|---|---|
| 破甲斩 | 纯倍率 | 命中后目标防御 -15%，持续 4s（新增 `armorBreak` 字段，承伤公式读取） |
| 震地冲 | 纯倍率 | 向目标位移 140px 并击退，位移过程无敌 0.2s |
| 召唤骨卫 | 只打一次伤害 | 生成实体骨卫 12s：40% 攻击、跟随玩家、自动攻击最近怪 |
| 生息法阵 | 瞬回 28% | 4 秒内每秒回 8%，站在法阵内才生效 |
| 法师穿透 | 单体 | 沿锁定方向命中一条直线上最多 3 个目标 |

验收：新增技能语义单测；`balance-sim` 复跑确认三职业全通、无单关死亡 > 3；百图 e2e 复跑。

### P1-2 怪物攻击前摇与可视化

- 新增 `entity.attackWindup`（普攻 0.45s / 首领 0.6s）与 `attackCooldown`（普攻 1.2s / 首领 0.9s），替换当前每帧 `Math.random()` 判定。
- 前摇期间怪物身上显示红色蓄力环，玩家可走位打断（脱离范围即落空）。
- 风险：会改变实际承伤节奏，必须复跑 `balance-sim` 与百图 e2e，死亡数允许小幅波动但需记录。

### P1-3 金币消耗出口（城镇商店）

- 城镇内新增杂货商：生命药水 30 金币、回元露 45 金币、黑铁矿石 60 金币、词缀重铸 150 金币/次。
- 商店面板复用现有弹窗样式；交互 `E`（可在键位设置中修改）。
- 目标：让金币、材料、印记形成闭环，减少「越攒越多」的空转感。

### P1-4 拾取与掉落表现

- 自动拾取开关（默认开）：金币 / 药水 / 材料自动吸附；装备保留手动确认，避免误穿。
- 掉落光柱：按品质（白/蓝/紫/金）绘制不同高度与颜色，稀有掉落附带屏幕边缘提示。
- 背包满时掉落保留地面并高亮，不静默丢失。

### P1-5 新手引导（前 3 分钟）

- 三步遮罩：移动（WASD/摇杆）→ 锁定并普攻 → 拾取与背包。
- 完成后写入 `oneknife999-tutorial-v1`，可在设置中重看。
- 仅在首次新档触发，读档不重复打断。

### P1-6 HUD 减负

- 760px 以下：战场记录与任务链默认折叠为一行摘要，点击展开。
- 保留「当前关卡 / 装备 / 背包 / 目标」四块核心信息。
- 验收：三视口冒烟 + 新增折叠交互用例，确保无纵向滚动。

### P1-7 perf 门禁化

- 阈值：`p99FrameMs ≤ 4ms`、`over20ms = 0`、`avgFps ≥ 1000`。
- 纳入 `npm run verify:ci`，CI 中跑无头 perf；超阈值直接失败。
- 基线：0.3.2 平均 3604 fps / p99 1ms；0.3.3 平均 3887 fps / p99 1ms / 最差帧 9.6ms / 零 20ms+ 长帧（新增逐帧指引箭头与连击绘制，无回退）。

### P2 长期方向

1. 图鉴 / 套装 / 成就：收集驱动，复用现有 12 部位与词缀数据。
2. 升级三选一（吸血鬼幸存者式）：在升级瞬间弹出 3 个短期增益，增加决策乐趣；需改成长结算与 UI。
3. 词缀重铸与锁定：金币 + 材料消耗，形成装备深坑。
4. 真机触控验证：iOS/Android 上验证摇杆、长按普攻、安全区、窄屏排版。
5. 多人服务器最小验证：账号、房间、战斗同步、掉落归属；按 docs/09 架构推进。
6. 云存档与跨设备：当前 JSON 导入导出可先升级为账号云存档。

## 五、验收标准与风险

### 本轮验收（0.3.3）

- `npm run verify`：84 个单测全绿（新增 7 个连击/指引用例）。
- `npm run test:ui`：1440×900 / 390×844 / 360×640 三视口 PASS。
- `npm run test:ui:levelup`：首关 Lv.2 PASS。
- `npm run test:ui:regression`：渲染/输入稳定性 PASS。
- `npm run perf`：平均 3887.39 fps、p99 1ms、最差帧 9.6ms、零 20ms+ 长帧。
- `ONEKNIFE_RUNS=1 npm run test:e2e`：百图 100/100、战士 Lv.41、16 次死亡、100 个检查点 SAVED+RESTORED（预校验迁移/重置清档/资产保存/损坏存档回退全部通过）。

### 风险控制

- 连击只影响金币，不影响经验/等级 → 不触碰 e2e 成长断言。
- 震屏只做渲染偏移，不改变相机与点击坐标 → 不影响输入测试。
- 指引箭头为纯绘制，不写入存档 → 无迁移成本。
- 长按普攻只在目标进入射程时出手 → 不产生提示风暴。

## 六、结论

本项目「玩法骨架」已完整（百图、三职业、装备、强化、词缀、任务链、PK、存档、测试），当前主要差距在**反馈厚度与目标可达性**，而非系统缺失。本轮以低风险、高感知的 P0 优化补齐连击、指引、打击感与移动端操作；下一轮应优先把技能描述与实现对齐、补怪物攻击前摇，再补金币出口与拾取体验，最后进入引导、HUD 减负与 perf 门禁。
