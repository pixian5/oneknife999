## 改动

### P0-1 铭牌阶梯避让（render.js）

0.4.1 复测遗留：怪群贴脸时铭牌之间仍互相遮挡（720 样本最差 57.7%，只靠纵深排序缓解）。本轮在统一绘制层内加**放置式阶梯避让**：铭牌按纵深排序后逐个放置，与已放置铭牌水平重叠（水平间距 < 两牌半宽和 - 6px）且垂直重叠（< 牌高 - 2px）时，整牌向上错开一级（牌高 + 3px 台阶，最多 3 级）。`drawNameplate` / `drawPlayerNameplate` 增加可选 `top` 覆盖参数，自然位置不变，只在冲突时抬升。代价：邻牌进出重叠区时位置有轻微跳动（路线图已声明接受该取舍）。

### P0-2 飘字视口裁剪（render.js）

`drawText(text, view, viewWidth)`：飘字上浮（vy -26）与贴边出生会被画布裁掉，绘制位置按可视区内缩（x 夹到 `[view.x+24, view.x+width-24]`，y 不低于 `view.y+16`）。世界坐标不变，只影响绘制位置。

### P0-3 铭牌可读性回归用例（tests/ui-nameplate.cjs）

把 0.4.1 的浏览器插桩固化为常驻回归：`addInitScript` 包装 `CanvasRenderingContext2D.fillText / arc`，按采样窗口记录绘制顺序与矩形，断言三项硬指标：

1. 飘字（数字类 fillText）在铭牌之后绘制且命中铭牌矩形 = **0**（0.4.1 的主 bug）；
2. 特效环（r ≥ 16 的 arc，排除 r=13 的移动目标圈）在铭牌之后绘制且命中铭牌 = **0**；
3. 铭牌之间互相遮挡 = **0**（阶梯避让生效）。

场景：真实键盘直行进入怪群 + 小幅交错聚怪 + 合成 X 键连打（普攻默认键 0.3.2 起为 X，不再是 J）。实测样本：9497 铭牌 / 316 飘字 / 11123 特效环，全部零遮挡。已接入 `npm run test:ui:nameplate` 与 CI。

### P1-4 重铸锁定词缀（shop.js / main.js / render.js / input.js）

按路线图实现：≥2 条词缀的穿戴装备可锁定 1 条，锁定词缀不参与重掷、报价 ×1.8（`reforgeQuote` / `reforgeAffix` 增加 `lockIndex` 参数，锁定不生效的条件：非整数下标、越界、词缀数 < 2）。UI：商店重铸行的词缀改为可点击芯片（锁定显示 🔒 与琥珀色，title 说明规则），重铸按钮显示 ×1.8 后价格与 🔒 标记；重铸完成后该部位锁定自动清除。商店面板签名补入锁定状态（修复了锁定后价格不刷新的缓存问题）。单测 +5（报价 ×1.8、越界/单条无效、锁定词缀原样保留、非锁定槽位重掷、不锁定行为不变）。

### P1-7 伤害估算展示（render.js + index.html）

玩家卡新增一行 `普攻期望(本区怪) ≈ X · 破甲期 ≈ Y`：复用 `computeDamage` 纯函数，目标是当前地图怪物防御的**中位数**，方差取 1.0（期望值）；破甲期对照按 -15% 防御再算一次。强化 / 重铸 / 换装的攻击收益从此直接可读，与 0.4.0 的三围面板互补。

### P1-10 破甲可视化（render.js）

目标仍处于破甲窗口（`armorBreakTimer > 0`）时，铭牌下方绘制 `⚔ 破甲 -15% · Ns`（琥珀色，随 tick 递减）。与铭牌统一几何常量，不引入新层。

### P2-12 perf 门禁（tests/perf-probe.cjs + ci.yml）

探测脚本增加失败条件：`p99FrameMs > 4` 或 `over20ms > 0` 即非零退出（阈值可用 `ONEKNIFE_PERF_P99_MAX` / `ONEKNIFE_PERF_OVER20_MAX` 覆盖）。CI 新增两步：铭牌可读性回归 + 帧率门禁。本机基线：p99 1.0ms、最差帧 5.6ms、零 20ms+ 长帧（阶梯避让的每帧排序开销可忽略，avgFps 4218 vs 上轮 6519 属机器负载波动，门禁只看 p99 与长帧）。

e2e catalog 的空间约束（节点互不重叠/避战区/避刷怪点、生成图刷怪不进战区、构图签名唯一、主路 ≥8 营位、支路图 ≥4 守卫且补给箱锚定支路）下沉到单测全量断言；另加 101–110 关（未来关号）生成鲁棒性用例。单测 109 → 114 个。
