## 实际尺寸结论

- 12 个图标缩到 23px / 19px 后仍能区分，强剪影优先：03 战靴、04 火剑、06 火环、07 火球、08 陨石、09 骷髅、10 骨卫、11 叶阵最稳。
- 01 破甲斩最终图只有碎裂盾牌、没有刀刃；作为“破甲”符号成立，但和“斩”的动作关联弱。
- 02 旋风扫是纯橙金旋涡，没有战刃；作为“横扫旋风”成立，和法师火焰技能的色系靠职业色区分。
- 05b 是单体雷矛，23px 下紫色长条很清晰，明显优于首轮的“人物+画框”。
- 07c 是爆发火球，和 06 的贴地火环拉开差异；但它不是严格意义上的“震环”，属于视觉优先的取舍。
- 12 镇魂符生成了带金边的牌匾/符牌，不是纸符；23px 下矩形轮廓最清楚，细节不可辨。

## 04 / 08 补拍结论

- **04 深渊帝陵禁卫**
  - `04d`：完整全身、紫焰头盔、暗黑地宫，长戟较小。
  - `04e`：完整全身、暗黑地宫、长戟清晰；判定优于 04 原版与 04d。
  - 三张都没有塔盾。提示词后加的“左手塔盾”没有被模型稳定执行；不要按文件名误以为有盾。
- **08 玄烬帝尊**
  - `08d`：人类帝王脸、冕冠、龙袍、紫电光轮都正确，但只有半身。
  - `08e`：1344×768 远景全身，冕冠到衣摆完整，但脸被全覆盖头盔遮住。
  - 当前提示词与尺寸下，**无法单图同时拿到“正确人脸 + 完整全身 + 暗黑氛围”**；要游戏立绘用 08e，要人物特写用 08d。

## 文件与限制

- 主图 12 张：`01`–`12`，全部 1024×1024 JPEG，67–131 KB。
- 补拍 7 张：`04d`、`04e`、`05b`、`07b`、`07c`、`08d`、`08e`；其中 08e 为 1344×768。
- 清单：`manifest.json`、`生成清单.json`、`最终选用.json`、`预览清单.json`、`补拍/manifest.json`、`补拍/生成清单.json`。
- 全部图片保留右下角“AI生成”水印；免费模型关闭水印需已签署免责声明，本批未去除。
- 没有 alpha 通道，不能直接当透明图标；若接入游戏，需要去水印授权、抠图/透明化、按 23px/19px 重新导出。

## 复现

```bash
ZHIPU_API_KEY=... python3 tools/cogview_batch.py \
  --manifest "美术素材-CogView/第三批-技能图标/manifest.json" \
  --out-dir "美术素材-CogView/第三批-技能图标" --interval 30

python3 tools/cogview_skill_preview.py
python3 tools/cogview_skill_candidates.py
```

免费模型串行 30 秒间隔可稳定出图；零间隔连续请求会立刻 429。API Key 只从环境变量读取，不写入仓库。
