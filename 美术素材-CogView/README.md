接口返回 URL 以 `_watermark.png` 结尾，但下载后实际是 JPEG 编码；扩展名与真实格式不一致，已改为 `.jpg`。

## 限制

- **强制水印**：两张图右下角都有“AI生成”显式水印。免费模型默认开启，官方文档说明关闭水印需要已签署免责声明的客户；本项目未签署，因此不尝试去除。
- **尺寸枚举固定**：仅支持 `1024x1024`、`768x1344`、`864x1152`、`1344x768`、`1152x864`、`1440x720`、`720x1440`，没有游戏现用的 1600×900。1440×720 是 2:1，需要裁成 16:9 才能用于地图背景。
- **无透明通道**：返回 RGB JPEG，不能直接做技能图标、徽章、怪物立绘的透明 PNG。
- **限流**：连续请求第二次直接返回 HTTP 429；等待约 30 秒后可再次成功。
- **提示词漂移**：场景 prompt 明确写了“无人物”，仍在中央生成了一个紫色类人轮廓；适合当概念参考，不适合当空场景底图。

## 结论

CogView-3-Flash 的出图质量、构图和材质细节可用，适合做概念稿、氛围参考和构图探索；由于水印、JPEG、固定尺寸、无透明通道，暂不直接接入 `game/assets` 生产管线。
