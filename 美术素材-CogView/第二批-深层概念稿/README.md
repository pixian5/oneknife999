## 模型限制与实测结论

- **水印**：14 张全部带右下角“AI生成”水印，免费模型默认强制，未去除。缩到 112/110/210/128px 后水印变小，但仍然存在。
- **格式**：全部为 JPEG，无透明通道；接口 URL 仍以 `_watermark.png` 结尾，与实际格式不符。
- **连贯请求**：本次 12 张按 30 秒间隔串行请求，全部一次成功，无 429；之前零间隔连续两次会立即 429。
- **全身构图不稳定**：方形图里的怪物容易被裁成半身；强调“远景全景、人物只占四成五”能拿到完整全身，但会丢掉暗黑氛围与武器细节。`04c` 就是这种取舍的失败样例。
- **首领身份漂移**：写“玄烬帝尊”时，模型倾向生成全覆盖头盔的黑暗领主；写“清晰人类面孔、冕冠、龙袍”能得到人脸，但只给近景头像，无法同时拿到“人脸 + 全身”。
- **图标可用性最好**：4 张图标都居中、元素完整、缩到 128px 仍能读出剑、法杖、道印、徽记；但黑底不是透明底，不能直接进游戏图标槽。
- **小尺寸可读性**：角色与图标缩到实际尺寸后轮廓清楚；怪物半身反而比全身更容易读；首领在 210px 下剪影成立。
