## 实际尺寸结论

尺寸来自真实页面测量，不是估算：

- 桌面 1440×900 / 1920×993：`.equipment-slot` 与 `.inventory-slot` 均为 **46px**；
- 移动 390×844：装备格约 **28.7px**、背包格约 **29.5px**，本批统一按 **29px** 验收；
- 技能图标仍为桌面 23px、移动 18px，本批不适用 23px 口径。

46px 下 16 张全部可辨；29px 下主要靠剪影与主色区分：

- 最稳：01 剑、02 盔、04 甲、07 紫晶戒、08 灰黑印记戒、10 靴、11 紫焰勋章、12 青玉、13 红药瓶、14 黑岩、16 金币。
- 偏弱：03 颈环链条在 29px 下只剩“金弧 + 紫点”，但仍能认出项链；05 与 06 都是深色护腕/手镯，靠 05 的金边与 06 的龙鳞紫眼区分；09 是横向带状物，容易被看成项圈；15 横向卷轴在 29px 下是“黄色长条 + 紫点”。

  --manifest "美术素材-CogView/第四批-装备与物品图标/manifest.json" \
