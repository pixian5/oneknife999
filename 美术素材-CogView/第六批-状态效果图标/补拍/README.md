# 第六批补拍候选

主图 12 张首轮全部返回后，发现 `03` 的眩晕语义偏弱、`04` 的眼罩没有真正遮住眼球、`11` 的红色背景光晕会破坏 HUD 图标的一致性，因此做了三轮补拍。最终采用 `03c`、`04e`、`11b`。

## 眩晕（03）

| 候选 | 说明 | 结论 |
|---|---|---|
| `03a-状态-眩晕-原版.jpg` | 银色战盔 + 三颗金星，背景有棕色石纹 | 语义偏弱，16px 只剩头盔 |
| `03b-状态-眩晕-金星环绕.jpg` | 纯星环，无头盔 | 星星清楚，但容易被读成“星辉”而不是眩晕 |
| `03c-状态-眩晕-倾斜战盔.jpg` | 裂纹战盔 + 金色星轨 | **采用**：24–32px 能同时看到头盔与星轨 |

## 致盲（04）

| 候选 | 说明 | 结论 |
|---|---|---|
| `04a-状态-致盲-原版红眼.jpg` | 睁开的红眼，背景是木板与铁栅 | 完全没有“盲”的语义，且背景杂乱 |
| `04b-状态-致盲-黑布蒙眼.jpg` | 红眼 + 横向黑布带 | 布带可见，但瞳孔仍外露 |
| `04c-状态-致盲-铁眼罩.jpg` | 黑色铁眼罩 + 红宝石 | 更像宝石徽章，眼睛语义丢失 |
| `04d-状态-致盲-黑布包眼.jpg` | 布带层层包住眼睛 | 出现两个白色高光，像双瞳，弃用 |
| `04e-状态-致盲-皮革眼罩.jpg` | 黑色皮革眼罩，闭眼红缝 | **采用**：没有外露眼球，24px 仍能看出两只闭合眼缝 |

## 狂暴（11）

| 候选 | 说明 | 结论 |
|---|---|---|
| `11a-状态-狂暴-原版红底.jpg` | 红色兽首 + 红色背景光晕 | 背景光会形成红色方块，弃用 |
| `11b-状态-狂暴-黑底兽首.jpg` | 纯黑底 + 赤红兽首 + 双角 | **采用**：轮廓最干净，24px 仍可辨 |
| `11c-状态-狂暴-黑底怒目.jpg` | 红脸 + 红烟 | 细节过密，16px 糊成一团 |

## 小尺寸对照

`候选小尺寸对照.jpg` 把上述候选按 128/64/32/16px 排在一起，可直接复核取舍。

## 水印与密钥

所有补拍同样由 `tools/cogview_batch.py` 调 CogView-3-Flash 生成，下载后自动清除右下角“AI生成”。Key 只从环境变量或仓库外 `~/.config/oneknife999/zhipu.env` 读取，不写入本目录。
