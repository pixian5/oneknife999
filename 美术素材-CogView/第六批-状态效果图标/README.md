# 第六批：状态效果图标 12 枚

用于游戏内中毒、减速、眩晕、致盲、破甲、灼烧、流血、冰冻、护盾、治疗、狂暴、疾行等状态的 HUD 提示。当前只作为素材库交付，尚未接入 `game/assets` 与 `render.js`。

## 规格

- 模型：`cogview-3-flash`
- 尺寸：12 张 `1024×1024` JPEG，RGB，无 alpha
- 背景：纯黑或近黑，圆形暗铁徽章居中，主体约占画面 64%
- 文字：全部无文字、无字母、无数字
- 水印：右下角“AI生成”已由 `tools/cogview_clean.py` 自动检测并清除；12 张均命中
- 密钥：只读当前执行环境的 `GLM_API_KEY` / `ZHIPU_API_KEY`，或仓库外 `~/.config/oneknife999/zhipu.env`；本目录不保存 Key

## 补拍与取舍

- `03` 采用 `03c`：裂纹战盔 + 金色星轨。`03a` 是首轮战盔，`03b` 是纯星环方案，均在 `补拍/` 留档。
- `04` 采用 `04e`：黑色皮革眼罩、闭眼红缝。`04a` 是睁眼红瞳，`04b` 加了横向布带但眼球仍外露，`04c` 更像红宝石，`04d` 出现双高光，均留档。
- `11` 采用 `11b`：纯黑底赤红兽首。`11a` 带红色背景光晕，`11c` 红烟过密，均留档。

## 可读性

`实际尺寸对照.jpg` 给出 64/32/24/16px 的 1:1 对照。结论：

- 24–32px 是这套图标的主力尺寸，HUD 优先按 32px 设计、24px 保底。
- 16px 下 `01/02/05/06/08/10/12` 仍能靠颜色与轮廓辨认，`03/04/11` 偏弱；若必须上 16px，建议给 `03/04/11` 单独做高对比简化版，而不是直接缩图。
- `02` 与 `12` 都是靴子，靠冰蓝/银蓝与“锁链/羽翼”区分；`07` 与 `05` 都偏红，靠“匕首/盾牌”区分。

## 复现

```bash
# 生成主图（30 秒间隔，断点续跑；已存在文件只检测不清洗）
python3 tools/cogview_batch.py \
  --manifest 美术素材-CogView/第六批-状态效果图标/manifest.json \
  --out-dir 美术素材-CogView/第六批-状态效果图标 \
  --interval 30

# 重建总览与 64/32/24/16px 对照
python3 tools/art_status_preview.py
```

## 限制

- CogView 只返回 JPEG，没有透明通道；接入 HUD 前需要另做抠底或改用带 alpha 的资产流程。
- `04` 的“闭眼红缝”是概念化表达，缩小后可能被读成两只红眼；若 UI 需要更强的“失明”语义，可再做一版“布带完全覆盖 + 无眼球”的高对比符号。
- 当前素材未接入游戏；`render.js` 仍用文字和屏幕叠加色表示中毒/破甲等状态。
