# 《一刀999》

原创传奇类 MMORPG 的可玩浏览器原型 + 完整设计文档体系。

- **可玩原型**：十章 100 张连续关卡、三职业、首领阶段战、掉落装备、自动保存；纯前端 Canvas 实现，代码位于 [game/](game/)。
- **设计文档**：[docs/](docs/) 是设计事实源（产品、战斗、成长、地图、PK、行会、经济、服务器、QA、数值基线），治理规则见 [docs/README.md](docs/README.md)。
- **当前版本**：0.8.66（见 [VERSION](VERSION)）

## 测试

```bash
npm run verify                # 语法检查 + 代码格式检查 + 纯函数单元测试（无需浏览器）
npm run test:ui               # 桌面 / 移动视口冒烟测试（含虚拟摇杆，需先 npm run serve）
npm run test:ui:regression    # 界面渲染与输入回归（需先 npm run serve）
npm run test:ui:nameplate     # 铭牌可读性回归：飘字 / 特效环不得压住血条（需先 npm run serve）
npm run test:e2e              # 真实浏览器百图通关回归（需先 npm run serve）
npm run perf                  # 帧率探测，结果写入 .test-artifacts/（需先 npm run serve）
npm run balance               # 真实速度数值模拟（三职业百图，输出 tests/balance-out.csv）
```

持续集成：0.7.0 按 GitCode 平行线的决定**删除 GitHub Actions**（主仓托管在 GitCode，Actions 无触发场景）。门禁改为本地 `npm run verify` + 三项浏览器回归，提交前必须跑完。

本轮真实键鼠清层 **F56–F60**：回响单管 31329 / 35157 / 39088 / 43124 / 107433 HP，用时 99.3 / 162.6 / 120.4 / 198.7 / 190.3 秒，死亡 87→127；五层总用时 771.3 秒，平均 154.3 秒。每层首领都触发一次「残星复起」，实际打两管。清层后观察 8 秒，死亡 127 不涨、`poison=0`、`hazards=0`，首领卡实时收起。

F60 是第三个里程碑：107433 / 43124 = **2.491 倍**，与 F40 的 2.507、F50 的 2.498 一致；`game/src/maps.js` 的 `f % 10 === 0 ? 1.25 : 0.55` 与 3 阶段确认是设计值。F60 死 10 次、190.3 秒。

F56–F60 死亡 **+40（平均 8.0/层）**，是 F51–F55 的 **+20（平均 4.0/层）** 的两倍；最难的普通层 F59 死 11 次、198.7 秒，比 F60 还多 1 次死亡、慢 8.4 秒。根因是 F56–F59 依次为第 6–9 章，`baseStage` 从 55 升到 85，再叠加深层倍率；F60 是第 10 章加 1.25 倍里程碑。

F50 91432 → F51 13732 是**章节轮换**：`buildAbyssMap()` 用 `(f-1)%10` 决定章节，F51 回到第 1 章基础；深层倍率仍按层累积，所以 F51 比 F41 的 11370 高 20.8%，F55 比 F45 的 23156 高 19.2%。但区域导航写“深层成长 +14% 生命 / +7% 攻击”，与 F50→F51 的实际下降冲突，需要决定“把数值锚改成按层累计”还是“改文案承认每 10 层轮换章节”。
