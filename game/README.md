# 一刀999 浏览器纵向切片

这是设计文档对应的可玩原型，目标是验证“出城 -> 找怪 -> 战斗 -> 掉落 -> 穿戴 -> 升级 -> 切换地图 -> 追逐首领”的体验闭环。它是前端模拟，不代表正式服务器实现；正式项目仍需按 `docs/09-服务器技术与反作弊.md` 接入权威战斗与资产服务。

## 启动

在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory game
```

然后打开 <http://127.0.0.1:4173>。

## 操作

- 选择战士、法师或道士后开始。
- `WASD` / 方向键移动，点击地面移动，点击怪物锁定。
- `J` 普攻，`1` 至 `4` 释放职业技能，`R` 释放满破势槽的一刀时刻。
- `F` 拾取附近掉落，`Q` 使用生命药水。
- `T` 前往当前地图的第一个出口；也可以直接走入场景边缘的发光出口区域触发切换。
- 右侧"区域导航"面板显示所有首发地图，高亮当前所在地图和已到访地图；点击非相邻地图会提示需要先走到相邻出口。
- 右侧背包中的装备可以点击穿戴；保存按钮把当前原型进度写入浏览器本地存储。

## 多地图与世界结构（v0.0.9）

本轮实现了 4 张首发地图，按等级递增构成线性探索路线：

| 地图 | 推荐等级 | 危险等级 | BOSS | 出口 |
|---|---:|---|---|---|
| 灰烬村外 | 1~10 | 村口保护 | 裂碑领主（2阶段） | → 雾松林 |
| 雾松林 | 8~18 | 野外可争夺 | 森林巨猿（2阶段·落木） | → 黑岩矿坑 / ← 灰烬村外 |
| 黑岩矿坑 | 15~28 | 野外可争夺 | 坑道尸皇（3阶段·召唤腐工/地裂/吞噬） | → 赤砂大漠 / ← 雾松林 |
| 赤砂大漠 | 20~35 | 危险区·爆装 | 沙蝎王（2阶段·尾刺/水井净化） | ← 黑岩矿坑 |

- **出口切换**：每张地图边缘有发光出口区域（青色脉冲边框 + 标签），走入即触发切换；跨地图保留等级、装备、背包、金币和首领印记。
- **等级门槛**：进入推荐等级过低的地图时会弹出二次确认（实际差距 2 级以上），取消则被弹回安全方向。
- **BOSS 阶段机制**：
  - 森林巨猿：50% 生命进入阶段二，开始落木（玩家附近随机生成红色蓄力圈，1.2 秒后爆发）。
  - 坑道尸皇：70%/35% 生命分三阶段，阶段一召唤腐工，阶段二/三释放地裂和吞噬（前方扇形危险区）。
  - 沙蝎王：50% 生命进入阶段二，尾刺精准锁定玩家位置；攻击叠加毒层（最多 5 层），需靠近地图中的水井地标净化。
- **危险区提示**：进入赤砂大漠会提示危险区规则；BOSS 蓄力危险区有红色虚线圈和橙色倒计时圆环双重预警。

## 本版范围

已实现三职业差异、职业资源、技能冷却、伤害与防御减免、首领阶段（含召唤/危险区/毒层/水井净化）、首领印记、地面掉落、装备穿戴、升级、委托进度、死亡复活提示、多地图切换、区域导航面板、移动端按钮和低依赖 Canvas 场景。掉落和战斗仍为本地演示，尚未包含多人联机、真实 PK 爆装、行会王城、交易撮合和服务端持久化。
