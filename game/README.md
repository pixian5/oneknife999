# 一刀999 浏览器百图原型

这是《一刀999》传奇类游戏的可玩浏览器原型，当前实现 10 章、100 张连续关卡地图，验证“清怪 -> 首领 -> 掉落 -> 升级 -> 自动保存 -> 出口 -> 下一关”的完整循环。当前版本为 0.8.97。

## 启动

在仓库根目录执行：

```bash
npm run serve
```

打开 <http://127.0.0.1:4174>（等价于 `python3 -m http.server 4174 --directory game`）。

## 代码结构

原型入口为 `index.html`，逻辑拆分为 `src/` 下的 ES Modules：

| ---------------------------------- | ------------------------------------------------------------------------------------------------------- |

| [src/maps.js](src/maps.js)         | 4 张手工地图 + 96 张确定性生成地图、关卡顺序与通关规则                                                  |
| [src/config.js](src/config.js)     | 职业、怪物资料、掉落池、运行环境标记，以及 0.2.5 装备/强化/词缀/技能升级/PK 规则常量                    |
| [src/geometry.js](src/geometry.js) | 确定性随机、贝塞尔采样与路径计算（纯函数）                                                              |
| [src/combat.js](src/combat.js)     | 伤害结算与击杀收益（纯函数，随机数参数注入；装备战力按有效值计入）                                      |
| [src/drops.js](src/drops.js)       | 掉落掷点、词缀滚动、拾取结算与场景节点效果（纯函数，随机数 / 时间参数注入）                             |

| [src/logger.js](src/logger.js)     | 结构化诊断日志：四级过滤、类别、环形缓冲、节流/采样、全局上下文、异常兜底与控制台入口（零依赖，可单测） |

| [src/keybinds.js](src/keybinds.js) | 键位配置：默认键位、保留键、改键校验与 localStorage 持久化（纯函数可单测）                              |

## 操作

- 选择战士、法师或道士后开始。
- `WASD` / 方向键或点击地面移动，点击怪物锁定；移动端使用左下角虚拟摇杆拖动移动。
- `X` 普攻（默认键位，紧邻技能键），`1`–`4` 技能，`R` 一刀时刻，`F` 交互（优先拾取掉落，其次搜索补给箱，再激活场景节点；在城镇内且附近无可交互物时开 / 关杂货商面板），`Q` 药水。移动端可**长按普攻按钮**持续攻击（仅锁定目标进入射程时出手）。
- 世界内**指引箭头**按关卡阶段指向最近普通怪、首领或前进出口，并显示目标名与格数；3 秒内连续击杀累计**连击**，每 5 连击额外金币。
- `K` 打开/关闭技能升级弹窗（升级获得技能点，每级 +6% 技能倍率，上限 10 级）。
- 右上角「设置」可自行修改普攻/技能/药水/拾取/大招/前往/技能弹窗等键位并持久保存；移动键固定为 WASD / 方向键，`Esc` 取消改键；「恢复默认」一键还原。
- `T` 前往当前关的东侧出口；必须完成普通怪与 Boss 两项目标；低等级进入高压图会弹出游戏内确认层（`Esc` 取消）。
- 点击右侧装备槽位 = 尝试强化该部位（+1~+5 必成，失败不降级不销毁，+8 起消耗材料，+10 起失败积累祝福值）。
- 危险/绝地地图会刷一名白名流浪武者：Lv.20 前不能主动攻击，击杀累积罪恶值，红名（罪恶 ≥ 300）死亡掉落 1 件穿戴装备。
- 右上角「音效」开关合成音效、「导出/导入」可备份或恢复 JSON 存档。
- 技能悬停显示完整说明，范围技能显示以角色为中心的范围圈。
- 技能语义（0.3.4）：破甲斩使目标防御 -15% 持续 4 秒；震地冲向目标突进最多 140px、击退并获 0.2 秒无敌；雷矛术沿直线穿透最多 3 个敌人；召唤骨卫生成 12 秒友军实体（跟随、自动索敌、按玩家 40% 伤害出手，青色虚线环标识）；生息法阵在脚下展开 4 秒，每秒回复 8% 最大生命，离开立即失效。
- 怪物攻击前摇（0.3.4）：普通怪 0.45 秒、首领 0.6 秒，头顶红色蓄力环由外向内收拢，收拢到底才出手；前摇期间走开、进入无敌或安全区即落空。出手后进入全局闸门（普通 3.1 秒 / 首领 1.7 秒，任何怪都不能重新抬手），同一时刻只有最近的一只怪蓄力，因此被多只怪围住时承伤速率与旧版持平。
- 城镇杂货商（0.3.5）：走进城镇按 `F` 打开右侧栏商店（离开城镇自动收起）。可购买生命药水 90 金币、黑铁矿石 ×1 60 金币、词缀重铸卷 200 金币；金币不足或缺少卷轴时按钮禁用并给出原因。
- 词缀重铸（0.3.5）：对已穿戴装备重掷一条词缀（白板装备则新附一条，新词缀自动避开已有属性），金币成本 = 120 + 40×强化等级 + 60×当前词缀数，另需 1 张词缀重铸卷。重铸只改变一条词缀，其余保持不变。
- 装备边际贡献（0.4.0）：已穿戴槽位悬停显示「本件贡献：攻击 +x · 生命 +y · 防御 +z」；背包装备悬停显示「装备后：攻击 73→118 · 生命 446→506 · 防御 37」（同部位已穿时给旧→新对比，公式与角色三围同源）；城镇重铸列表每行也标出本件贡献，重铸成功后该行高亮 2 秒。
- 铭牌与飘字（0.4.1–0.4.2）：名字 / 血量 / 血条统一画在场景最上层，伤害飘字、粒子与技能环不会再压住血条；铭牌只绘制视野内目标（按纵深排序），靠地图边缘的飘字会被夹回视口内；死亡复活后**首领保留已损失生命**（普通怪仍满血重置），不会因一次失误把整条首领血条重打一遍。
- 铭牌可读性回归（0.4.2）：`npm run test:ui:nameplate` 插桩 Canvas 绘制并逐帧检测「非铭牌内容命中铭牌」，断言飘字 / 粒子 / 特效环遮挡为 0。0.7.0 曾按 GitCode 平行线删除 GitHub Actions；当前已恢复 GitHub Actions，本地提交前仍先跑 `npm run verify` + 关键浏览器回归。
- 致盲被动回归（0.7.2）：`npm run test:ui:blind` 把玩家放到第 31 关「冰封雪原猎手」旁不还手，等它命中后断言 `snapshot().player.blind > 0`、`blindMissChance === 0.3` 且生命确实下降——防的是「参数写好了但没人读」这类静默失效。
- 行为开关回归（0.7.3）：`npm run test:ui:abilities` 在雾松林逐只对比 16 只怪的 `attackShape / passives / onDeath` 签名，断言 `noabishapes` / `noabipassives` / `noabideath` 各自只关一维、其余逐只不变，`noabilities` 仍三类全关。难度消融结论：第 30 关死亡压力主要来自**攻击形态**（基线中位 8 死 → 关形态 1 死），被动中等（5 死），亡语无影响（8 死）。
- 角色面板三围（0.3.8）：头像 / 战力下方显示 **生命 / 攻击 / 防御**，三项均与战斗结算同源——攻击含装备有效战力 ×0.9（与伤害公式一致）、生命取 `playerMaxHp()`、防御取 `playerDefense()`。重铸或换装后可直接对照数值变化；「战力」仍是综合评分，不等同于伤害。
- 怪物头顶显示等级和生命；悬停显示背景、攻击、防御和技能。
- 普通怪和 Boss 都带独立背景与至少两条技能资料；后 96 图的生成怪会按章节显示专属介绍。

## 百图结构

地图按 10 章 × 10 图组织：灰烬边境、苍月群岛、龙脉地宫、冰封北境、烬火魔域、幽冥鬼蜮、天穹遗迹、星陨禁区、神魔战场、帝陵终境。

每关都包含独立地图名、推荐等级、危险标签、四类普通怪、区域首领、掉落、剧情目标和前后出口。前 4 关为手工地图，第 5–100 关按关号确定性生成营地、Boss、怪群、道路与地标，形成 100 个唯一实际构图。前哨、荒径、古寨、深谷、祭坛、迷宫、王庭、禁门、圣台和终殿各有专属道路、地标与首领场造型。后 96 图的怪群不再漂浮在随机空地：主路按“前段警戒带 -> 中段压迫带 -> 首领前集结”分段布置；`fork/radial` 额外在支路中段布置 4 只支路守卫，绕路取补给会有明确战斗代价。每张图的 Canvas 会显示分段编号、路线名称和预计怪数，且普通怪刷新点避开首领战区。右侧区域导航显示当前关附近 6 图以及“第 N/100 关”，保持整个 HUD 在一个视口内。

每张地图还固定放置 1 处前线篝火、1 个秘藏补给箱和 1 个场景交互节点。篝火在半径 62 内持续恢复生命、职业资源并净化毒层；补给箱在半径 70 内按 `F` 搜索一次，奖励生命药水、金币和首领印记；场景节点在半径 66 内按 `F` 激活一次，根据前哨、荒径、古寨、深谷、祭坛、迷宫、王庭、禁门、圣台或终殿提供破势、资源、免伤、净毒或 Boss 锁定等即时效果。`fork/radial` 地图会把补给箱明确放在支路，HUD 显示“可选支路”提示；主线可直达战斗与首领区，玩家可自行决定是否绕路取补给。两类一次性交互都会写入当前地图进度并自动保存，节点位置会避开出生点、怪物刷新点和 Boss，详情见 [地图场景交互节点打磨记录](../docs/18-地图场景交互节点打磨记录.md)。

剧情按十章、100 个唯一节点推进；进入地图会显示章节摘要和角色对白，任务卡给出本关叙事目标，通关后揭示下一层真相。完整剧情见 [百图剧情与任务线](../docs/15-百图剧情与任务线.md)。

## 升级节奏

| 关卡阶段 |   升级速度 | 阶段终点 |
| -------- | ---------: | -------: |
| 1–10     |   每图一级 |    Lv.11 |
| 11–30    | 每两图一级 |    Lv.21 |
| 31–60    | 每三图一级 |    Lv.31 |
| 61–100   | 每四图一级 |    Lv.41 |

普通怪和 Boss 提供击杀经验，首次进度击杀给满额经验，清完本关目标后继续刷怪给一半经验；击杀经验可即时升级并获得技能点。为避免刷怪破坏主线节奏，本关可升到的最高等级 = 主线曲线等级 + 1（终局封顶 Lv.41），通关结算时保留已获得的击杀等级并与主线曲线对齐。后期升级变慢后，每张地图仍通过装备、金币、药水、印记和首领材料提供即时收益。

## 通关、保存与恢复

- 每关必须达到普通怪目标并击杀 Boss；两项允许任意顺序完成。
- 首次完成后只发放一次奖励，随后自动保存到 `oneknife999-prototype-save-v4`。
- 自动保存发生在关卡奖励和升级结算之后。
- 拾取掉落、穿戴/替换装备、使用药水后立即自动保存关键资产；刷新不会丢失这些变更。
- 点击“重置”会同时清除 v3 当前存档和 v2 旧存档，刷新后不会再次迁移旧进度。
- 刷新或任务中断后恢复当前地图、等级、经验、装备、背包和 100 图独立进度。
- 只有 v2 旧存档时会自动迁移到 v3，保留旧等级下限且不删除 v2 原件。
- 死亡回到当前地图安全营地，不会从后期退回第一关。
- 第 100 关完成后显示“百图征途已通关 / 全部完成”。

详细规则见 [地图关卡与通关规则](../docs/12-地图关卡与通关规则.md) 和 [百图关卡与成长曲线](../docs/14-百图关卡与成长曲线.md)。

## 战斗反馈与掉落

- 角色头顶显示等级与生命条，底部技能栏上方显示职业资源条。
- 普通怪死亡有 42% 概率掉落一次，Boss 固定掉落两次。
- 掉落池包含生命药水、回元露、金币、装备、材料和首领印记碎片。
- 进入地图左下安全营后免伤并恢复生命与职业资源；赤砂大漠水井可快速净化毒层。
- 玩家按下方向键会立即取消普攻自动接近，松开后不会继续追逐旧目标。

## 诊断日志

原型内置零依赖结构化日志（`src/logger.js`），用于出问题时直接定位「哪一次、在哪个分支、当时什么状态」。

| 场景         | 用法                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------- |
| 日常试玩     | 默认 `info` 级，只记录启动、存档、升级、死亡等关键事件                                             |
| 详细排查     | 打开 `?log=debug`，浏览器控制台同时打印，可现场观察每个失败分支                                    |
| 完全静默     | `?log=off` 关闭全部日志（仅用于对比帧率）                                                          |
| 自动化测试   | `?e2e=1` 自动切到 debug 但**不镜像控制台**，避免探针被 console I/O 拖慢                            |
| 手动查看缓冲 | 控制台执行 `__ONEKNIFE_LOG__.text()` / `.text({ level: "warn" })` / `.stats()` / `.config()`       |
| E2E 读取     | `window.__ONEKNIFE_E2E__.logs({ limit, level, category })` 返回结构化条目，`logsText()` 返回纯文本 |

- 缓冲固定 600 条环形队列，溢出时累计 `dropped` 并在 `stats()` 中显示，不占用持续内存。
- 每条记录带全局上下文：地图 / 关卡号 / 职业 / 等级 / 血量上限 / 帧号 / 深渊层 / 难度。
- 高频事件（普攻、被击、毒跳、危险区）按次数采样，重复阻塞提示（冷却、缺资源、射程外）按同键节流，既保留可诊断性又不污染日志、不拖慢帧率。
- 未捕获异常与 Promise 拒绝由 `installGlobalErrorHooks()` 兜底写入 `error` 级日志。

## 测试

先安装依赖（仅 Playwright 包，不会下载浏览器）：

```bash
npm install
```

三类测试都直接使用本机已安装的 Google Chrome（`ONEKNIFE_CHANNEL` 可切换：默认 `chrome`；CI 上设 `chromium` 并使用 `npx playwright install chromium`）：

```bash
npm run verify                # 语法检查 + Prettier 格式检查 + 纯函数单元测试（不需要浏览器）
npm run format                # 按 .prettierrc 格式化 game/src 与 tests
npm run test:ui               # 桌面 + 移动视口冒烟测试（需要先 npm run serve）
npm run test:ui:levelup       # 首关击杀升级回归（需要先 npm run serve）
npm run test:ui:regression    # 界面渲染与输入回归（需要先 npm run serve）
npm run test:ui:blind         # 致盲被动端到端回归（需要先 npm run serve）
npm run test:ui:status        # 状态 HUD 四视口渲染回归（直接写字段，需要先 npm run serve）
npm run test:ui:status-real   # 五类状态真实战斗触发回归（需要先 npm run serve）
npm run test:ui:abilities     # 细粒度行为开关回归（需要先 npm run serve）
npm run test:ui:threats       # 五类地图威胁 + 专属精英回归（需要先 npm run serve）
npm run test:ui:echo          # F90 回响 B / 重构重生 / 入口补给一次性（需要先 npm run serve）
npm run test:ui:trash         # 深层 5 杀后清残余杂兵 / respawn Infinity（需要先 npm run serve）
```
