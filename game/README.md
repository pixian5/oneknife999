# 一刀999 浏览器纵向切片

这是设计文档对应的第一版可玩原型，目标是验证“出城 -> 找怪 -> 战斗 -> 掉落 -> 穿戴 -> 升级 -> 追逐首领”的 30 分钟体验闭环。它是前端模拟，不代表正式服务器实现；正式项目仍需按 `docs/09-服务器技术与反作弊.md` 接入权威战斗与资产服务。

## 启动

在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory game
```

然后打开 <http://127.0.0.1:4173>。

## 操作

- 选择战士、法师或道士后开始。
- `WASD` / 方向键移动，点击地面移动，点击怪物锁定。
- `J` 普攻，`1` 至 `4` 释放职业技能，`R` 释放满破势槽的一刀时刻。
- `F` 拾取附近掉落，`Q` 使用生命药水。
- 右侧背包中的装备可以点击穿戴；保存按钮把当前原型进度写入浏览器本地存储。

## 本版范围

已实现三职业差异、职业资源、技能冷却、伤害与防御减免、首领阶段、首领印记、地面掉落、装备穿戴、升级、委托进度、死亡复活提示、移动端按钮和低依赖 Canvas 场景。掉落和战斗仍为本地演示，尚未包含多人联机、真实 PK 爆装、行会王城、交易撮合和服务端持久化。
