# 一刀999 浏览器纵向切片

这是设计文档对应的可玩原型，目标是验证“出城 -> 找怪 -> 战斗 -> 掉落 -> 穿戴 -> 升级 -> 切换地图 -> 追逐首领”的体验闭环。它是前端模拟，不代表正式服务器实现；正式项目仍需按 `docs/09-服务器技术与反作弊.md` 接入权威战斗与资产服务。

## 启动

在仓库根目录执行：

```bash
python3 -m http.server 4174 --directory game
```

然后打开 <http://127.0.0.1:4174>。

## 操作

- 选择战士、法师或道士后开始。
- `WASD` / 方向键移动，点击地面移动，点击怪物锁定。
- 底部“普攻”按钮（或 `J`）会对当前锁定目标造成 100% 主属性伤害，并按职业积累怒气、法力或符力；`1` 至 `4` 释放职业技能，`R` 释放满破势槽的一刀时刻。
- 鼠标悬停技能会显示完整说明、资源消耗、冷却和射程；范围技能会在场景中以角色为中心显示半径预览。
- `F` 拾取附近掉落，`Q` 使用生命药水。
- `T` 始终指向当前地图的前进出口；前进出口需要完成当前地图的普通怪与 Boss 目标，返回上一地图的出口始终可用。
- 右侧"区域导航"面板显示所有首发地图，高亮当前所在地图和已到访地图；点击非相邻地图会提示需要先走到相邻出口。
- 右侧背包中的装备可以点击穿戴；保存按钮把当前原型进度写入浏览器本地存储。

## 战斗反馈与掉落（v0.1.2）

- 页面固定在一个视口内，桌面端信息区自动压缩；窄屏设备把角色、任务、地图、装备和背包变成横向滑动的信息带，不产生整页上下滚动。
- 角色头顶显示等级和生命条，职业资源蓝条位于底部技能栏上方；“普攻”按钮会说明当前职业的普通攻击与资源变化。
- 鼠标悬停技能会显示伤害、消耗、冷却和施法距离；范围技能同时在场景中显示以角色为中心的半径。
- 怪物头顶显示等级、当前生命和最大生命；鼠标悬停怪物会显示背景、攻击、防御、技能和首领阶段机制。
- 普通怪物死亡有 42% 概率生成一次地面掉落，区域首领固定生成两次掉落。掉落池包含生命药水、回元露、金币袋、区域装备、材料和首领印记碎片。
- 普攻触发的自动接近会在玩家按下任意方向键时取消，松开方向键不会继续追逐旧目标。

## 地图与关卡完成方式（v0.1.2）

每张地图都按“清剿普通怪 -> 击败区域首领 -> 前往下一关”的固定流程完成。场景右上角持续显示唯一下一步和三项检查清单，右侧当前关卡显示总进度，区域导航显示每张地图的未开始、进行中或已通关状态。

| 地图 | 普通怪目标 | 首领目标 | 完成后的动作 |
|---|---:|---|---|
| 灰烬村外 | 8 只 | 裂碑领主 | 东侧金色出口 -> 雾松林 |
| 雾松林 | 10 只 | 森林巨猿 | 东侧金色出口 -> 黑岩矿坑 |
| 黑岩矿坑 | 10 只 | 坑道尸皇 | 东侧金色出口 -> 赤砂大漠 |
| 赤砂大漠 | 10 只 | 沙蝎王 | 显示“四图通关，纵向切片完成” |

- Boss 不计入普通怪击杀数；两项目标不限制完成顺序。
- 未完成时前进出口显示红色锁定状态，走入会被推回并提示精确缺口；完成后改为金色并明确下一地图。
- 前三张地图首次通关分别发放 60 金币和 8 枚首领印记；最终地图同样发奖并显示最终结算。重复进入或 Boss 刷新不会重复发奖。
- 每张地图的击杀、Boss、通关与奖励状态独立保存。详细状态机和验收规则见 [`../docs/12-地图关卡与通关规则.md`](../docs/12-地图关卡与通关规则.md)。
- 原型按单人纵向切片调校：角色每级增加 18 点最大生命，四名区域首领保留阶段机制但使用 900/1400/2100/3000 的体验生命池，确保完成目标后能实际走到出口。
- 进入任意地图的安全缓冲区会补满生命与职业资源；地图左下角城镇内侧是可撤回的安全区，免受野怪和 Boss 危险区伤害并缓慢恢复生命/职业资源；赤砂大漠的水井还会更快净化毒层。死亡回到灰烬村后也会恢复，避免低血状态阻断继续完成关卡。

## 多地图与世界结构（v0.0.9）

本轮实现了 4 张首发地图，按等级递增构成线性探索路线：

| 地图 | 推荐等级 | 危险等级 | BOSS | 出口 |
|---|---:|---|---|---|
| 灰烬村外 | 1~10 | 村口保护 | 裂碑领主（2阶段） | → 雾松林 |
| 雾松林 | 8~18 | 野外可争夺 | 森林巨猿（2阶段·落木） | → 黑岩矿坑 / ← 灰烬村外 |
| 黑岩矿坑 | 15~28 | 野外可争夺 | 坑道尸皇（3阶段·召唤腐工/地裂/吞噬） | → 赤砂大漠 / ← 雾松林 |
| 赤砂大漠 | 20~35 | 危险区·爆装 | 沙蝎王（2阶段·尾刺/水井净化） | ← 黑岩矿坑 |

- **出口切换**：每张地图边缘有发光出口区域（青色脉冲边框 + 标签），走入即触发切换；跨地图保留等级、装备、背包、金币和首领印记。
- **等级门槛**：进入推荐等级过低的地图时会弹出二次确认（实际差距 2 级以上），取消则被弹回安全方向。
- **BOSS 阶段机制**：
  - 森林巨猿：50% 生命进入阶段二，开始落木（玩家附近随机生成红色蓄力圈，1.2 秒后爆发）。
  - 坑道尸皇：70%/35% 生命分三阶段，阶段一召唤腐工，阶段二/三释放地裂和吞噬（前方扇形危险区）。
  - 沙蝎王：50% 生命进入阶段二，尾刺精准锁定玩家位置；攻击叠加毒层（最多 5 层），需靠近地图中的水井地标净化。水井半径 70 内免受尾刺/危险区伤害，并以每秒约 10% 最大生命恢复；点击水井旁空地（不要点击与水井重叠的赤砂蝎）即可进入净化点。
- **危险区提示**：进入赤砂大漠会提示危险区规则；BOSS 蓄力危险区有红色虚线圈和橙色倒计时圆环双重预警。

## 本版范围

已实现三职业差异、职业资源、技能冷却、伤害与防御减免、首领阶段（含召唤/危险区/毒层/水井净化）、城镇安全区撤离、怪物信息、概率掉落、首领印记、装备穿戴、升级、委托进度、死亡复活提示、多地图切换、区域导航面板、固定视口 HUD、移动端按钮和低依赖 Canvas 场景。掉落和战斗仍为本地演示，尚未包含多人联机、真实 PK 爆装、行会王城、交易撮合和服务端持久化。

## 真实通关验收

`tests/e2e-ten-clear-runs.cjs` 使用 Playwright 的真实鼠标/键盘事件和浏览器时钟推进，不写入游戏内部状态。测试会按战士、法师、道士循环完成四图，低血时点击城镇或水井安全点恢复，再检查四图进度、出口切换和最终结算文案。最近一次十次结果见 [`../docs/13-通关测试记录.md`](../docs/13-通关测试记录.md)。
