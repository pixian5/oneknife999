# 一刀999 浏览器百图原型

这是《一刀999》传奇类游戏的可玩浏览器原型，当前实现 10 章、100 张连续关卡地图，验证“清怪 -> 首领 -> 掉落 -> 升级 -> 自动保存 -> 出口 -> 下一关”的完整循环。当前版本为 0.1.6。

## 启动

在仓库根目录执行：

```bash
python3 -m http.server 4174 --directory game
```

打开 <http://127.0.0.1:4174>。

## 操作

- 选择战士、法师或道士后开始。
- `WASD` / 方向键或点击地面移动，点击怪物锁定。
- `J` 普攻，`1`–`4` 技能，`R` 一刀时刻，`F` 拾取，`Q` 药水。
- `T` 前往当前关的东侧出口；必须完成普通怪与 Boss 两项目标。
- 技能悬停显示完整说明，范围技能显示以角色为中心的范围圈。
- 怪物头顶显示等级和生命；悬停显示背景、攻击、防御和技能。
- 普通怪和 Boss 都带独立背景与至少两条技能资料；后 96 图的生成怪会按章节显示专属介绍。

## 百图结构

地图按 10 章 × 10 图组织：灰烬边境、苍月群岛、龙脉地宫、冰封北境、烬火魔域、幽冥鬼蜮、天穹遗迹、星陨禁区、神魔战场、帝陵终境。

每关都包含独立地图名、推荐等级、危险标签、四类普通怪、区域首领、掉落、剧情目标和前后出口。前 4 关为手工地图，第 5–100 关按关号确定性生成营地、Boss、怪群、道路与地标，形成 100 个唯一实际构图。前哨、荒径、古寨、深谷、祭坛、迷宫、王庭、禁门、圣台和终殿各有专属道路、地标与首领场造型。右侧区域导航显示当前关附近 6 图以及“第 N/100 关”，保持整个 HUD 在一个视口内。

剧情按十章、100 个唯一节点推进；进入地图会显示章节摘要和角色对白，任务卡给出本关叙事目标，通关后揭示下一层真相。完整剧情见 [百图剧情与任务线](../docs/15-百图剧情与任务线.md)。

## 升级节奏

| 关卡阶段 | 升级速度 | 阶段终点 |
|---|---:|---:|
| 1–10 | 每图一级 | Lv.11 |
| 11–30 | 每两图一级 | Lv.21 |
| 31–60 | 每三图一级 | Lv.31 |
| 61–100 | 每四图一级 | Lv.41 |

普通怪和 Boss 提供当前地图的经验片段，首次通关时按累计地图数校准等级和经验，重复刷怪不会破坏主线成长曲线。后期升级变慢后，每张地图仍通过装备、金币、药水、印记和首领材料提供即时收益。

## 通关、保存与恢复

- 每关必须达到普通怪目标并击杀 Boss；两项允许任意顺序完成。
- 首次完成后只发放一次奖励，随后自动保存到 `oneknife999-prototype-save-v3`。
- 自动保存发生在关卡奖励和升级结算之后。
- 拾取掉落、穿戴/替换装备、使用药水后立即自动保存关键资产；刷新不会丢失这些变更。
- 点击“重置”会同时清除 v3 当前存档和 v2 旧存档，刷新后不会再次迁移旧进度。
- 刷新或任务中断后恢复当前地图、等级、经验、装备、背包和 100 图独立进度。
- 只有 v2 旧存档时会自动迁移到 v3，保留旧等级下限且不删除 v2 原件。
- 死亡回到当前地图安全营地，不会从后期退回第一关。
- 第 100 关完成后显示“百图征途已通关 / 全部完成”。

详细规则见 [地图关卡与通关规则](../docs/12-地图关卡与通关规则.md) 和 [百图关卡与成长曲线](../docs/14-百图关卡与成长曲线.md)。

## 战斗反馈与掉落

- 角色头顶显示等级与生命条，底部技能栏上方显示职业资源条。
- 普通怪死亡有 42% 概率掉落一次，Boss 固定掉落两次。
- 掉落池包含生命药水、回元露、金币、装备、材料和首领印记碎片。
- 进入地图左下安全营后免伤并恢复生命与职业资源；赤砂大漠水井可快速净化毒层。
- 玩家按下方向键会立即取消普攻自动接近，松开后不会继续追逐旧目标。

## 真实浏览器验收

```bash
ONEKNIFE_RUNS=1 \
NODE_PATH=/Users/x/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules \
/Users/x/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node \
tests/e2e-ten-clear-runs.cjs
```

驱动使用真实鼠标、键盘和浏览器时钟完成 100 图。默认 URL 含 `e2e=1&fast=1`：该模式仅在本机地址生效，快进只把伤害放大 25 倍，Boss 单次伤害限制为最大生命的 18%，不直接修改玩家、怪物或关卡状态。每一关都清怪、验证 Boss 完整阶段和危险技能、读取自动存档、刷新页面、验证恢复，然后走出口进入下一关。

最近结果见 [通关测试记录](../docs/13-通关测试记录.md)。

界面冒烟测试：

```bash
NODE_PATH=/Users/x/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules \
/Users/x/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node \
tests/ui-smoke.cjs
```

该测试检查桌面与移动视口无纵向滚动、Canvas 非空、底部技能栏不越界、技能说明悬停和范围技能预览。

三职业并行百图复核：

```bash
ONEKNIFE_RUNS=3 \
ONEKNIFE_CLASSES=warrior,mage,taoist \
ONEKNIFE_CONCURRENCY=3 \
NODE_PATH=/Users/x/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules \
/Users/x/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node \
tests/e2e-ten-clear-runs.cjs
```

该命令先验证 v2→v3 迁移、重置清除两代存档和装备自动保存，再同时打开三个独立浏览器账号，各自真实完成 100 图并在每关刷新恢复。

## 原型边界

当前掉落和战斗仍是本地前端模拟，尚未接入多人联机、服务端资产权威、真实 PK 爆装、行会王城和交易撮合。快进验收证明百图结构可达，不代表正式速度下的数值和平衡已经最终完成。
