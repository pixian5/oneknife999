# 一刀999 浏览器百图原型

这是《一刀999》传奇类游戏的可玩浏览器原型，当前实现 10 章、100 张连续关卡地图，验证“清怪 -> 首领 -> 掉落 -> 升级 -> 自动保存 -> 出口 -> 下一关”的完整循环。当前版本为 0.2.3。

## 启动

在仓库根目录执行：

```bash
npm run serve
```

打开 <http://127.0.0.1:4174>（等价于 `python3 -m http.server 4174 --directory game`）。

## 代码结构

原型入口为 `index.html`，逻辑拆分为 `src/` 下的 ES Modules：

| 文件 | 职责 |
|---|---|
| [src/main.js](src/main.js) | 入口与主逻辑：地图流程、输入、主循环与 E2E 接口（战斗/掉落为薄封装，调用纯逻辑模块） |
| [src/maps.js](src/maps.js) | 4 张手工地图 + 96 张确定性生成地图、关卡顺序与通关规则 |
| [src/config.js](src/config.js) | 职业、怪物资料、掉落池与运行环境标记 |
| [src/geometry.js](src/geometry.js) | 确定性随机、贝塞尔采样与路径计算（纯函数） |
| [src/combat.js](src/combat.js) | 伤害结算与击杀收益（纯函数，随机数参数注入） |
| [src/drops.js](src/drops.js) | 掉落掷点、拾取结算与场景节点效果（纯函数，随机数 / 时间参数注入） |
| [src/runtime.js](src/runtime.js) | 运行时状态容器（state / keys / pointer / moveTarget / joystick） |
| [src/render.js](src/render.js) | Canvas 世界绘制与右侧 HUD 的 DOM 渲染 |
| [src/persist.js](src/persist.js) | localStorage 存档读写与迁移函数表驱动的版本升级 |
| [src/util.js](src/util.js) | DOM 查询与数学辅助（纯函数） |

`geometry.js`、`maps.js`、`config.js`、`combat.js`、`drops.js` 不依赖 DOM，可直接被 Node 单元测试引用，也是未来服务端共享逻辑的候选。

## 操作

- 选择战士、法师或道士后开始。
- `WASD` / 方向键或点击地面移动，点击怪物锁定；移动端使用左下角虚拟摇杆拖动移动。
- `J` 普攻，`1`–`4` 技能，`R` 一刀时刻，`F` 交互（优先拾取掉落，其次搜索补给箱，再激活场景节点），`Q` 药水。
- `T` 前往当前关的东侧出口；必须完成普通怪与 Boss 两项目标。
- 技能悬停显示完整说明，范围技能显示以角色为中心的范围圈。
- 怪物头顶显示等级和生命；悬停显示背景、攻击、防御和技能。
- 普通怪和 Boss 都带独立背景与至少两条技能资料；后 96 图的生成怪会按章节显示专属介绍。

## 百图结构

地图按 10 章 × 10 图组织：灰烬边境、苍月群岛、龙脉地宫、冰封北境、烬火魔域、幽冥鬼蜮、天穹遗迹、星陨禁区、神魔战场、帝陵终境。

每关都包含独立地图名、推荐等级、危险标签、四类普通怪、区域首领、掉落、剧情目标和前后出口。前 4 关为手工地图，第 5–100 关按关号确定性生成营地、Boss、怪群、道路与地标，形成 100 个唯一实际构图。前哨、荒径、古寨、深谷、祭坛、迷宫、王庭、禁门、圣台和终殿各有专属道路、地标与首领场造型。后 96 图的怪群不再漂浮在随机空地：主路按“前段警戒带 -> 中段压迫带 -> 首领前集结”分段布置；`fork/radial` 额外在支路中段布置 4 只支路守卫，绕路取补给会有明确战斗代价。每张图的 Canvas 会显示分段编号、路线名称和预计怪数，且普通怪刷新点避开首领战区。右侧区域导航显示当前关附近 6 图以及“第 N/100 关”，保持整个 HUD 在一个视口内。

每张地图还固定放置 1 处前线篝火、1 个秘藏补给箱和 1 个场景交互节点。篝火在半径 62 内持续恢复生命、职业资源并净化毒层；补给箱在半径 70 内按 `F` 搜索一次，奖励生命药水、金币和首领印记；场景节点在半径 66 内按 `F` 激活一次，根据前哨、荒径、古寨、深谷、祭坛、迷宫、王庭、禁门、圣台或终殿提供破势、资源、免伤、净毒或 Boss 锁定等即时效果。`fork/radial` 地图会把补给箱明确放在支路，HUD 显示“可选支路”提示；主线可直达战斗与首领区，玩家可自行决定是否绕路取补给。两类一次性交互都会写入当前地图进度并自动保存，节点位置会避开出生点、怪物刷新点和 Boss，详情见 [地图场景交互节点打磨记录](../docs/18-地图场景交互节点打磨记录.md)。

剧情按十章、100 个唯一节点推进；进入地图会显示章节摘要和角色对白，任务卡给出本关叙事目标，通关后揭示下一层真相。完整剧情见 [百图剧情与任务线](../docs/15-百图剧情与任务线.md)。

## 升级节奏

| 关卡阶段 | 升级速度 | 阶段终点 |
|---|---:|---:|
| 1–10 | 每图一级 | Lv.11 |
| 11–30 | 每两图一级 | Lv.21 |
| 31–60 | 每三图一级 | Lv.31 |
| 61–100 | 每四图一级 | Lv.41 |

普通怪和 Boss 提供当前地图的经验片段，首次通关时按累计地图数校准等级和经验，重复刷怪不会破坏主线成长曲线。后期升级变慢后，每张地图仍通过装备、金币、药水、印记和首领材料提供即时收益。

## 通关、保存与恢复

- 每关必须达到普通怪目标并击杀 Boss；两项允许任意顺序完成。
- 首次完成后只发放一次奖励，随后自动保存到 `oneknife999-prototype-save-v3`。
- 自动保存发生在关卡奖励和升级结算之后。
- 拾取掉落、穿戴/替换装备、使用药水后立即自动保存关键资产；刷新不会丢失这些变更。
- 点击“重置”会同时清除 v3 当前存档和 v2 旧存档，刷新后不会再次迁移旧进度。
- 刷新或任务中断后恢复当前地图、等级、经验、装备、背包和 100 图独立进度。
- 只有 v2 旧存档时会自动迁移到 v3，保留旧等级下限且不删除 v2 原件。
- 死亡回到当前地图安全营地，不会从后期退回第一关。
- 第 100 关完成后显示“百图征途已通关 / 全部完成”。

详细规则见 [地图关卡与通关规则](../docs/12-地图关卡与通关规则.md) 和 [百图关卡与成长曲线](../docs/14-百图关卡与成长曲线.md)。

## 战斗反馈与掉落

- 角色头顶显示等级与生命条，底部技能栏上方显示职业资源条。
- 普通怪死亡有 42% 概率掉落一次，Boss 固定掉落两次。
- 掉落池包含生命药水、回元露、金币、装备、材料和首领印记碎片。
- 进入地图左下安全营后免伤并恢复生命与职业资源；赤砂大漠水井可快速净化毒层。
- 玩家按下方向键会立即取消普攻自动接近，松开后不会继续追逐旧目标。

## 测试

先安装依赖（仅 Playwright 包，不会下载浏览器）：

```bash
npm install
```

三类测试都直接使用本机已安装的 Google Chrome（`ONEKNIFE_CHANNEL` 可切换：默认 `chrome`；CI 上设 `chromium` 并使用 `npx playwright install chromium`）：

```bash
npm run verify                # 语法检查 + Prettier 格式检查 + 纯函数单元测试（不需要浏览器）
npm run format                # 按 .prettierrc 格式化 game/src 与 tests
npm run test:ui               # 桌面 + 移动视口冒烟测试（需要先 npm run serve）
npm run test:ui:regression    # 界面渲染与输入回归（需要先 npm run serve）
npm run test:e2e              # 百图通关回归（需要先 npm run serve）
npm run perf                  # 帧率探测（需要先 npm run serve，结果写入 .test-artifacts/）
```

真实浏览器验收会使用真实鼠标、键盘和浏览器时钟完成 100 图。默认 URL 含 `e2e=1&fast=1`：该模式仅在本机地址生效，快进只把伤害放大 25 倍，Boss 单次伤害限制为最大生命的 18%，不直接修改玩家、怪物或关卡状态。每一关都清怪、验证 Boss 完整阶段和危险技能、读取自动存档、刷新页面、验证恢复，然后走出口进入下一关。

最近结果见 [通关测试记录](../docs/13-通关测试记录.md)。

界面冒烟测试检查桌面（1440×900）、移动（390×844）与窄屏（360×640）三个视口无纵向滚动、Canvas 非空、底部技能栏不越界、技能说明悬停、范围技能预览，以及虚拟摇杆拖拽移动与松开复位。

界面渲染与输入回归测试检查首领刷新读秒随实体递减（不再固定 0s）、技能/背包/装备/导航/日志/关卡卡在静止帧内不被每帧重建、Shift/CapsLock 状态下大写按键仍可移动，以及真实拾取后面板按需刷新。

帧率探测（`npm run perf`）用无头 Chrome 关闭垂直同步采样 8 秒真实操作，当前基线为平均约 4647 fps、p99 帧 0.9ms、最差帧 8.3ms、零长帧（MacBook M5 / 1440×900；桌面无头环境，不代表移动真机）。

三职业并行百图复核：

```bash
ONEKNIFE_RUNS=3 ONEKNIFE_CLASSES=warrior,mage,taoist ONEKNIFE_CONCURRENCY=3 npm run test:e2e
```

该命令先验证 v2→v3 迁移、重置清除两代存档和装备自动保存，再同时打开三个独立浏览器账号，各自真实完成 100 图并在每关刷新恢复。路线营位打磨后的最近结果为战士、法师、道士均通过 100/100、Lv.41，合计 300 个检查点通过。若要逐关真实走到并激活场景节点，可追加 `ONEKNIFE_ACTIVATE_SITES=1`；该模式已完成战士 100/100 节点激活回归。

## 原型边界

当前掉落和战斗仍是本地前端模拟，尚未接入多人联机、服务端资产权威、真实 PK 爆装、行会王城和交易撮合。快进验收证明百图结构可达，不代表正式速度下的数值和平衡已经最终完成。
