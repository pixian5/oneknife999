# 战斗与数值经验

> 来源：`docs/02`、`docs/03`、`docs/04`、`docs/11`、`docs/14`、`docs/20261011-1335-深入代码分析与数值断层-GLM.md`、`docs/20261021-0316-*`、`docs/20261022-2146-真实速度数值复测-豆包.md`、`docs/20261023-0240-技能语义对齐与怪物前摇-DeepSeek-V4.1-Flash.md`。

## 数值基线

- 承伤公式必须与 docs/11 一致：`减免 = 防御 / (防御 + 100 + 攻击者等级 × 5)`，且输入输出同源（`computeIncomingDamage`），不要另写一套。
- 首领单次受击上限 3.5% 最大生命，防止高倍率技能跳过阶段战；快进模式放宽到 18%。
- 第 5 关曾出现「关 4→5 数值断崖」：生成图曲线必须锚定手工第 4 关水平，难度与装备两条曲线同步抬升；`maps.test.mjs` 已有「关 4→5 无断崖」断言。
- 满破势爆发 1.55 倍，且一刀时刻会清空破势槽，两者不叠加。

## 经验与等级

- 击杀经验必须真实结算并可连续升级（`applyExperience`），不能把经验硬截断在 99、只在通关时重算等级——这是玩家反馈过的真实事故。
- 本关等级上限 = 主线曲线等级 + 1（终局封顶 Lv.41）；首轮进度击杀给满额经验，清完目标后继续刷怪给 50%，避免无限刷级又不至于「打半天不升级」。

## 怪物出手节奏（重要）

- 旧模型：每帧掷骰（普通 0.32 次/秒、首领 0.6 次/秒），并且**每帧只判定距离最近的一只怪**，被 6 只怪围住承伤不叠加。
- 改成固定前摇后，若照搬设计稿 1.2 / 0.9 秒冷却，每只怪独立出手 + 前摇必中 → 承伤线性爆炸，实测第 4 关沙蝎王 1 张图 15 次死亡。
- 现行方案：前摇 0.45s（普通）/ 0.6s（首领） + 全局闸门 `player.attackGate`（3.1s / 1.7s） + `MAX_WINDUP_ATTACKERS = 1`，把承伤速率校准回旧模型。**闸门必须在 `update()` 里逐帧递减**，否则写入一次就永久锁死怪物攻击。
- 调这类参数的正确流程：先用临时 Playwright 复现最难的 Boss 战（连跑 3 次），再跑百图 e2e 看是否出现单图死亡循环，最后再谈数值微调。
- **致死来源要按来源统计，不能只看总数**：0.7.6 给探针加了 `killers` 后发现，第 30 关战士的 53 次死亡分散在 9 个来源上——`ranged` 25%、`charge` 21%、`sweep` 17% 三类「扩大交战窗口」的形态合计 62%，首领 13%、普通近战 13%、地面危险区 8%，`heavy` 零致死人。结论：整体收系数是钝刀，定向调 `ranged` / `charge` 更有效；`heavy` 继续削只会牺牲手感而没有收益。

## 金币与养成经济

- 纯 PvE 原型里金币若只有「掉落 + 任务 + 连击」入口而无出口，会迅速膨胀（百图末约 22.9 万），任务奖励与掉落失去决策价值。必须有持续消耗出口：消耗品、材料、词缀重铸。
- 重铸成本要随强化等级与词缀条数上升（现行 `120 + 40×强化 + 60×词缀数`），否则「洗白板」会比强化更划算；同时每次只重掷一条，保留养成过程。
- 重铸卷 / 材料等消耗品用独立计数而不是全塞进材料池：混池会让玩家在强化时误吃掉买来的卷轴。

## 装备属性生效链路

- **防御词缀曾长期是「死代码」**（0.3.5 上线重铸 → 0.3.6 发现 → 0.3.7 修复）：`equipmentDefenseBonus()` 与 `equipmentDefense()` 都写对了，但承伤处写的是 `activeHero().defense`，装备防御从未参与结算。现在统一走 `runtime.playerDefense()`。改装备属性时务必确认「定义 → 汇总 → 传入结算」三段都接通，否则 HUD 显示了但战斗不生效；新增承伤点必须用 `playerDefense()`，不要再直接取 `activeHero().defense`。
- 攻击 / 生命词缀走的是 `effectiveItemPower` 与 `equipmentHpBonus`，已在伤害公式与 `playerMaxHp()` 中生效，可作为接线参照。

## 技能语义

- 文案写了机制就必须实现：破甲（防御 -15% / 4s）、冲锋（140px + 击退 + 0.2s 无敌）、穿透（直线最多 3 目标）、骨卫（12s 友军实体、40% 攻击）、法阵（4s、每秒 8%、离开失效）。「只加伤害不改机制」会被玩家立刻感知为虚假描述。
- 召唤物用 `friendly` 标记与怪物隔离（不索敌、不被锁定、不复活、不进快照）。
